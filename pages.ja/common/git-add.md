# git add

> 変更されたファイルをコミット対象としてステージする。
> 詳細情報: <https://git-scm.com/docs/git-add>。

- ファイルをコミット対象としてステージする:

`git add {{ディレクトリ/サブディレクトリ/ファイル}}`

- すべてのファイル (追跡済みおよび未追跡) を追加する:

`git add {{[-A|--all]}}`

- 現在のディレクトリ以下にあるすべてのファイルを再帰的に追加する:

`git add .`

- 追跡済みのファイルのみを追加する:

`git add {{[-u|--update]}}`

- 無視されているファイルを追加する:

`git add {{[-f|--force]}} {{ディレクトリ/サブディレクトリ/ファイル}}`

- ファイルの一部を対話形式でステージする:

`git add {{[-p|--patch]}}`

- 指定したファイルの一部を対話形式でステージする:

`git add {{[-p|--patch]}} {{ディレクトリ/サブディレクトリ/ファイル}}`

- ファイルを対話形式でステージする:

`git add {{[-i|--interactive]}}`
