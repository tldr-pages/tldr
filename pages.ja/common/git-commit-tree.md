# git commit-tree

> コミットオブジェクトを作成する低レベルユーティリティ。
> 参照: `git commit`。
> 詳細情報: <https://git-scm.com/docs/git-commit-tree>。

- 指定したメッセージでコミットオブジェクトを作成する:

`git commit-tree {{ツリー}} -m "{{メッセージ}}"`

- ファイルからメッセージを読み込んでコミットオブジェクトを作成する (`stdin` には `-` を使用):

`git commit-tree {{ツリー}} -F {{ディレクトリ/サブディレクトリ/ファイル}}`

- GPG署名付きのコミットオブジェクトを作成する:

`git commit-tree {{ツリー}} -m "{{メッセージ}}" {{[-S|--gpg-sign]}}`

- 指定した親コミットオブジェクトを持つコミットオブジェクトを作成する:

`git commit-tree {{ツリー}} -m "{{メッセージ}}" -p {{親コミットSHA}}`
