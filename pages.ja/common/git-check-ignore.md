# git check-ignore

> Gitの無視・除外ファイル (`.gitignore`) を解析、デバッグする。
> 詳細情報: <https://git-scm.com/docs/git-check-ignore>。

- ファイルまたはディレクトリが無視されているか確認する:

`git check-ignore {{ディレクトリ/サブディレクトリ/ファイル_または_ディレクトリ}}`

- 複数のファイルまたはディレクトリが無視されているか確認する:

`git check-ignore {{ディレクトリ/サブディレクトリ/ファイル_または_ディレクトリ1 ディレクトリ/サブディレクトリ/ファイル_または_ディレクトリ2 ...}}`

- 1行に1つずつ記載されたパス名を `stdin` から読み込む:

`git < {{ディレクトリ/サブディレクトリ/ファイル一覧}} check-ignore --stdin`

- インデックスを確認しない (パスが無視されず追跡された理由のデバッグに使用する):

`git check-ignore --no-index {{ディレクトリ/サブディレクトリ/ファイル_または_ディレクトリ1 ディレクトリ/サブディレクトリ/ファイル_または_ディレクトリ2 ...}}`

- 各パスに一致したパターンの詳細を含める:

`git check-ignore {{[-v|--verbose]}} {{ディレクトリ/サブディレクトリ/ファイル_または_ディレクトリ1 ディレクトリ/サブディレクトリ/ファイル_または_ディレクトリ2 ...}}`
