# git subtree

> サブツリーをまとめてマージ、またはリポジトリからサブツリーを分割する。
> 詳細情報: <https://manned.org/git-subtree>。

- Gitリポジトリをサブツリーとして追加し、コミットをまとめて1つにする:

`git subtree add {{[-P|--prefix]}} {{ディレクトリ/サブディレクトリ}} --squash {{リポジトリURL}} {{ブランチ名}}`

- サブツリーのリポジトリを最新コミットへ更新する:

`git subtree pull {{[-P|--prefix]}} {{ディレクトリ/サブディレクトリ}} {{リポジトリURL}} {{ブランチ名}}`

- 最新のサブツリーコミットまでの変更をサブツリーへマージする:

`git subtree merge {{[-P|--prefix]}} {{ディレクトリ/サブディレクトリ}} --squash {{リポジトリURL}} {{ブランチ名}}`

- コミットをサブツリーのリポジトリへプッシュする:

`git subtree push {{[-P|--prefix]}} {{ディレクトリ/サブディレクトリ}} {{リポジトリURL}} {{ブランチ名}}`

- サブツリーの履歴から新しいプロジェクトの履歴を抽出する:

`git subtree split {{[-P|--prefix]}} {{ディレクトリ/サブディレクトリ}} {{リポジトリURL}} {{[-b|--branch]}} {{ブランチ名}}`
