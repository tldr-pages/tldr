# git clone

> 既存のリポジトリを複製する。
> 詳細情報: <https://git-scm.com/docs/git-clone>。

- 既存のリポジトリを新しいディレクトリに複製する (既定のディレクトリ名はリポジトリ名):

`git clone {{リモートリポジトリの場所}} {{ディレクトリへのパス}}`

- 既存のリポジトリとそのサブモジュールを複製する:

`git clone --recursive {{リモートリポジトリの場所}}`

- 既存のリポジトリの `.git` ディレクトリのみを複製する:

`git clone {{[-n|--no-checkout]}} {{リモートリポジトリの場所}}`

- ローカルリポジトリを複製する:

`git clone {{[-l|--local]}} {{ローカルリポジトリへのパス}}`

- メッセージを抑制して複製する:

`git clone {{[-q|--quiet]}} {{リモートリポジトリの場所}}`

- 既存のリポジトリの既定ブランチから最新10件のコミットのみを取得して複製する (時間を節約する場合に便利):

`git clone --depth 10 {{リモートリポジトリの場所}}`

- 既存のリポジトリから指定したブランチのみを取得して複製する:

`git clone {{[-b|--branch]}} {{ブランチ名}} --single-branch {{リモートリポジトリの場所}}`

- 指定したSSHコマンドを使用して既存のリポジトリを複製する:

`git clone {{[-c|--config]}} core.sshCommand="{{ssh -i SSH秘密鍵へのパス}}" {{リモートリポジトリの場所}}`
