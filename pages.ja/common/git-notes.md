# git notes

> オブジェクトのノートを追加または確認する。
> 詳細情報: <https://git-scm.com/docs/git-notes>。

- すべてのノートと、それらが付けられているオブジェクトを一覧表示する:

`git notes list`

- 指定したオブジェクトに付けられているすべてのノートを一覧表示する (既定は `HEAD`):

`git notes list {{オブジェクト}}`

- 指定したオブジェクトに付けられているノートを表示する (既定は `HEAD`):

`git notes show {{オブジェクト}}`

- 指定したオブジェクトにノートを追加する (既定のテキストエディターを開く):

`git notes append {{オブジェクト}}`

- メッセージを指定して、指定したオブジェクトにノートを追加する:

`git notes append --message="{{メッセージテキスト}}"`

- 既存のノートを編集する (既定は `HEAD`):

`git notes edit {{オブジェクト}}`

- あるオブジェクトから別のオブジェクトへノートをコピーする:

`git notes copy {{コピー元オブジェクト}} {{コピー先オブジェクト}}`

- 指定したオブジェクトに追加されたすべてのノートを削除する:

`git notes remove {{オブジェクト}}`
