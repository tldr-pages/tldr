# git log

> コミット履歴を表示する。
> 詳細情報: <https://git-scm.com/docs/git-log>。

- 現在の作業ディレクトリにあるGitリポジトリで、現在のコミットから始まるコミット履歴を新しい順に表示する:

`git log`

- 指定したファイルまたはディレクトリの履歴を差分と共に表示する:

`git log {{[-p|--patch]}} {{ファイルまたはディレクトリへのパス}}`

- 各コミットで変更されたファイルの概要を表示する:

`git log --stat`

- 現在のブランチのコミットを、各コミットメッセージの先頭行のみを使用したグラフで表示する:

`git log --oneline --graph`

- リポジトリ全体のすべてのコミット、タグ、ブランチをグラフで表示する:

`git log --oneline --decorate --all --graph`

- メッセージに指定した文字列を含むコミットのみを、大文字と小文字を区別せずに表示する:

`git log {{[-i|--regexp-ignore-case]}} --grep {{検索文字列}}`

- 指定した作成者による最新のコミットを `n` 件表示する:

`git log {{[-n|--max-count]}} {{件数}} --author "{{作成者}}"`

- 指定した2つの日付の間にあるコミットを表示する (日付形式はyyyy-mm-dd):

`git log --before "{{2017-01-29}}" --after "{{2017-01-17}}"`
