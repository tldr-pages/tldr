# git pull

> リモートリポジトリからブランチを取得し、ローカルリポジトリへマージする。
> 詳細情報: <https://git-scm.com/docs/git-pull>。

- 既定のリモートリポジトリから変更をダウンロードしてマージする:

`git pull`

- 既定のリモートリポジトリから変更をダウンロードしてリベースする:

`git pull {{[-r|--rebase]}}`

- 指定したリモートリポジトリから変更をダウンロードする:

`git pull {{リモート名}}`

- 指定したリモートリポジトリとブランチから変更をダウンロードし、`HEAD` にマージする:

`git pull {{リモート名}} {{ブランチ}}`
