# git blame

> ファイルの各行を最後に変更したコミットと作成者を表示する。
> 詳細情報: <https://git-scm.com/docs/git-blame>。

- 作成者情報 (作成者名とコミットハッシュ) 付きでファイルを表示する:

`git blame {{ディレクトリ/サブディレクトリ/ファイル}}`

- 作成者名の代わりに作成者のメールアドレスを表示する:

`git blame {{[-e|--show-email]}} {{ディレクトリ/サブディレクトリ/ファイル}}`

- 指定したコミット時点の作成者情報付きでファイルを表示する:

`git blame {{コミット}} {{ディレクトリ/サブディレクトリ/ファイル}}`

- 指定したコミットより前の作成者情報付きでファイルを表示する:

`git blame {{コミット}}~ {{ディレクトリ/サブディレクトリ/ファイル}}`

- 指定した行から作成者情報付きでファイルを表示する:

`git blame -L {{123}} {{ディレクトリ/サブディレクトリ/ファイル}}`

- ファイルの指定した行範囲を注釈付きで表示する:

`git blame -L {{開始行}},{{終了行}} {{ディレクトリ/サブディレクトリ/ファイル}}`

- 指定したテキストに一致する最初の行から10行を注釈付きで表示する:

`git blame -L '/{{テキスト}}/',+10 {{ディレクトリ/サブディレクトリ/ファイル}}`

- 空白文字と行の移動を無視して、ファイルを注釈付きで表示する:

`git blame -w -C -C -C {{ディレクトリ/サブディレクトリ/ファイル}}`
