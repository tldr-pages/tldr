# git reset

> 現在のGitの `HEAD` を指定した状態へリセットし、コミットを取り消すか変更のステージを解除する。
> パスを渡すとステージ解除として動作し、コミットハッシュまたはブランチを渡すとコミットの取り消しとして動作する。
> 詳細情報: <https://git-scm.com/docs/git-reset>。

- すべてのステージを解除する:

`git reset`

- 指定したファイルのステージを解除する:

`git reset {{ディレクトリ/サブディレクトリ/ファイル1 ディレクトリ/サブディレクトリ/ファイル2 ...}}`

- ファイルの一部を対話形式でステージ解除する:

`git reset {{[-p|--patch]}} {{ディレクトリ/サブディレクトリ/ファイル}}`

- 最後のコミットを取り消し、その変更とその他の未コミットの変更をファイルシステムに保持する:

`git reset HEAD~`

- 最後の2件のコミットを取り消し、その変更をインデックスへ追加してコミット対象としてステージする:

`git reset --soft HEAD~2`

- ステージ済みかどうかにかかわらず、未コミットの変更をすべて破棄する (ステージされていない変更のみの場合は `git checkout` を使用する):

`git reset --hard`

- リポジトリを指定したコミットへリセットし、それ以降のコミット済み、ステージ済み、未コミットの変更を破棄する:

`git reset --hard {{コミット}}`
