# git rm

> リポジトリのインデックスとローカルファイルシステムからファイルを削除する。
> 詳細情報: <https://git-scm.com/docs/git-rm>。

- リポジトリのインデックスとファイルシステムからファイルを削除する:

`git rm {{ディレクトリ/サブディレクトリ/ファイル}}`

- ディレクトリを再帰的に削除する:

`git rm -r {{ディレクトリ/サブディレクトリ}}`

- リポジトリのインデックスからファイルを削除し、ローカルには残す:

`git rm --cached {{ディレクトリ/サブディレクトリ/ファイル}}`

- リポジトリを `.git` ディレクトリだけの状態にする:

`git rm -r .`
