# git tag

> タグを作成、一覧表示、削除、または検証する。
> タグはコミットへの静的な参照である。
> 詳細情報: <https://git-scm.com/docs/git-tag>。

- すべてのタグを一覧表示する:

`git tag`

- 現在のコミットを指す、指定した名前のタグを作成する:

`git tag {{タグ名}}`

- 指定したコミットを指す、指定した名前のタグを作成する:

`git tag {{タグ名}} {{コミット}}`

- 指定したメッセージを持つ注釈付きタグを作成する:

`git tag {{タグ名}} {{[-m|--message]}} {{タグメッセージ}}`

- 指定した名前のタグを削除する:

`git tag {{[-d|--delete]}} {{タグ名}}`

- リモートから更新されたタグを取得する:

`git fetch {{[-t|--tags]}}`

- タグをリモートへプッシュする:

`git push origin tag {{タグ名}}`

- 指定したコミットを含むすべてのタグを一覧表示する (省略した場合は `HEAD`):

`git tag --contains {{コミット}}`
