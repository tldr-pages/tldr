# git check-attr

> 各パス名について、各属性がそのパス名のgitattributeとして未指定、設定済み、未設定のどれであるかを一覧表示する。
> 詳細情報: <https://git-scm.com/docs/git-check-attr>。

- ファイル上のすべての属性値を確認する:

`git check-attr {{[-a|--all]}} {{ディレクトリ/サブディレクトリ/ファイル}}`

- ファイル上の指定した属性値を確認する:

`git check-attr {{属性}} {{ディレクトリ/サブディレクトリ/ファイル}}`

- 指定したファイル群のすべての属性値を確認する:

`git check-attr {{[-a|--all]}} {{ディレクトリ/サブディレクトリ/ファイル1 ディレクトリ/サブディレクトリ/ファイル2 ...}}`

- 1つ以上のファイル上の指定した属性値を確認する:

`git check-attr {{属性}} {{ディレクトリ/サブディレクトリ/ファイル1 ディレクトリ/サブディレクトリ/ファイル2 ...}}`
