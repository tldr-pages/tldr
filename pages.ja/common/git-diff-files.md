# git diff-files

> sha1ハッシュとモードを使ってファイルを比較する。
> 詳細情報: <https://git-scm.com/docs/git-diff-files>。

- 変更されたすべてのファイルを比較する:

`git diff-files`

- 指定したファイルだけを比較する:

`git diff-files {{ディレクトリ/サブディレクトリ/ファイル}}`

- 変更されたファイル名だけを表示する:

`git diff-files --name-only`

- 拡張ヘッダー情報の要約を出力する:

`git diff-files --summary`
