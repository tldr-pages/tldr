# git write-tree

> 現在のインデックスからツリーオブジェクトを作成する低レベルユーティリティ。
> 詳細情報: <https://git-scm.com/docs/git-write-tree>。

- 現在のインデックスからツリーオブジェクトを作成する:

`git write-tree`

- ディレクトリから参照されるオブジェクトがオブジェクトデータベースに存在するか確認せずに、ツリーオブジェクトを作成する:

`git write-tree --missing-ok`

- サブディレクトリを表すツリーオブジェクトを作成する (指定したサブディレクトリ内のサブプロジェクト用ツリーオブジェクトを書き込むために使用):

`git write-tree --prefix {{サブディレクトリ}}/`
