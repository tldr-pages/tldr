# git checkout

> ブランチまたはパスを作業ツリーにチェックアウトする。
> 詳細情報: <https://git-scm.com/docs/git-checkout>。

- 新しいブランチを作成して切り替える:

`git checkout -b {{ブランチ名}}`

- 指定した参照を基に新しいブランチを作成して切り替える (ブランチ、リモート/ブランチ、タグなどが有効な参照):

`git checkout -b {{ブランチ名}} {{参照}}`

- 既存のローカルブランチに切り替える:

`git checkout {{ブランチ名}}`

- 直前にチェックアウトしていたブランチに切り替える:

`git checkout -`

- 既存のリモートブランチに切り替える:

`git checkout {{[-t|--track]}} {{リモート名}}/{{ブランチ名}}`

- 現在のディレクトリにあるステージされていない変更をすべて破棄する (その他の取り消し操作については `git reset` を参照):

`git checkout .`

- 指定したファイルのステージされていない変更を破棄する:

`git checkout {{ファイルへのパス}}`

- 現在のディレクトリにあるファイルを、指定したブランチにコミットされているバージョンへ置き換える:

`git checkout {{ブランチ名}} -- {{ファイルへのパス}}`
