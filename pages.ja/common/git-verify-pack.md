# git verify-pack

> パックされたGitアーカイブファイルを検証する。
> 詳細情報: <https://git-scm.com/docs/git-verify-pack>。

- パックされたGitアーカイブファイルを検証する:

`git verify-pack {{ディレクトリ/サブディレクトリ/pack-file}}`

- パックされたGitアーカイブファイルを検証し、詳細を表示する:

`git verify-pack {{[-v|--verbose]}} {{ディレクトリ/サブディレクトリ/pack-file}}`

- パックされたGitアーカイブファイルを検証し、統計だけを表示する:

`git verify-pack {{[-s|--stat-only]}} {{ディレクトリ/サブディレクトリ/pack-file}}`
