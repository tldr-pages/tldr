# git diff

> 追跡済みファイルの変更を表示する。
> 詳細情報: <https://git-scm.com/docs/git-diff>。

- ステージされていない変更を表示する:

`git diff`

- ステージ済みの変更を含む、コミットされていないすべての変更を表示する:

`git diff HEAD`

- ステージ済み (追加済みだが未コミット) の変更のみを表示する:

`git diff --staged`

- 指定した日時以降のすべてのコミットによる変更を表示する (日時式には "1 week 2 days" やISO形式の日付などを指定する):

`git diff 'HEAD@{{{3 months|weeks|days|hours|seconds ago}}}'`

- 変更されたファイル、棒グラフ、追加および削除された行数などの差分統計を表示する:

`git diff --stat {{コミット}}`

- 指定したコミット以降に作成、名前変更、モード変更されたファイルの概要を表示する:

`git diff --summary {{コミット}}`

- 2つのブランチまたはコミット間で、指定したファイルを比較する:

`git diff {{ブランチ1}}..{{ブランチ2}} {{ディレクトリ/サブディレクトリ/ファイル}}`

- 現在のブランチにあるファイルと、別のブランチにある異なるファイルを比較する:

`git diff {{別のブランチ}}:{{ディレクトリ/サブディレクトリ/ファイル2}} {{ディレクトリ/サブディレクトリ/ファイル1}}`
