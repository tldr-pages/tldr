# git worktree

> 同じリポジトリに紐付いた複数の作業ツリーを管理する。
> 詳細情報: <https://git-scm.com/docs/git-worktree>。

- ディレクトリと同じ名前のブランチ用の新しい作業ツリーディレクトリを追加する (ブランチが存在しない場合は作成される):

`git worktree add {{ブランチ}}`

- 指定したブランチをチェックアウトした新しいディレクトリを作成する:

`git worktree add {{ディレクトリ/サブディレクトリ}} {{ブランチ}}`

- 新しいブランチをチェックアウトした新しいディレクトリを作成する:

`git worktree add {{ディレクトリ/サブディレクトリ}} -b {{新しいブランチ}}`

- すべての作業ディレクトリ (メインのものを含む) を一覧表示する:

`git worktree list`

- 既存の作業ツリーを新しい場所に移動する:

`git worktree move {{ディレクトリ/サブディレクトリ/作業ツリー}} {{新しい/パス}}`

- 作業ツリーディレクトリとそのメタデータを削除する (未コミットの変更がない場合のみ):

`git worktree remove {{ディレクトリ/サブディレクトリ/作業ツリー}}`

- 手動で削除された作業ツリーディレクトリのメタデータを削除する:

`git worktree prune`
