# git push

> コミットをリモートリポジトリにプッシュする。
> 詳細情報: <https://git-scm.com/docs/git-push>。

- 現在のブランチのローカル変更を、既定の対応するリモートブランチへ送信する:

`git push`

- 指定したローカルブランチの変更を、対応するリモートブランチへ送信する:

`git push {{リモート名}} {{ローカルブランチ}}`

- 指定したローカルブランチの変更を対応するリモートブランチへ送信し、そのリモートブランチを既定のプッシュおよびプル先に設定する:

`git push {{[-u|--set-upstream]}} {{リモート名}} {{ローカルブランチ}}`

- 指定したローカルブランチの変更を、指定したリモートブランチへ送信する:

`git push {{リモート名}} {{ローカルブランチ}}:{{リモートブランチ}}`

- すべてのローカルブランチの変更を、指定したリモートリポジトリの対応するブランチへ送信する:

`git push --all {{リモート名}}`

- リモートリポジトリのブランチを削除する:

`git push {{リモート名}} {{[-d|--delete]}} {{リモートブランチ}}`

- 対応するローカルブランチがないリモートブランチを削除する:

`git push --prune {{リモート名}}`

- リモートリポジトリにまだ存在しないタグを公開する:

`git push --tags`
