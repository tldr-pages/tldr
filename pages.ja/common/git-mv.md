# git mv

> ファイルを移動または名前変更し、Gitインデックスを更新する。
> 詳細情報: <https://git-scm.com/docs/git-mv>。

- リポジトリ内でファイルを移動し、その移動を次のコミットに追加する:

`git mv {{ディレクトリ/サブディレクトリ/ファイル}} {{ディレクトリ/サブディレクトリ/移動先}}`

- ファイルまたはディレクトリを名前変更し、その名前変更を次のコミットに追加する:

`git mv {{ディレクトリ/サブディレクトリ/ファイル_または_ディレクトリ}} {{ディレクトリ/サブディレクトリ/移動先}}`

- 移動先パスにファイルまたはディレクトリが存在する場合、それを上書きする:

`git mv {{[-f|--force]}} {{ディレクトリ/サブディレクトリ/ファイル_または_ディレクトリ}} {{ディレクトリ/サブディレクトリ/移動先}}`
