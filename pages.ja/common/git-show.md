# git show

> さまざまな種類のGitオブジェクト (コミット、タグなど) を表示する。
> 詳細情報: <https://git-scm.com/docs/git-show>。

- 最新のコミットの情報 (ハッシュ、メッセージ、変更内容、その他のメタデータ) を表示する:

`git show`

- 指定したコミット、タグ、ブランチの情報を表示する (最新のコミットを指す `HEAD` など):

`git show {{コミット|タグ|ブランチ}}`

- 追加、名前変更、削除されたファイルの一覧だけを表示する:

`git show --summary {{コミット}}`

- 行の比較時に空白を無視する:

`git show {{[-w|--ignore-all-space]}}`

- 差分出力を抑制し、コミットメッセージを1行で表示する:

`git show --oneline {{[-s|--no-patch]}} {{コミット}}`

- 変更されたファイルの差分統計 (追加行数や削除行数など) を表示する:

`git show --stat {{コミット}}`

- コミットで変更されたすべてのファイル (修正、追加、削除) の簡易一覧を表示する:

`git show --name-only {{コミット}}`

- ブランチ、タグ、コミットなどで指定したリビジョン時点のファイル内容を表示する:

`git show {{リビジョン}}:{{ディレクトリ/サブディレクトリ/ファイル}}`
