# git apply

> コミットを作成せず、ファイルやインデックスにパッチを適用する。
> 参照: `git am`。
> 詳細情報: <https://git-scm.com/docs/git-apply>。

- パッチを適用したファイルに関するメッセージを表示する:

`git apply {{[-v|--verbose]}} {{ディレクトリ/サブディレクトリ/ファイル}}`

- パッチを適用し、変更したファイルをインデックスに追加する:

`git apply --index {{ディレクトリ/サブディレクトリ/ファイル}}`

- リモートのパッチファイルを適用する:

`curl {{[-L|--location]}} {{https://example.com/file.patch}} | git apply`

- 入力の差分統計を出力してからパッチを適用する:

`git apply --stat --apply {{ディレクトリ/サブディレクトリ/ファイル}}`

- パッチを逆向きに適用する:

`git apply {{[-R|--reverse]}} {{ディレクトリ/サブディレクトリ/ファイル}}`

- 作業ツリーを変更せず、パッチの適用結果をインデックスに保存する:

`git apply --cache {{ディレクトリ/サブディレクトリ/ファイル}}`
