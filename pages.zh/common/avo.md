# avo

> Avo 的官方接口。
> 更多信息：<https://www.avo.app/docs/implementation/cli>。

- 在当前目录初始化工作区：

`avo init`

- 登录 Avo 平台：

`avo login`

- 切换到现有的 Avo 分支：

`avo checkout {{分支名称}}`

- 拉取当前路径的分析包装器：

`avo pull`

- 显示 Avo 实现的状态：

`avo status`

- 解决 Avo 文件中的 Git 冲突：

`avo conflict`

- 在默认 Web 浏览器中打开当前 Avo 工作区：

`avo edit`

- 显示子命令的帮助：

`avo {{子命令}} --help`
