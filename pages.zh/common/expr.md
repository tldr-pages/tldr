# expr

> 计算表达式和操作字符串。
> 更多信息：<https://www.gnu.org/software/coreutils/manual/html_node/expr-invocation.html>。

- 获取特定字符串的长度：

`expr length "{{字符串}}"`

- 获取具有特定长度的子字符串：

`expr substr "{{字符串}}" {{起始位置}} {{长度}}`

- 将特定子字符串与锚定模式匹配：

`expr match "{{字符串}}" '{{模式}}'`

- 获取字符串中特定字符集的第一个字符位置：

`expr index "{{字符串}}" {{字符集}}`

- 计算特定的数学表达式：

`expr {{表达式1}} {{+|-|*|/|%}} {{表达式2}}`

- 如果第一个表达式的值非零且非空则返回它，否则返回第二个：

`expr {{表达式1}} \| {{表达式2}}`

- 如果两个表达式都非零且非空则返回第一个，否则返回零：

`expr {{表达式1}} \& {{表达式2}}`
