# gawk

> GNU 版本的 awk，一种用于处理文件的多功能编程语言。
> 另请参阅：`awk`。
> 更多信息：<https://www.gnu.org/software/gawk/manual/gawk.html>。

- 打印以空格分隔的文件中的第五列（字段）：

`gawk '{print $5}' {{路径/到/文件}}`

- 打印以空格分隔的文件中包含 "foo" 的行的第二列：

`gawk '/{{foo}}/ {print $2}' {{路径/到/文件}}`

- 使用逗号（而不是空格）作为字段分隔符打印每行的最后一列：

`gawk {{[-F|--field-separator]}} ',' '{print $NF}' {{路径/到/文件}}`

- 对文件中第一列的值求和并打印总数：

`gawk '{s+=$1} END {print s}' {{路径/到/文件}}`

- 从第一行开始每隔两行打印一次：

`gawk 'NR%3==1' {{路径/到/文件}}`

- 根据条件打印不同的值：

`gawk '{if ($1 == "foo") print "完全匹配 foo"; else if ($1 ~ "bar") print "部分匹配 bar"; else print "Baz"}' {{路径/到/文件}}`

- 打印第十列值在最小值和最大值之间的所有行：

`gawk '($10 >= {{最小值}} && $10 <= {{最大值}})' {{路径/到/文件}}`

- 使用冒号作为分隔符，打印 UID >=1000 的用户表，带标题和格式化输出（`%-20s` 表示：20 个左对齐字符串字符，`%6s` 表示：6 个右对齐字符串字符）：

`gawk 'BEGIN {FS=":";printf "%-20s %6s %25s\n", "名称", "UID", "Shell"} $4 >= 1000 {printf "%-20s %6d %25s\n", $1, $4, $7}' /etc/passwd`
