# nl

> 为文件或 `stdin` 中的行编号。
> 更多信息：<https://manned.org/nl.1p>。

- 为文件中的非空行编号：

`nl {{路径/到/文件}}`

- 从 `stdin` 读取：

`{{命令}} | nl -`

- 为所有正文行编号（包括空白行），或不为正文行编号：

`nl -b {{a|n}} {{路径/到/文件}}`

- 仅为匹配基本正则表达式（BRE）模式的正文行编号：

`nl -b p'FooBar[0-9]' {{路径/到/文件}}`

- 使用特定的编号增量：

`nl -i {{增量}} {{路径/到/文件}}`

- 指定行编号的格式：右对齐或左对齐，保留或不保留前导零：

`nl -n {{rz|ln|rn}}`

- 指定行编号的宽度（默认为 6）：

`nl -w {{列宽}} {{路径/到/文件}}`

- 使用特定字符串分隔行号和行内容（默认为 `TAB`）：

`nl -s {{分隔符}} {{路径/到/文件}}`
