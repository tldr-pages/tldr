# astyle

> C、C++、C# 和 Java 编程语言的源代码缩进器、格式化器和美化器。
> 运行时，会创建原始文件的副本，并在原始文件名后附加 ".orig"。
> 更多信息：<https://manned.org/astyle>。

- 应用默认样式：每级缩进 4 个空格，无格式更改：

`astyle {{源文件}}`

- 应用 Java 样式，大括号附加：

`astyle {{[-A2|--style=java]}} {{路径/到/文件}}`

- 应用 allman 样式，大括号断开：

`astyle {{[-A1|--style=allman]}} {{路径/到/文件}}`

- 使用自定义空格缩进。选择 2 到 20 个空格：

`astyle {{[-s|--indent=spaces=]}}{{空格数}} {{路径/到/文件}}`

- 使用自定义制表符缩进。选择 2 到 20 个制表符：

`astyle {{[-t|--indent=tab=]}}{{制表符数}} {{路径/到/文件}}`
