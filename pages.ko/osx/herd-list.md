# herd list

> Herd PHP 플랫폼에서 사용 가능한 명령 목록을 표시.
> 더 많은 정보: <https://herd.laravel.com/docs/macos/advanced-usage/herd-cli>.

- 사용 가능한 모든 명령 목록 표시:

`herd list`

- 지정한 네임스페이스에서 사용 가능한 모든 명령 목록 표시:

`herd list {{네임스페이스}}`

- 모든 명령을 원시 형식으로 표시(명령 실행기에 포함할 때 유용):

`herd list --raw`

- 지정한 출력 형식으로 명령 목록 표시:

`herd list --format {{txt|xml|json|md}}`

- 인수에 대한 설명 없이 모든 명령 목록 표시:

`herd list --short`
