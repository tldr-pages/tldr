# tag

> Mac OS X 파일(10.9 Mavericks 이상)의 태그를 편집.
> 더 많은 정보: <https://github.com/jdberry/tag#usage>.

- 파일에 태그 추가:

`tag {{[-a|--add]}} {{태그_이름1,태그_이름2,...}} {{경로/대상/파일}}`

- 파일에서 지정한 태그 제거:

`tag {{[-r|--remove]}} {{태그_이름}} {{경로/대상/파일}}`

- 파일에서 모든 태그 제거:

`tag {{[-r|--remove]}} \* {{경로/대상/파일}}`

- 지정한 태그가 있는 모든 파일 표시:

`tag {{[-m|--match]}} {{태그_이름}}`
