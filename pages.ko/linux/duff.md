# duff

> 중복 파일을 찾는 도구.
> 더 많은 정보: <https://github.com/elmindreda/duff>.

- 디렉터리에서 중복 파일을 재귀적으로 검색:

`duff -r {{경로/대상/디렉터리}}`

- 각 중복 파일 그룹에서 하나를 제외한 나머지 파일 목록 표시:

`duff -er {{경로/대상/디렉터리}}`

- 중복 없는 고유 파일 목록 표시:

`duff -ur {{경로/대상/디렉터리}}`

- SHA-1 대신 SHA-256 사용:

`duff -d sha256 {{경로/대상/디렉터리}}`

- digest 대신 파일을 바이트 단위로 직접 비교:

`duff -t {{경로/대상/디렉터리}}`

- 재귀 검색 시 숨김 파일과 디렉터리를 포함:

`duff -ar {{경로/대상/디렉터리}}`
