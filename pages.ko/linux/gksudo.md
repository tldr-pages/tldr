# gksudo

> `sudo`의 프런트엔드.
> X 터미널 에뮬레이터를 실행하지 않고도 루트 권한이 필요한 그래픽 명령을 실행할 수 있음.
> 참고: 이 명령은 `pkexec` 등의 명령으로 대체되어, 더 이상 유지 관리되지 않음.
> 관련 항목: `gksu`.
> 더 많은 정보: <https://manned.org/gksudo>.

- 지정한 사용자로 명령 실행:

`gksudo {{[-u|--user]}} {{사용자_아이디}} {{명령어}}`

- 현재 환경 변수를 유지한 상태로 명령 실행:

`gksudo {{[-u|--user]}} {{사용자_아이디}} {{[-k|--preserve-env]}} {{명령어}}`

- `su`를 사용하여 `gksu` 명령을 실행:

`gksu {{[-u|--user]}} {{사용자_아이디}} {{[-w|--su-mode]}} {{명령어}}`

- `sudo`를 사용하여 `gksu` 명령을 실행:

`gksudo {{[-u|--user]}} {{사용자_아이디}} {{[-S|--sudo-mode]}} {{명령어}}`

- 지정한 명령의 디버그 정보 출력:

`gksudo {{[-u|--user]}} {{사용자_아이디}} {{[-d|--debug]}} {{명령어}}`
