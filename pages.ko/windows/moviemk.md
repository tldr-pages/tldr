# moviemk

> 비디오를 생성하고 편집.
> 참고: 이 명령은 더 이상 사용되지 않음.
> 더 많은 정보: <https://learn.microsoft.com/previous-versions/windows/desktop/wmmdvdm/command-line-options-for-windows-movie-maker>.

- Windows Movie Maker 실행:

`moviemk`

- 기존 Windows Movie Maker 프로젝트 파일 열기:

`moviemk {{경로\대상\파일.mswmm}}`

- 기존 프로젝트로 새 오디오, 이미지 또는 비디오 파일 가져오기:

`moviemk {{경로\대상\애셋}}`

- Windows Movie Maker 가져오기 파일 목록 XML에 미리 정의된 애셋 가져오기:

`moviemk {{경로\대상\파일.xml}}`
