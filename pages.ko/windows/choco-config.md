# choco config

> Chocolatey 설정 파일의 설정을 관리.
> 더 많은 정보: <https://docs.chocolatey.org/en-us/choco/commands/config/>.

- 모든 설정과 해당 값 표시:

`choco config list`

- 지정한 설정의 값 표시:

`choco config get {{설정_이름}}`

- 지정한 설정의 값 설정:

`choco config set {{설정_이름}} {{값}}`

- 지정한 설정 제거:

`choco config unset {{설정_이름}}`
