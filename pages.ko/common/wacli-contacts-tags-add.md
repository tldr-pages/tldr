# wacli contacts tags add

> WhatsApp 연락처에 태그를 추가.
> 관련 항목: `wacli contacts show`, `wacli contacts search`.
> 더 많은 정보: <https://wacli.sh/contacts.html>.

- 연락처에 태그를 추가:

`wacli contacts tags add {{전화번호}}@s.whatsapp.net {{태그}}`

- 사용자 지정 저장소를 사용해 연락처에 태그를 추가:

`wacli contacts tags add {{전화번호}}@s.whatsapp.net {{태그}} --store {{경로/대상/저장소}}`
