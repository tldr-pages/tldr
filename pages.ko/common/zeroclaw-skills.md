# zeroclaw skills

> ZeroClaw의 사용자 정의 스킬을 관리.
> 더 많은 정보: <https://github.com/zeroclaw-labs/zeroclaw#quick-start>.

- 설치된 스킬 목록 표시:

`zeroclaw skills list`

- GitHub URL에서 스킬 설치:

`zeroclaw skills install https://github.com/{{사용자}}/{{저장소}}`

- 로컬 경로에서 스킬 설치:

`zeroclaw skills install {{경로/대상/스킬}}`

- 설치된 스킬 제거:

`zeroclaw skills remove {{스킬_이름}}`

- 도움말 표시:

`zeroclaw skills {{[-h|--help]}}`
