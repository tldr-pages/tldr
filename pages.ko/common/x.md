# x

> 모듈과 패키지를 관리.
> 더 많은 정보: <https://x-cmd.com>.

- 모듈 사용 (예: path 모듈):

`x {{모듈}}`

- 패키지를 전역으로 설치 (예: jq):

`x env use {{패키지}}`

- 현재 쉘 세션에서 패키지를 임시로 실행:

`x env try {{패키지}}`

- 설치하지 않고 패키지를 직접 실행:

`x {{패키지}}`

- AI 기능을 위한 OpenAI API 키 초기화:

`x openai init`

- 패키지 설치 방법을 확인하고 설치 실행:

`x install`
