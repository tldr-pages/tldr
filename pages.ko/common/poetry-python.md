# poetry-python

> Poetry로 Python 버전 관리.
> 관련 항목: `asdf`.
> 더 많은 정보: <https://python-poetry.org/docs/cli/#python>.

- 지정한 Python 버전 설치:

`poetry python install {{3.13.1}}`

- System 또는 Poetry에서 관리하는 모든 Python 버전 목록 표시:

`poetry python list`

- Poetry에서 관리하는 모든 Python 버전 목록 표시:

`poetry python list --managed`

- Poetry에서 관리하는 지정한 Python 버전 제거 :

`poetry python remove {{3.13.1}}`
