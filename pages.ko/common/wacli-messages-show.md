# wacli messages show

> 지정한 WhatsApp 메시지를 ID를 사용해 표시.
> 관련 항목: `wacli messages list`, `wacli messages context`.
> 더 많은 정보: <https://wacli.sh/messages.html>.

- 지정한 메시지를 JSON 형식으로 표시:

`wacli messages show {{메시지_아이디}} --json`

- 사용자 지정 저장소를 사용해 지정한 메시지 표시:

`wacli messages show {{메시지_아이디}} --json --store {{경로/대상/저장소}}`
