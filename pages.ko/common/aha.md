# aha

> ANSI 이스케이프 시퀀스를 HTML로 변환.
> 더 많은 정보: <https://manned.org/aha>.

- 터미널 출력을 HTML로 변환:

`{{색상_명령어}} | aha > {{경로/대상/출력파일}}.html`

- `stdin` 대신 파일을 입력으로 사용:

`aha -f {{경로/대상/입력파일.txt}} > {{경로/대상/출력파일}}.html`

- 검은색 배경으로 HTML 변환:

`{{색상_명령어}} | aha {{[-b|--black]}} > {{경로/대상/출력파일}}.html`

- 분홍색 배경과 문서 제목을 지정해 HTML 변환:

`{{색상_명령어}} | aha {{[-p|--pink]}} {{[-t|--title]}} "{{title}}" > {{경로/대상/출력파일}}.html`

- HTML 출력에 CSS 파일 추가:

`{{색상_명령어}} | aha {{[-c|--css]}} {{경로/대상/스타일}}.css > {{경로/대상/출력파일}}.html`

- 가로 스크롤을 방지하기 위해 자동 줄바꿈 활성화:

`{{색상_명령어}} | aha {{[-w|--word-wrap]}} > {{경로/대상/출력파일}}.html`

- 도움말 표시:

`aha {{[-h|--help]}}`
