# [[

> 파일 유형을 확인하고 값을 비교.
> 조건이 참이면 종료 상태 0, 거짓이면 1을 반환.
> 더 많은 정보: <https://gnu.org/software/bash/manual/bash.html#index-_005b_005b>.

- 지정한 변수가 문자열 또는 `glob` 패턴과 일치하는지 확인:

`[[ ${{변수}} == "{{문자열}}" ]]`

- 지정한 문자열이 정규 표현식(`regex`) 패턴과 일치하는지 확인:

`[[ ${{변수}} =~ {{패턴}} ]]`

- 지정한 변수가 숫자와 같음([eq]ual)/같지 않음([n]ot [e]qual)/큼([g]reater [t]han)/작음([l]ess [t]han)/크거나 같음([g]reater than or [e]qual)/작거나 같음([l]ess than or [e]qual)인지 확인:

`[[ ${{변수}} -{{eq|ne|gt|lt|ge|le}} {{정수}} ]]`

- 지정한 변수의 값이 비어 있지 않은지([n]on-empty) 확인:

`[[ -n ${{변수}} ]]`

- 지정한 변수의 값이 비어 있는지 확인 (길이가 0,[z]ero):

`[[ -z ${{변수}} ]]`

- 지정한 파일([f]ile)이 존재하는지 확인:

`[[ -f {{경로/대상/파일}} ]]`

- 지정한 디렉터리([d]irectory)가 존재하는지 확인:

`[[ -d {{경로/대상/디렉터리}} ]]`

- 지정한 파일 또는 디렉터리가 존재하는지([e]xists) 확인:

`[[ -e {{경로/대상/파일_또는_디렉터리}} ]]`
