# rcsmerge

> RCS 리비전의 변경 사항을 작업 파일에 병합.
> 관련 항목: `ci`, `co`, `rcs`, `rcsdiff`, `rlog`.
> 더 많은 정보: <https://manned.org/rcsmerge>.

- 두 리비전 간 차이점을 작업 파일에 병합:

`rcsmerge -r{{리비전1}} -r{{리비전2}} {{경로/대상/파일}}`

- 브랜치 리비전의 변경 사항을 작업 파일에 병합:

`rcsmerge -r{{브랜치_리비전}} {{경로/대상/파일}}`

- 메시지 표시 없이 병합 (진단 메시지 표시 하지 않음):

`rcsmerge -q -r{{리비전1}} -r{{리비전2}} {{경로/대상/파일}}`

- 작업 파일을 덮어쓰지 않고 병합 결과를 `stdout`으로 출력:

`rcsmerge -p -r{{리비전1}} -r{{리비전2}} {{경로/대상/파일}}`
