# jj describe

> Update the change description or other metadata.
> 더 많은 정보: <https://docs.jj-vcs.dev/latest/cli-reference/#jj-describe>.

- 현재 변경에 대한 설명 업데이트:

`jj {{[desc|describe]}}`

- 지정한 revset의 변경 섦여 업데이트:

`jj {{[desc|describe]}} {{revsets}}`

- 지정한 메시지로 변경 설명 업데이트:

`jj {{[desc|describe]}} {{[-m|--message]}} {{메시지}}`
