# jj config unset

> 설정 옵션을 제거.
> 관련 항목: `jj config set`.
> 더 많은 정보: <https://docs.jj-vcs.dev/latest/cli-reference/#jj-config-unset>.

- 사용자 수준 설정 파일에서 설정 옵션 제거:

`jj config {{[u|unset]}} --user {{이름}}`

- 저장소 수준 설정 파일에서 설정 옵션 제거:

`jj config {{[u|unset]}} --repo {{이름}}`

- 작업공간 수준 설정 파일에서 설정 옵션 제거:

`jj config {{[u|unset]}} --workspace {{이름}}`
