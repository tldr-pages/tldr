# tdf

> TUI 기반 PDF 뷰어.
> 더 많은 정보: <https://github.com/itsjunetime/tdf>.

- 지정한 PDF 파일 열기:

`tdf {{경로/대상/파일}}.pdf`

- 전체 화면 모드로 PDF 파일 열기:

`tdf {{[-f|--fullscreen]}} {{경로/대상/파일}}.pdf`

- 사용자 지정 흰색 색상 설정:

`tdf {{[-w|--white-color]}} {{ffffff}} {{경로/대상/파일}}.pdf`

- 사용자 지정 검은색 색상 설정:

`tdf {{[-b|--black-color]}} "rgb({{0}}, {{0}}, {{0}})" {{경로/대상/파일}}.pdf`
