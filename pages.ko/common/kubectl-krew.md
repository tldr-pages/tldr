# kubectl krew

> `kubectl`용 플러그인 관리자.
> 관련 항목: `kubectl-plugin`.
> 더 많은 정보: <https://krew.sigs.k8s.io/docs/>.

- 사용 가능한 플러그인 검색:

`kubectl krew search`

- 플러그인 설치:

`kubectl krew install {{플러그인_이름}}`

- 설치된 플러그인 목록 표시:

`kubectl krew list`

- 로컬 플러그인 인덱스 업데이트:

`kubectl krew update`

- 설치된 모든 플러그인 업그레이드:

`kubectl krew upgrade`

- 플러그인 정보 표시:

`kubectl krew info {{플러그인_이름}}`

- 플러그인 삭제:

`kubectl krew uninstall {{플러그인_이름}}`
