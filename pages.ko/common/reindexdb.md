# reindexdb

> PostgreSQL 데이터베이스의 인덱스를 다시 생성.
> 더 많은 정보: <https://www.postgresql.org/docs/current/app-reindexdb.html>.

- 지정한 데이터베이스의 인덱스 다시 생성:

`reindexdb {{데이터베이스_이름}}`

- 연결 옵션을 지정하여 데이터베이스의 인덱스 다시 생성:

`reindexdb {{데이터베이스_이름}} {{[-h|--host]}} {{호스트명}} {{[-p|--port]}} {{포트}} {{[-U|--username]}} {{호스트명}}`

- 모든 데이터베이스의 인덱스 다시 생성:

`reindexdb {{[-a|--all]}}`

- 데이터베이스의 지정한 테이블 인덱스 다시 생성:

`reindexdb {{데이터베이스_이름}} {{[-t|--table]}} {{테이블_이름}}`

- 데이터베이스의 지정한 인덱스 다시 생성:

`reindexdb {{데이터베이스_이름}} {{[-i|--index]}} {{인덱스_이름}}`

- 데이터베이스의 지정한 스키마 인덱스 다시 생성:

`reindexdb {{데이터베이스_이름}} {{[-S|--schema]}} {{스키마_이름}}`

- 자세한 출력을 표시하며 인덱스 다시 생성:

`reindexdb {{데이터베이스_이름}} {{[-v|--verbose]}}`

- 여러 병렬 작업을 사용하여 데이터베이스의 인덱스 다시 생성:

`reindexdb {{데이터베이스_이름}} {{[-j|--jobs]}} {{작업_개수}}`
