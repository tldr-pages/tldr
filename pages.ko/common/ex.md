# ex

> 명령줄 텍스트 편집기.
> 관련 항목: `vim`.
> 더 많은 정보: <https://www.vim.org/>.

- 파일 열기:

`ex {{경로/대상/파일}}`

- [대화형] 저장하고 종료:

`wq`

- [대화형] 마지막 작업 실행 취소:

`undo`

- [대화형] 파일에서 패턴 검색:

`/{{검색_패턴}}`

- [대화형] 전체 파일에서 `regex` 대체를 수행:

`%s/{{정규_표현식}}/{{대체}}/g`

- [대화형] 텍스트 삽입:

`i<Enter>{{텍스트}}<Ctrl c>`

- [대화형] Vim으로 전환:

`visual`
