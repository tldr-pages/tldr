# supabase

> Supabase 프로젝트를 로컬 및 클라우드 환경에서 개발, 배포 및 관리.
> 더 많은 정보: <https://supabase.com/docs/reference/cli>.

- 액세스 토큰을 사용하여 Supabase에 로그인:

`supabase login`

- 현재 디렉터리에 새로운 Supabase 프로젝트 초기화:

`supabase init`

- 로컬 Supabase 개발 스택 시작:

`supabase start`

- 로컬 Supabase 개발 스택 중지:

`supabase stop`

- 로컬 Supabase 개발 스택 상태 표시:

`supabase status`

- 현재 디렉터리를 원격 Supabase 프로젝트에 연결:

`supabase link --project-ref {{프로젝트_아이디}}`

- 모든 Supabase 프로젝트 목록 표시:

`supabase projects list`

- 지정한 쉘의 자동 완성 스크립트 생성:

`supabase completion {{bash|fish|zsh|...}}`
