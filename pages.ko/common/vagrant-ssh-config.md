# vagrant ssh-config

> Vagrant machine에 직접 SSH로 접속하는 데 필요한 설정을 표시 (`vagrant ssh`을 사용하지 않음).
> 관련 항목: `vagrant`.
> 더 많은 정보: <https://developer.hashicorp.com/vagrant/docs/cli/ssh_config>.

- 현재 디렉터리에서 실행 중인 machine의 SSH 설정 표시:

`vagrant ssh-config`

- 이름 또는 ID를 지정하여 machine의 SSH 설정 표시:

`vagrant ssh-config {{이름|id}}`
