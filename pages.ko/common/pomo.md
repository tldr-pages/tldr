# pomo

> Pomodoro 기법을 위한 유틸리티.
> 더 많은 정보: <https://codeberg.org/kevinschoon/pomo>.

- pomo 데이터베이스 초기화:

`pomo init`

- pomodoro 세션 시작:

`pomo start {{메시지}}`

- 각각 3초 동안 진행되는 3개의 pomodoro 세션 시작:

`pomo start --duration 3s --pomodoros 3 {{메시지}}`

- 이전 작업 목록 표시:

`pomo list`

- 도움말 표시:

`pomo --help`
