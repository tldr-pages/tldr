# doctl completion

> 지정한 쉘에서 사용할 `doctl` 자동완성 스크립트를 생성.
> 더 많은 정보: <https://docs.digitalocean.com/reference/doctl/reference/completion/>.

- Bash용 자동 완성 스크립트 생성:

`doctl completion bash`

- fish용 자동 완성 스크립트 생성:

`doctl completion fish`

- PowerShell용 자동 완성 스크립트 생성:

`doctl completion powershell`

- Zsh용 자동 완성 스크립트 생성:

`doctl completion zsh`
