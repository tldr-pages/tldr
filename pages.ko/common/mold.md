# mold

> GNU `ld`를 대체할 수 있는 더 빠른 최신 링커.
> 관련 항목: `ld`.
> 더 많은 정보: <https://github.com/rui314/mold/blob/main/docs/mold.md>.

- `ld` 대신 `mold`를 사용하여 `make`, `ninja`, `cargo`와 같은 빌드 명령 실행:

`mold --run {{명령어}} {{인자...}}`

- 오브젝트 파일들을 실행 파일로 링크:

`mold {{경로/대상/파일1.o 경로/대상/파일2.o ...}} {{[-o|--output]}} {{경로/대상/출력_실행파일}}`

- 오브젝트 파일들을 공유 라이브러리로 링크:

`mold --shared {{경로/대상/파일1.o 경로/대상/파일2.o ...}} {{[-o|--output]}} {{경로/대상/라이브러리.so}}`

- 특정 디렉터리에 위치한 라이브러리와 오브젝트 파일 링크:

`mold {{경로/대상/파일.o}} {{[-L|--library-path]}} {{경로/대상/라이브러리_디렉터리}} -l{{라이브러리_이름}}`

- 각 심볼에 대해 어떤 입력 파일이 다른 파일에 의존하는지 출력:

`mold --print-dependencies {{경로/대상/파일1.o 경로/대상/파일2.o ...}} {{[-o|--output]}} {{경로/대상/출력_실행파일}}`
