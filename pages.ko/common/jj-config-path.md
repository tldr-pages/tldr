# jj config path

> 설정 파일의 경로를 출력.
> 관련 항목: `jj config edit`.
> 더 많은 정보: <https://docs.jj-vcs.dev/latest/cli-reference/#jj-config-path>.

- 사용자 수준 설정 파일 경로 출력:

`jj config {{[p|path]}} --user`

- 저장소 수준 설정 파일 경로 출력:

`jj config {{[p|path]}} --repo`

- 작업공간 수준 설정 파일 경로 출력:

`jj config {{[p|path]}} --workspace`
