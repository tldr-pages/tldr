# timg

> 터미널에서 이미지와 비디오를 표시하는 뷰어.
> 더 많은 정보: <https://github.com/hzeller/timg#synopsis>.

- 정적 이미지 표시:

`timg {{이미지.jpg}}`

- 현재 디렉터리의 모든 JPEG 이미지 표시:

`timg *.jpg`

- 아이콘 파일에 포함된 모든 비트맵 표시:

`timg {{예시.ico}}`

- 비디오 재생:

`timg {{비디오.mp4}}`

- 웹캠 영상 재생:

`timg {{/dev/videoX}}`

- 애니메이션 GIF 재생:

`timg {{gif.gif}}`

- 버전 정보 표시:

`timg --version`
