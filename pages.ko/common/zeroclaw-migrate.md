# zeroclaw migrate

> 다른 에이전트 런타임의 데이터를 ZeroClaw로 마이그레이션.
> 더 많은 정보: <https://github.com/zeroclaw-labs/zeroclaw#quick-start>.

- 데이터를 실제로 기록하지 않고 OpenClaw에서 마이그레이션 시뮬레이션:

`zeroclaw migrate openclaw --dry-run`

- OpenClaw 워크스페이스의 메모리 마이그레이션:

`zeroclaw migrate openclaw`

- 도움말 표시:

`zeroclaw migrate {{[-h|--help]}}`
