# deno fmt

> 소스 파일의 형식을 정리.
> 더 많은 정보: <https://docs.deno.com/runtime/reference/cli/fmt/>.

- 현재 디렉터리에서 지원되는 모든 파일을 재귀적으로 포맷:

`deno fmt`

- 지정한 파일 또는 디렉터리 포맷:

`deno fmt {{경로/대상/파일_또는_디렉터리1 경로/대상/파일_또는_디렉터리2 ...}}`

- 파일을 수정하지 않고 포맷 검사:

`deno fmt --check {{경로/대상/파일_또는_디렉터리}}`

- 파일 변경 사항을 감시하고 자동으로 포맷:

`deno fmt --watch {{경로/대상/파일_또는_디렉터리}}`

- 지정한 디렉터리를 제외하고 파일 포맷:

`deno fmt --ignore={{경로/대상/제외된_디렉터리}} {{경로/대상/디렉터리}}`

- `stdin`에서 코드를 읽어 포맷하고 결과를 `stdout`에 출력:

`echo "{{마크다운_텍스트}}" | deno fmt --ext {{md}} -`
