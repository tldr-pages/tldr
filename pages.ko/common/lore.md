# lore

> Epic Games에서 개발한 버전 관리 시스템.
> 코드와 대용량 바이너리 자산을 함께 다루는 프로젝트에 최적화됨.
> 더 많은 정보: <https://github.com/EpicGames/lore/blob/main/docs/reference/lore-cli-commands.md>.

- 기존 저장소 복제:

`lore clone {{https://example.com/path/to/repository}}`

- 작업 디렉터리 및 스테이징 영역의 상태 표시:

`lore status`

- 지정한 메시지로 변경 사항 커밋:

`lore commit "{{메시지}}"`

- 새로운 브랜치 생성:

`lore branch create {{브랜치_이름}}`

- 저장소 전용 서비스 시작:

`lore service start`

- 도움말 표시:

`lore help`

- 버전 정보 표시:

`lore --version`
