# wlsunset

> 일몰/일출 시간에 따라 Wayland 컴포지터의 색 온도를 조정.
> 더 많은 정보: <https://manned.org/wlsunset>.

- 지정한 위치를 기준으로 일몰 및 일출 시간 자동 계산:

`wlsunset -l {{위도}} -L {{경도}}`

- 일몰/일출 시간 직접 설정 (time format: `HH:MM`):

`wlsunset -s {{일몰_시간}} -S {{일출_시간}}`

- 주간 및 야간 색온도 설정 (기본값: 주간 - 6500, 야간 - 4000):

`wlsunset -T {{주간_온도}} -t {{야간_온도}}`

- 전환 애니메이션 시간을 `n`초로 설정 (일몰/일출 시간을 직접 지정한 경우에만 적용):

`wlsunset -d {{n}} -s {{일몰_시간}} -S {{일출_시간}}`

- 감마 값 설정 (기본값: 1.0):

`wlsunset -g {{감마_값}}`
