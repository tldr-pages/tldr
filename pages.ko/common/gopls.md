# gopls

> 공식적인 Go 언어 서버.
> 더 많은 정보: <https://go.dev/gopls/>.

- 언어 서버 시작:

`gopls serve`

- 하나 이상의 파일에 대한 진단 정보 표시:

`gopls check {{경로/대상/파일1.go 경로/대상/파일2.go ...}}`

- 하나 이상의 파일을 포맷하고 변경 사항을 파일에 적용:

`gopls format {{[-w|-write]}} {{경로/대상/파일1.go 경로/대상/파일2.go ...}}`

- 파일에서 누락된 import를 추가하고 사용하지 않는 import를 제거한 후 변경 사항 적용:

`gopls imports {{[-w|-write]}} {{경로/대상/파일.go}}`

- 지정한 줄과 열에 있는 식별자의 정의 표시:

`gopls definition {{경로/대상/파일.go}}:{{줄}}:{{컬럼}}`

- 지정한 줄과 열에 있는 식별자의 모든 참조 목록 표시:

`gopls references {{경로/대상/파일.go}}:{{줄}}:{{컬럼}}`

- 지정한 줄과 열에 있는 식별자의 이름을 변경하고 영향을 받는 파일에 변경 사항 적용:

`gopls rename {{[-w|-write]}} {{경로/대상/파일.go}}:{{줄}}:{{컬럼}} {{새로운_이름}}`

- 버전 정보 표시:

`gopls version`
