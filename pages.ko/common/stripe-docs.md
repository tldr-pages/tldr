# stripe docs

> 터미널에서 <https://docs.stripe.com>을 탐색.
> 더 많은 정보: <https://docs.stripe.com/cli/docs>.

- 경로별 문서 페이지 읽기:

`stripe docs {{/payments}}`

- 리소스 이름별 API 참조 페이지 읽기:

`stripe docs api {{product}}`

- HTTP 메서드 및 경로별 API 참조 페이지 읽기:

`stripe docs api {{GET /v1/products}}`

- 웹훅 이벤트에 대한 API 참조 페이지 읽기:

`stripe docs api {{product.created}}`

- 키워드로 문서 검색:

`stripe docs search "{{payment intents}}"`
