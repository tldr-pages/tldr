# pulumi whoami

> 현재 로그인한 사용자 정보를 출력.
> 더 많은 정보: <https://www.pulumi.com/docs/iac/cli/commands/pulumi_whoami/>.

- 현재 로그인한 사용자 이름 출력:

`pulumi whoami`

- 현재 로그인한 사용자의 상세 정보 출력:

`pulumi whoami {{[-v|--verbose]}}`

- 현재 로그인한 사용자의 상세 정보를 JSON 형식으로 출력:

`pulumi whoami {{[-j|--json]}}`

- 도움말 표시:

`pulumi whoami {{[-h|--help]}}`
