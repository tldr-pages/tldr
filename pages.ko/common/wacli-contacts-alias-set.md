# wacli contacts alias set

> WhatsApp 연락처에 사용자 지정 별칭 설정.
> 관련 항목: `wacli contacts show`, `wacli contacts search`.
> 더 많은 정보: <https://wacli.sh/contacts.html>.

- 지정한 연락처에 별칭 설정:

`wacli contacts alias set {{전화번호}}@s.whatsapp.net {{별칭}}`

- 사용자 지정 저장소를 사용하여 연락처에 별칭 설정:

`wacli contacts alias set {{전화번호}}@s.whatsapp.net {{별칭}} --store {{경로/대상/저장소}}`
