# zapier validate

> Zapier 통합의 유효성 검사.
> 더 많은 정보: <https://github.com/zapier/zapier-platform/blob/main/packages/cli/docs/cli.md#validate>.

- 통합 유효성 검사:

`zapier validate`

- 스타일 검사 없이 통합 유효성 검사:

`zapier validate --without-style`

- 빌드 스크립트를 실행하지 않고 통합 유효성 검사:

`zapier validate --skip-build`

- 추가 디버그 출력과 함께 통합 유효성 검사:

`zapier validate {{[-d|--debug]}}`

- 다른 출력 형식으로 통합 유효성 검사 결과 표시:

`zapier validate {{[-f|--format]}} {{plain|json|raw|row|table}}`
