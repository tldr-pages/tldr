# yek

> 저장소 또는 디렉터리를 LLM이 처리하기 쉬운 하나의 파일로 직렬화 (빠른 Rust 기반 저장소 매퍼).
> 더 많은 정보: <https://github.com/bodo-run/yek#usage>.

- 현재 디렉터리를 직렬화하여 임시 파일에 저장 (해당 경로 출력):

`yek`

- 지정한 여러 디렉터리를 직렬화하여, 출력 디렉터리에 저장:

`yek {{경로/대상/디렉터리1 경로/대상/디렉터리2 ...}} --output-dir {{경로/대상/출력_디렉터리}}`

- 여러 파일 또는 glob 패턴을 사용하여 처리 (쉘 확장을 방지하려면 glob 패턴을 따옴표로 감쌈):

`yek "{{경로/대상/디렉터리/**/*.rs}}" "{{경로/대상/디렉터리/**/*.md}}"`

- 토큰 기준 최대 출력 크기를 128k 토큰으로 제한:

`yek {{경로/대상/디렉터리}} --tokens 128k`

- 바이트 기준 최대 출력 크기와 출력 파일 이름 지정:

`yek {{경로/대상/디렉터리}} --max-size {{100KB}} --output-name {{yek-output.txt}}`

- JSON 형식으로 스트리밍 출력:

`yek {{경로/대상/디렉터리}} --json`

- 출력에 디렉터리 트리 헤더 포함:

`yek {{경로/대상/디렉터리}} --tree-header`
