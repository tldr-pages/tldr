# zstyle

> Zsh에서 설정 스타일을 정의하고 조회.
> 이 내장 명령은 `zsh/zutil` 모듈의 일부.
> 더 많은 정보: <https://zsh.sourceforge.io/Doc/Release/Zsh-Modules.html>.

- 정의된 모든 스타일 목록 표시:

`zstyle`

- 바로 붙여넣어 사용 가능한 `zstyle` 명령 형식으로 스타일 목록 표시:

`zstyle -L`

- 지정한 패턴에 대한 스타일 정의:

`zstyle {{패턴}} {{스타일}} {{값1 값2 ...}}`

- 지정한 패턴의 스타일 삭제:

`zstyle -d {{패턴}}`

- 스타일 값을 문자열로 가져와 변수에 저장:

`zstyle -s {{컨텍스트}} {{스타일}} {{변수_이름}}`

- 스타일 값을 불리언 값으로 가져와 변수에 저장:

`zstyle -b {{컨텍스트}} {{스타일}} {{변수_이름}}`

- 스타일 값을 배열로 가져와 변수에 저장:

`zstyle -a {{컨텍스트}} {{스타일}} {{변수_이름}}`
