# x8

> 취약하거나 흥미로운 웹 파라미터를 식별하기 위한 숨겨진 파라미터 탐지 도구 모음.
> 더 많은 정보: <https://github.com/Sh1Yo/x8/blob/main/docs.md>.

- URL 쿼리에서 숨겨진 파라미터 탐지:

`x8 {{[-u|--url]}} {{https://example.com/}} {{[-w|--wordlist]}} {{경로/대상/단어리스트.txt}}`

- 사용자 지정 쿼리 삽입 지점 (`%s`)을 사용하여 파라미터 탐지:

`x8 {{[-u|--url]}} {{https://example.com/?something=1%26%s}} {{[-w|--wordlist]}} {{경로/대상/단어리스트.txt}}`

- JSON 형식의 POST 본문을 통해 파라미터 전송:

`x8 {{[-u|--url]}} {{https://example.com/}} {{[-X|--method]}} {{POST}} {{[-b|--body]}} '{{{"x":{%s\}\}}}' {{[-w|--wordlist]}} {{경로/대상/단어리스트.txt}}`

- 사용자 지정 템플릿 (`%k`: 키, `%v`: 값)을 사용해 파라미터 탐지:

`x8 {{[-u|--url]}} {{https://example.com/}} {{[-P|--param-template]}} {{user[%k]=%v}} {{[-w|--wordlist]}} {{경로/대상/단어리스트.txt}}`

- 쿼리의 특수 문자를 처리할 수 있도록 파라미터를 인코딩하여 탐지:

`x8 {{[-u|--url]}} {{https://example.com/?path=..%2faction.php%3f%s%23}} --encode {{[-w|--wordlist]}} {{경로/대상/단어리스트.txt}}`

- URL의 숨겨진 헤더 탐지:

`x8 {{[-u|--url]}} {{https://example.com/}} --headers {{[-w|--wordlist]}} {{경로/대상/헤더.txt}}`

- 높은 동시성으로 여러 URL을 병렬 검사하고 발견된 파라미터 검증:

`x8 {{[-u|--url]}} {{https://example.com/}} {{https://4rt.one/}} {{[-W|--workers]}} {{0}} -c {{3}} --verify`

- 발견된 파라미터의 요청 및 응답 데이터를 지정한 디렉터리에 저장:

`x8 {{[-u|--url]}} {{https://example.com/}} {{[-w|--wordlist]}} {{경로/대상/단어리스트.txt}} --save-responses {{경로/대상/출력_디렉터리}}`
