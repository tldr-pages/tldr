# jj git remote

> Git 원격 저장소 관리.
> 더 많은 정보: <https://docs.jj-vcs.dev/latest/cli-reference/#jj-git-remote>.

- 모든 Git 원격 저장소 목록 표시:

`jj git remote list`

- Git 원격 저장소 추가:

`jj git remote add {{원격_저장소}} {{주소}}`

- Git 원격 저장소의 URL 변경:

`jj git remote set-url {{원격_저장소}} {{주소}}`

- Git 원격 저장소 제거:

`jj git remote remove {{원격_저장소}}`

- Git 원격 저장소 이름 변경:

`jj git remote rename {{오래된_이름}} {{새로운_이름}}`
