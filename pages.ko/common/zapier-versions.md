# zapier versions

> Zapier 통합의 버전 목록 표시.
> 더 많은 정보: <https://github.com/zapier/zapier-platform/blob/main/packages/cli/docs/cli.md#validate>.

- 통합의 버전 목록 표시:

`zapier versions`

- 사용 중단된 버전도 포함하여 표시:

`zapier versions {{[-a|--all]}}`

- 추가 디버그 출력 표시:

`zapier versions {{[-d|--debug]}}`

- 다른 출력 형식으로 버전 목록 표시:

`zapier versions {{[-f|--format]}} {{plain|json|raw|row|table}}`
