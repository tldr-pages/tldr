# rdp_check.py

> RDP 프로토콜을 사용하여 대상 호스트에서 계정 자격 증명이 유효한지 확인 (전체 로그인 수행 없이, 인증 여부만 검사).
> Impacket 도구의 일부.
> 더 많은 정보: <https://github.com/fortra/impacket>.

- 대상 호스트에서 자격 증명이 유효한지 확인 (비밀번호를 생략하면 입력 요청):

`rdp_check.py {{도메인}}/{{사용자명}}@{{대상}}`

- NTLM 해시를 사용해 자격 증명 확인:

`rdp_check.py -hashes {{LM_해시}}:{{NT_해시}} {{도메인}}/{{사용자명}}@{{대상}}`

- 비밀번호를 명시적으로 지정해 자격 증명 확인:

`rdp_check.py {{도메인}}/{{사용자명}}:{{비밀번호}}@{{대상}}`

- 대상 호스트의 로컬 계정 자격 증명 확인 (도메인 없이):

`rdp_check.py {{사용자명}}:{{비밀번호}}@{{대상}}`
