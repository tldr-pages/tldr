# cron

> Penjadwal sistem untuk menjalankan pekerjaan atau tugas tanpa pengawasan.
> Perintah untuk membuat, menyunting, atau menghapus entri tugas `cron` adalah `crontab`.
> Informasi lebih lanjut: <https://manned.org/cron>.

- Tampilkan dokumentasi untuk mengatur entri tugas `cron`:

`tldr crontab`
