# docker image tag

> Tandai citra-citra Docker saat ini dengan kumpulan tag.
> Informasi lebih lanjut: <https://docs.docker.com/reference/cli/docker/image/tag/>.

- Pasang suatu nama dan tag terhadap citra dengan ID tertentu:

`docker {{[tag|image tag]}} {{id_citra}} {{nama}}:{{tag}}`

- Pasang suatu tag ke dalam suatu citra:

`docker {{[tag|image tag]}} {{citra}}:{{tag_saat_ini}} {{citra}}:{{tag_baru}}`

- Tampilkan bantuan:

`docker {{[tag|image tag]}}`
