# python

> पायथन भाषा इंटरप्रेटर।
> अधिक जानकारी: <https://docs.python.org/using/cmdline.html>।

- एक REPL (इंटरैक्टिव शेल) शुरू करें:

`python`

- एक विशिष्ट पायथन फ़ाइल निष्पादित करें:

`python {{फ़ाइल.py/का/पथ}}`

- एक विशिष्ट पायथन फ़ाइल निष्पादित करें और फिर REPL शुरू करें:

`python -i {{फ़ाइल.py/का/पथ}}`

- एक पायथन एक्सप्रेशन निष्पादित करें:

`python -c "{{एक्सप्रेशन}}"`

- निर्दिष्ट लाइब्रेरी मॉड्यूल की स्क्रिप्ट चलाएं:

`python -m {{मॉड्यूल}} {{तर्क}}`

- `pip` का उपयोग करके एक पैकेज स्थापित करें:

`python -m pip install {{पैकेज}}`

- एक पायथन स्क्रिप्ट को इंटरैक्टिव रूप से डीबग करें:

`python -m pdb {{फ़ाइल.py/का/पथ}}`

- वर्तमान निर्देशिका में पोर्ट 8000 पर अंतर्निहित HTTP सर्वर शुरू करें:

`python -m http.server`
