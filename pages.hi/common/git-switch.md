# git switch

> एक गिट शाखा से दूसरी शाखा पर जाएँ। इसके लिए गिट 2.23 या बाद का संस्करण चाहिए।
> यह भी देखें: `git checkout`।
> अधिक जानकारी: <https://git-scm.com/docs/git-switch>।

- किसी मौजूदा शाखा पर जाएँ:

`git switch {{शाखा_का_नाम}}`

- नई शाखा बनाएँ और उसी पर जाएँ:

`git switch {{[-c|--create]}} {{शाखा_का_नाम}}`

- किसी खास कमिट से नई शाखा बनाएँ और उस शाखा पर जाएँ:

`git switch {{[-c|--create]}} {{शाखा_का_नाम}} {{कमिट}}`

- जिस शाखा पर आप इससे पहले थे, उस पर लौटें:

`git switch -`

- दूसरी शाखा पर जाएँ और सबमॉड्यूल को उस शाखा में दर्ज कमिट पर लाएँ:

`git switch --recurse-submodules {{शाखा_का_नाम}}`

- दूसरी शाखा पर जाएँ और मौजूदा शाखा के ऐसे स्थानीय बदलावों को अपने आप उस शाखा में मर्ज करें जिन्हें अभी कमिट नहीं किया गया है:

`git switch {{[-m|--merge]}} {{शाखा_का_नाम}}`

- किसी शाखा पर जाए बिना किसी टैग या कमिट को चेकआउट करें:

`git switch {{[-d|--detach]}} {{टैग|कमिट}}`

- किसी रिमोट शाखा को ट्रैक करने वाली स्थानीय शाखा बनाएँ और उस पर जाएँ:

`git switch {{[-t|--track]}} {{रिमोट_का_नाम}}/{{शाखा}}`
