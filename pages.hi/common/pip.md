# pip

> पायथन पैकेज प्रबंधक।
> कुछ उप-आदेशों, जैसे कि `install`, के अपने उपयोग प्रलेखन हैं।
> अधिक जानकारी: <https://pip.pypa.io/en/stable/cli/pip/>।

- एक पैकेज स्थापित करें (स्थापना के और उदाहरणों के लिए `pip install` देखें):

`pip install {{पैकेज}}`

- सिस्टम-व्यापी डिफ़ॉल्ट स्थान के बजाय उपयोगकर्ता की निर्देशिका में पैकेज स्थापित करें:

`pip install --user {{पैकेज}}`

- एक पैकेज अपग्रेड करें:

`pip install {{[-U|--upgrade]}} {{पैकेज}}`

- एक पैकेज अनइंस्टॉल करें:

`pip uninstall {{पैकेज}}`

- स्थापित पैकेजों को एक फ़ाइल में सहेजें:

`pip freeze >{{requirements.txt}}`

- स्थापित पैकेजों की सूची दिखाएं:

`pip list`

- स्थापित पैकेज की जानकारी दिखाएं:

`pip show {{पैकेज}}`

- एक फ़ाइल से पैकेज स्थापित करें:

`pip install {{[-r|--requirement]}} {{requirements.txt}}`
