# conda

> किसी भी प्रोग्रामिंग भाषा के लिए पैकेज, निर्भरता और परिवेश प्रबंधन।
> कुछ उप-आदेशों, जैसे कि `create`, के अपने उपयोग प्रलेखन हैं।
> यह भी देखें: `mamba`।
> अधिक जानकारी: <https://docs.conda.io/projects/conda/en/latest/commands/index.html>।

- एक नया परिवेश बनाएं और उसमें निर्दिष्ट पैकेज स्थापित करें:

`conda create {{[-n|--name]}} {{परिवेश_नाम}} {{python=3.9 matplotlib}}`

- सभी परिवेशों की सूची दिखाएं:

`conda info {{[-e|--envs]}}`

- एक परिवेश सक्रिय करें:

`conda activate {{परिवेश_नाम}}`

- एक परिवेश निष्क्रिय करें:

`conda deactivate`

- एक परिवेश हटाएं (सभी पैकेज हटा दें):

`conda remove {{[-n|--name]}} {{परिवेश_नाम}} --all`

- वर्तमान परिवेश में पैकेज स्थापित करें:

`conda install {{python=3.4 numpy}}`

- वर्तमान परिवेश में स्थापित पैकेजों की सूची दिखाएं:

`conda list`

- अप्रयुक्त पैकेज और कैश हटाएं:

`conda clean {{[-a|--all]}}`
