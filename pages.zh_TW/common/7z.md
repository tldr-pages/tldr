# 7z

> 一個高壓縮率的檔案封存器。
> 更多資訊：<https://manned.org/7z>。

- 封存一個檔案或目錄：

`7z a {{封存檔案.7z}} {{檔案或目錄}}`

- 對已存在的封存檔案加密（包含檔名）：

`7z a {{加密檔案.7z}} -p{{密碼}} -mhe=on {{封存檔案.7z}}`

- 解壓縮一個已存在的 7z 檔案，並保持原來的目錄結構：

`7z x {{封存檔案.7z}}`

- 解壓縮一個封存檔案到指定的輸出目錄：

`7z x {{封存檔案.7z}} -o{{輸出目錄}}`

- 解壓縮一個封存檔案到標準輸出：

`7z x {{封存檔案.7z}} -so`

- 使用指定的類型來封存檔案：

`7z a -t{{7z|bzip2|gzip|lzip|tar|zip}} {{封存檔案}} {{檔案或目錄}}`

- 列出一個封存檔案的內容：

`7z l {{封存檔案.7z}}`

- 設定壓縮等級（數字越高表示壓縮越多，但速度越慢）：

`7z a {{封存檔案.7z}} -mx={{0|1|3|5|7|9}} {{檔案或目錄}}`
