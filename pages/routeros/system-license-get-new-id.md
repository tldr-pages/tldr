# system license get-new-id

> Generate a new system ID to activate RouterOS for Cloud Hosted Router (CHR).
> Note: This command may override, deactivate, and/or remove your current MikroTik RouterOS license, so please proceed cautiously.
> More information: <https://manual.mikrotik.com/docs/cli-reference/system/license/generate-new-id/>.

- Generate a new system ID:

`/system/license/generate-new-id`
