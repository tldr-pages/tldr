# clock

> Set the system clock.
> More information: <https://www.cisco.com/c/en/us/td/docs/ios/fundamentals/command/reference/cf_book/cf_c1.html#clock>.

- Set the current date and time:

`clock set {{23}}:{{59}}:{{59}} {{30}} {{april}} {{2000}}`

- Display the current system date and time:

`show clock`

- Display the current system date and time, along with the source of the time:

`show clock detail`
