# jj workspace root

> Show the root directory of a Jujutsu workspace.
> See also: `jj workspace`, `jj git root`.
> More information: <https://docs.jj-vcs.dev/latest/cli-reference/#jj-workspace-root>.

- Print the root directory of the current workspace:

`jj workspace root`

- Print the root directory of a specific workspace:

`jj workspace root --name {{workspace_name}}`
