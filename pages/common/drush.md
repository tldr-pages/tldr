# drush

> Shell and scripting interface for Drupal.
> More information: <https://www.drush.org/latest/usage/>.

- Enable a module:

`drush en {{module_name}}`

- Uninstall a module:

`drush pmu {{module_name}}`

- Clear all caches:

`drush cr`

- Clear CSS and JavaScript caches:

`drush cc css-js`
