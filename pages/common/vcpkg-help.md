# vcpkg-help

> Display help for a specific vcpkg command or conceptual topic.
> More information: <https://learn.microsoft.com/en-us/vcpkg/commands/help>.

- List all available help topics:

`vcpkg help topics`

- List all vcpkg commands with a short synopsis:

`vcpkg help commands`

- Show the help page for a specific command, such as `install`:

`vcpkg help {{command}}`

- Show the help page for a conceptual topic, such as `triplet` or `binarycaching`:

`vcpkg help {{topic}}`
