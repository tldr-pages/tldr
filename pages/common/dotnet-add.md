# dotnet add

> Add package or project references to a .NET project.
> In .NET 10 and later, use `dotnet package add` or `dotnet reference add`.
> See also: `dotnet package add`, `dotnet reference add`.
> More information: <https://learn.microsoft.com/dotnet/core/tools/dotnet>.

- View documentation for adding package references:

`tldr dotnet package add`

- View documentation for adding project references:

`tldr dotnet reference add`

- Display help:

`dotnet add --help`
