# jj git import

> Update the Jujutsu repository with changes made in the underlying Git repository.
> In colocated workspaces, import happens automatically.
> See also: `jj git export`.
> More information: <https://docs.jj-vcs.dev/latest/cli-reference/#jj-git-import>.

- Import changes from the underlying Git repository:

`jj git import`

- Forcibly import changes in a colocated workspace:

`jj git import --ignore-working-copy`
