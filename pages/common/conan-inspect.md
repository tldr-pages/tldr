# conan inspect

> Print the public fields of a conanfile.py recipe.
> More information: <https://docs.conan.io/2/reference/commands/inspect.html>.

- Inspect the recipe in the current directory:

`conan inspect`

- Inspect a recipe from a specific folder and print the result as JSON:

`conan inspect {{path/to/recipe_folder}} --format=json`

- Inspect a recipe from a specific folder:

`conan inspect {{path/to/recipe_folder}}`
