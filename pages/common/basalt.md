# basalt

> Terminal user interface (TUI) application to manage Obsidian vaults and notes.
> More information: <https://basalt.page>.

- Open Basalt and select a vault from the vault selector:

`basalt`

- Open a specific note file:

`basalt {{path/to/note.md}}`

- Open Basalt with a specific theme:

`basalt --theme {{theme_name}}`

- Display version:

`basalt --version`

- Display help:

`basalt --help`
