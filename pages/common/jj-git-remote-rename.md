# jj git remote rename

> Rename a Git remote.
> See also: `jj git remote add`, `jj git remote list`, `jj git remote remove`, `jj git remote set-url`.
> More information: <https://docs.jj-vcs.dev/latest/cli-reference/#jj-git-remote-rename>.

- Rename an existing Git remote:

`jj git remote rename {{old_name}} {{new_name}}`
