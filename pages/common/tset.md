# tset

> Initialize or reset terminal state.
> More information: <https://manned.org/tset>.

- Initialize the terminal:

`tset`

- Set control characters and modes:

`tset -c`

- Print the terminal type to the (`stderr`) output:

`tset -r`

- Print shell commands to set the environment:

`tset -s`

- Resize the terminal window to the detected size:

`tset -w`
