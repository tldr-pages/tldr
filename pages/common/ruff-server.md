# ruff server

> Run the Ruff Language Server (LSP) for editor integrations.
> More information: <https://docs.astral.sh/ruff/editors/>.

- Start the language server over standard input and output:
  `ruff server`

- Start the server with preview features enabled:
  `ruff server --preview`

- Run the server in quiet mode, suppressing non-essential log messages:
  `ruff server --quiet`
