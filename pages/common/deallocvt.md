# deallocvt

> Deallocate unused virtual consoles.
> More information: <https://manned.org/deallocvt>.

- Free all unused consoles:

`deallocvt`

- Display version:

`deallocvt {{[-V|--version]}}`

- Display help:

`deallocvt {{[-h|--help]}}`

- Deallocate a specific console:

`deallocvt {{[-C|--console]}} {{/dev/ttyN}}`
