# deallocvt

> Deallocate unused virtual consoles.
> More information: <https://manned.org/deallocvt>.

- Free all unused consoles:

`deallocvt`

- Print version number:

`deallocvt {{[-V|--version]}}`

- Print this usage message:

`deallocvt {{[-h|--help]}}`

- Specify the console device to use:

`deallocvt {{[-C|--console]}}`
