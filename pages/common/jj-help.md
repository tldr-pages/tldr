# jj help

> Display help information for `jj` or a specific subcommand.
> More information: <https://docs.jj-vcs.dev/latest/cli-reference/#jj-help>.

- Display help for `jj`:

`jj help`

- Display help for a specific subcommand:

`jj help {{subcommand}}`

- Display help for a nested subcommand:

`jj help {{subcommand}} {{sub_subcommand}}`

- Display help for a keyword (e.g. `bookmarks`, `config`, `filesets`, `revsets`, `templates`, etc.):

`jj help {{[-k|--keyword]}} {{keyword}}`
