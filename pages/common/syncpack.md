# syncpack

> Manage and enforce consistent dependency versions across JavaScript monorepos.
> More information: <https://jamiemason.github.io/syncpack/>.

- List all mismatched dependency versions across the monorepo:

`syncpack list-mismatches`

- Automatically fix mismatched dependency versions across all packages:

`syncpack fix-mismatches`

- Format and sort all package manifests consistently:

`syncpack format`

- Check if all package manifests satisfy version and formatting rules:

`syncpack lint`
