# size-limit

> Calculate the real cost to run a JavaScript library or application and enforce size budgets.
> More information: <https://github.com/ai/size-limit>.

- Check the bundle size against the limits configured in `package.json` or `.size-limit.json`:

`size-limit`

- Analyze and visualize the bundle composition to see why it is a given size:

`size-limit --why`

- Output the size analysis results in JSON format:

`size-limit --json`
