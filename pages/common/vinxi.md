# vinxi

> Full-stack JavaScript and TypeScript application server and bundler toolkit powered by Vite and Nitro.
> More information: <https://vinxi.vercel.app/>.

- Start the development server for the current application:

`vinxi dev`

- Build the application for production deployment:

`vinxi build`

- Start the production server after building:

`vinxi start`

- Display version and environment diagnostics:

`vinxi info`
