# jj git remote add

> Add a Git remote.
> See also: `jj git remote list`, `jj git remote remove`, `jj git remote rename`, `jj git remote set-url`.
> More information: <https://docs.jj-vcs.dev/latest/cli-reference/#jj-git-remote-add>.

- Add a Git remote by name and URL:

`jj git remote add {{remote_name}} {{remote_url}}`

- Add a Git remote with a specific push URL:

`jj git remote add --push-url {{push_url}} {{remote_name}} {{remote_url}}`
