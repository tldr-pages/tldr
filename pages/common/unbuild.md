# unbuild

> A unified JavaScript and TypeScript build system powered by Rollup and Jiti.
> More information: <https://github.com/unjs/unbuild>.

- Build the package in the current working directory using `package.json` or `build.config.ts`:

`unbuild`

- Generate stub files for rapid local development without re-bundling on every change:

`unbuild --stub`

- Build a package located in a specific directory:

`unbuild {{path/to/package_directory}}`
