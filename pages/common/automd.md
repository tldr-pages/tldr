# automd

> Automated Markdown documentation maintainer for updating badges, JSDoc, and config snippets.
> More information: <https://automd.unjs.io/>.

- Update all documentation blocks in the current directory:

`automd`

- Update a specific Markdown file:

`automd --file {{path/to/file.md}}`

- Watch source files and regenerate documentation blocks on change:

`automd --watch`
