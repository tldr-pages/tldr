# presentations

> SoftMaker Office's presentation application.
> See also: `planmaker`, `textmaker`.
> More information: <https://help.softmaker.com/presentations2026/en/index.html>.

- Launch the presentation application with a new blank document:

`planmaker`

- Open an existing file with Presentations:

`planmaker {{path/to/file.prdx}}`

- Launch Presentations with [N]o open documents:

`planmaker -N`
