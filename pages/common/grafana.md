# grafana

> Grafana server, and a CLI for administering a Grafana instance.
> Some subcommands such as `server` and `cli` have their own usage documentation.
> More information: <https://grafana.com/docs/grafana/latest/administration/cli/>.

- Start the Grafana server:

`grafana server`

- List installed plugins with the CLI:

`grafana cli plugins ls`

- Display help:

`grafana {{[-h|--help]}}`

- Display version:

`grafana {{[-v|--version]}}`
