# calligrastage

> Calligra's presentation application.
> See also: `calligraflow`, `calligrasheets`, `calligrawords`, `karbon`.
> More information: <https://manned.org/calligrastage>.

- Launch the presentation application:

`calligrastage`

- Open a specific presentation:

`calligrastage {{path/to/file.odp}}`

- Create a new document from a template file:

`calligrastage --new {{path/to/file.odp}}`

- Launch Calligra Stage with an interactive dialog to print the document:

`calligrastage {{path/to/file.odp}} --print`

- Launch Calligra Stage with an interactive dialog to export the document to PDF:

`calligrastage {{path/to/file.odp}} --export-pdf`

- Launch Calligra Stage and export document to PDF to a specific file:

`calligrastage {{path/to/input.odp}} --export-pdf --export-filename {{path/to/output.pdf}}`

- Display help or version:

`calligrastage --{{help|version}}`
