# colcrt

> Filter nroff output for CRT previewing.
> More information: <https://manned.org/colcrt>.

- Provide virtual half-line and reverse line feed sequences:

`colcrt`

- Suppress all underlining:

`colcrt {{-2}}`

- Cause all half-lines to be printed:

`colcrt {{-}}`

- Display help:

`colcrt {{[-h|--help]}}`

- Display version:

`colcrt {{[-V|--version]}}`
