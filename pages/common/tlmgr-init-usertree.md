# tlmgr init-usertree

> Initialize a user-specific TeX Live tree to allow managing packages without administrative privileges.
> More information: <https://www.tug.org/texlive/doc/tlmgr.html#init-usertree>.

- Initialize a user-specific TeX Live tree at the default location (`$TEXMFHOME`):

`tlmgr init-usertree`

- Initialize a user-specific TeX Live tree in a specific directory:

`tlmgr init-usertree --usertree {{path/to/directory}}`
