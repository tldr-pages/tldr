# nypm

> Unified package manager CLI for Node.js that auto-detects npm, pnpm, yarn, or bun.
> More information: <https://github.com/unjs/nypm>.

- Install all dependencies for the current project:

`nypm install`

- Add a dependency to the project:

`nypm add {{package_name}}`

- Add a development dependency to the project:

`nypm add -D {{package_name}}`

- Remove a dependency from the project:

`nypm remove {{package_name}}`
