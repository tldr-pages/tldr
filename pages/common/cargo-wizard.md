# cargo-wizard

> Cargo subcommand for applying predefined profile templates to Rust projects for fast builds, fast runtime, or minimal binary size.
> More information: <https://github.com/kobzol/cargo-wizard>.

- Run an interactive terminal wizard to configure a Cargo profile:

`cargo wizard`

- Apply a predefined template to a Cargo profile non-interactively:

`cargo wizard apply {{fast-compile|fast-runtime|min-size}} {{release}}`
