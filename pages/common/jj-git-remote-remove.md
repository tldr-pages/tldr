# jj git remote remove

> Remove a Git remote and forget its bookmarks.
> See also: `jj git remote add`, `jj git remote list`, `jj git remote rename`, `jj git remote set-url`.
> More information: <https://docs.jj-vcs.dev/latest/cli-reference/#jj-git-remote-remove>.

- Remove a Git remote by name:

`jj git remote remove {{remote_name}}`
