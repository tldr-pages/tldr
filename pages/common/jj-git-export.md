# jj git export

> Update the underlying Git repository with changes made in the Jujutsu repository.
> In colocated workspaces, export happens automatically.
> See also: `jj git import`.
> More information: <https://docs.jj-vcs.dev/latest/cli-reference/#jj-git-export>.

- Export changes to the underlying Git repository:

`jj git export`

- Forcibly export changes in a colocated workspace:

`jj git export --ignore-working-copy`
