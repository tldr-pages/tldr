# llm uninstall

> Uninstall Python packages and plugins from the LLM environment.
> More information: <https://llm.datasette.io/en/stable/help.html#llm-uninstall-help>.

- Uninstall a specific plugin:

`llm uninstall {{plugin_name}}`

- Uninstall multiple plugins:

`llm uninstall {{plugin1 plugin2 ...}}`

- Uninstall a plugin without asking for confirmation:

`llm uninstall {{[-y|--yes]}} {{plugin_name}}`
