# pkgroll

> Zero-config JavaScript and TypeScript package bundler built on Rollup and esbuild.
> More information: <https://github.com/privatenumber/pkgroll>.

- Bundle the package in the current directory based on the package manifest exports:

`pkgroll`

- Watch source files for changes and rebuild automatically:

`pkgroll --watch`

- Minify the output bundle and generate sourcemaps:

`pkgroll --minify --sourcemap`

- Clean the output directory before building:

`pkgroll --clean-dist`
