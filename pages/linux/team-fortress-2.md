# Team Fortress 2

> Start a headless Team Fortress 2 server.
> More information: <https://wiki.teamfortress.com/wiki/Linux_dedicated_server>.

- Start the server:

`{{path/to/}}srcds_run_64 +map {{ctf_2fort}}`

- Set the maximum player count:

`{{path/to/}}srcds_run_64 +map {{ctf_2fort}} +maxplayers {{2..100}}`
