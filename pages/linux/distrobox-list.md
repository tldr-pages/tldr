# distrobox list

> List Distrobox containers.
> Distrobox containers are listed separately from other Podman or Docker containers.
> See also: `distrobox`.
> More information: <https://distrobox.it/usage/distrobox-list/>.

- List all Distrobox containers:

`distrobox {{[ls|list]}}`

- List all Distrobox containers with verbose information:

`distrobox {{[ls|list]}} {{[-v|--verbose]}}`

- List containers without color:

`distrobox list --no-color`
