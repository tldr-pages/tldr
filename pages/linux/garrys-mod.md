# Garry's Mod

> Start a headless Garry's Mod server.
> More information: <https://wiki.facepunch.com/gmod/Linux_Dedicated_Server_Hosting>.

- Start the server:

`{{path/to}}/srcds_run`

- Start a server with a specific map:

`{{path/to}}/srcds_run +map {{gm_flatgrass}}`

- Set the maximum player count:

`{{path/to}}/srcds_run +maxplayers {{12}}`

- Start the server with a Game Server Login Token:

`{{path/to}}/srcds_run +sv_setsteamaccount {{token}}`
