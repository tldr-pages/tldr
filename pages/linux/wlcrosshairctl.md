# wlcrosshairctl

> Overlay an uninteractable image on top of the screen.
> Requires the `~/.config/wlcrosshair/config.toml` to be configured before use.
> More information: <https://github.com/marzeq/wlcrosshair>.

- Start the `wlcrosshair` daemon:

`wlcrosshair`

- Show the crosshair:

`wlcrosshairctl show`

- Hide the crosshair:

`wlcrosshairctl hide`

- Toggle the crosshair visibility:

`wlcrosshairctl toggle`

- Reload the settings from `~/.config/wlcrosshair/config.toml`:

`wlcrosshairctl reload`
