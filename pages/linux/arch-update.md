# arch-update

> Interactive update notifier & applier for Arch Linux.
> More information: <https://github.com/Antiz96/arch-update>.

- Start the system update:

`arch-update`

- List pending updates:

`arch-update {{[-l|--list]}}`

- Start the systray applet and enable it automatically at boot:

`arch-update --tray --enable`

- List last 10 Arch news:

`arch-update {{[-n|--news]}} 10`
