# flatpak kill

> Stop a running Flatpak application.
> More information: <https://docs.flatpak.org/en/latest/flatpak-command-reference.html#flatpak-kill>.

- Stop a running Flatpak application by its application ID:

`flatpak kill {{com.example.App}}`

- Stop a running application and display debug information:

`flatpak kill --verbose {{com.example.App}}`

- Display help:

`flatpak kill --help`
