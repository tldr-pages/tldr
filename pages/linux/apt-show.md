# apt show

> Show detailed information about packages.
> More information: <https://manned.org/apt.8>.

- Show detailed information about a package:

`apt show {{package}}`

- Show detailed information about multiple packages:

`apt show {{package1 package2 ...}}`

- Show detailed information about a specific version of a package:

`apt show {{package}}={{version}}`

- Show information about all available versions of a package:

`apt show {{[-a|--all-versions]}} {{package}}`
