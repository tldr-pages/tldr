# nmtui

> Text user interface for controlling NetworkManager.
> Use `<ArrowKeys>` to navigate, `<Enter>` to select an option.
> See also: `nmcli`.
> More information: <https://networkmanager.pages.freedesktop.org/NetworkManager/NetworkManager/nmtui.html>.

- Open the user interface:

`nmtui`

- Activate or deactivate a connection:

`nmtui connect`

- Connect to a specific network:

`nmtui connect {{name|uuid|device|ssid}}`

- Add, edit, or delete a connection:

`nmtui edit`

- Edit a specific connection:

`nmtui edit {{name|id}}`

- Set the system hostname:

`nmtui hostname`
