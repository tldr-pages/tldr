# opi

> Search and install packages from openSUSE, community, and proprietary repositories.
> More information: <https://github.com/openSUSE/opi>.

- Search for a package:

`opi {{package}}`

- Install media codecs:

`opi codecs`

- Search for a package without running scripts:

`opi -P {{package}}`

- Search for a package in non interactive mode:

`sudo opi -n {{package}}`

- Search multi packages:

`opi -m {{package1 package2 ...}}`
