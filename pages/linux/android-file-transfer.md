# android-file-transfer

> Graphical MTP client for Android devices.
> See also: `aft-mtp-cli`, `aft-mtp-mount`.
> More information: <https://github.com/whoozle/android-file-transfer-linux>.

- Start the graphical client:

`android-file-transfer`

- Reset the USB device before connecting:

`android-file-transfer -R`

- Start and print debug output:

`android-file-transfer -v`

- View documentation for the command-line client:

`tldr aft-mtp-cli`

- View documentation for the FUSE mount helper:

`tldr aft-mtp-mount`
