# aerospace

> A tiling window manager for macOS.
> More information: <https://nikitabobko.github.io/AeroSpace/commands>.

- Reload the configuration:

`aerospace reload-config`

- Switch to a workspace:

`aerospace workspace {{workspace}}`

- Move the focused window to a workspace:

`aerospace move-node-to-workspace {{workspace}}`

- Focus a window in a direction:

`aerospace focus {{left|down|up|right}}`

- Move the focused window in a direction:

`aerospace move <left|down|up|right>`

- List all windows:

`aerospace list-windows --all`

- List all workspaces:

`aerospace list-workspaces --all`

- Change the focused window's layout:

`aerospace layout {{tiling|floating}}`
