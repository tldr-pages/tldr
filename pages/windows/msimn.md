# msimn

> Manage emails and subscribed online news with Microsoft Outlook Express.
> Note: This program is deprecated since Windows Vista in favor of their successors (Windows Mail, Windows Live Mail, Mail, New Outlook).
> More information: <https://web.archive.org/web/20140506083227/http://support.microsoft.com/kb/177233>.

- Run Outlook Express with both email and news features enabled:

`msimn`

- Run Outlook Express with News Reader Only mode, disabling email functionality:

`msimn {{/newsonly|/outnews}}`

- Run Outlook Express showing the News Reader without disabling emails (applicable only prior to version 4.0):

`msimn /outnews`

- Run Outlook Express with Mail Only mode, disabling news reader functionality (applicable only prior to version 5.0):

`msimn /mailonly`
