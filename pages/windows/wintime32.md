# WinTime32

> Measure a 32-bit program's execution time and memory usage.
> See also: `WinTime64`.
> More information: <https://github.com/cbielow/wintime>.

- Measure a 32-bit program's execution time and memory usage:

`WinTime32 -- "{{path\to\program.exe}}"`

- View more usage examples:

`tldr wintime64`
