# pacman --upgrade

> Устанавливать пакеты вручную из файлов архивов.
> Больше информации: <https://manned.org/pacman.8>.

- Установить один или несколько пакетов из файлов:

`sudo pacman -U {{путь/к/пакету1.pkg.tar.zst путь/к/пакету2.pkg.tar.zst ...}}`

- Установить пакет без подтверждения:

`sudo pacman -U --noconfirm {{путь/к/пакету.pkg.tar.zst}}`

- Перезаписать конфликтующие файлы при установке пакета:

`sudo pacman -U --overwrite {{путь/к/файлу}} {{путь/к/пакету.pkg.tar.zst}}`

- Установить пакет, пропустив проверку версий зависимостей [d]:

`sudo pacman -Ud {{путь/к/пакету.pkg.tar.zst}}`

- Загрузить и вывести [p] пакеты, которые будут затронуты обновлением (не устанавливает пакеты):

`pacman -Up {{путь/к/пакету.pkg.tar.zst}}`

- Показать [h] справку:

`pacman -Uh`
