# ip route

> Подкоманда для управления таблицей IP-маршрутизации.
> Смотрите также: `routel`, `ip rule`.
> Больше информации: <https://manned.org/ip-route>.

- Показать основную (`main`) таблицу маршрутизации:

`ip {{[r|route]}}`

- Добавить маршрут по умолчанию через шлюз:

`sudo ip {{[r|route]}} {{[a|add]}} default via {{ip_адрес_шлюза}}`

- Добавить маршрут по умолчанию через `ethX`:

`sudo ip {{[r|route]}} {{[a|add]}} default dev {{ethX}}`

- Добавить статический маршрут:

`sudo ip {{[r|route]}} {{[a|add]}} {{ip_адрес_назначения}} via {{ip_адрес_шлюза}} dev {{ethX}}`

- Удалить статический маршрут:

`sudo ip {{[r|route]}} {{[d|delete]}} {{ip_адрес_назначения}} dev {{ethX}}`

- Изменить или заменить статический маршрут:

`sudo ip {{[r|route]}} {{change|replace}} {{ip_адрес_назначения}} via {{ip_адрес_шлюза}} dev {{ethX}}`

- Показать маршрут, который будет использован ядром для достижения IP-адреса:

`ip {{[r|route]}} {{[g|get]}} {{ip_адрес_назначения}}`

- Показать конкретную таблицу маршрутизации:

`ip {{[r|route]}} {{[l|list]}} {{[t|table]}} {{номер_таблицы}}`
