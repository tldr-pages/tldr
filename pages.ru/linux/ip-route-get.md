# ip route get

> Получать маршрут до назначения и выводить его содержимое так, как его видит ядро.
> Больше информации: <https://manned.org/ip-route>.

- Показать маршрут до назначения:

`ip {{[r|route]}} {{[g|get]}} {{1.1.1.1}}`

- Показать маршрут до назначения от конкретного адреса источника:

`ip {{[r|route]}} {{[g|get]}} {{назначение}} from {{источник}}`

- Показать маршрут до назначения для пакетов, приходящих на конкретный интерфейс:

`ip {{[r|route]}} {{[g|get]}} {{назначение}} iif {{ethX}}`

- Показать маршрут до назначения с принудительным выходом через конкретный интерфейс:

`ip {{[r|route]}} {{[g|get]}} {{назначение}} oif {{ethX}}`

- Показать маршрут до назначения с указанным типом обслуживания (ToS):

`ip {{[r|route]}} {{[g|get]}} {{назначение}} tos {{0x10}}`

- Показать маршрут до назначения с использованием конкретного экземпляра VRF (Virtual Routing and Forwarding):

`ip {{[r|route]}} {{[g|get]}} {{назначение}} vrf {{myvrf}}`
