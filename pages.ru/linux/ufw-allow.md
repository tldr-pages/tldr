# ufw allow

> Разрешать трафик через межсетевой экран.
> Больше информации: <https://manned.org/ufw>.

- Разрешить весь трафик на порту:

`sudo ufw allow {{порт}}`

- Разрешить трафик для протокола на порту:

`sudo ufw allow {{порт}}/{{протокол}}`

- Разрешить входящий трафик для протокола и добавить комментарий для документирования:

`sudo ufw allow in {{протокол}} comment '{{комментарий}}'`

- Разрешить весь трафик с адреса источника:

`sudo ufw allow from {{адрес_источника}}`

- Разрешить весь входящий трафик из подсети 192.168.13.0/24:

`sudo ufw allow from 192.168.13.0/24`

- Разрешить TCP-трафик от 192.168.1.12 к 192.168.1.100 на порт 443:

`sudo ufw allow from 192.168.1.12 to 192.168.1.100 port 443 proto tcp`

- Разрешить весь входящий GRE-трафик к 192.168.1.100 на интерфейсе eth0:

`sudo ufw allow in on eth0 to 192.168.1.100 proto gre`
