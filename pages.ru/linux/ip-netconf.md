# ip netconf

> Показывать параметры конфигурации сети.
> Больше информации: <https://manned.org/ip-netconf>.

- Показать сетевую конфигурацию для всех интерфейсов:

`ip {{[netc|netconf]}}`

- Показать сетевую конфигурацию для конкретного интерфейса:

`ip {{[netc|netconf]}} {{[s|show]}} dev {{сетевой_интерфейс}}`

- Показать только сетевую конфигурацию IPv4:

`ip -4 {{[netc|netconf]}}`

- Показать только сетевую конфигурацию IPv6:

`ip -6 {{[netc|netconf]}}`
