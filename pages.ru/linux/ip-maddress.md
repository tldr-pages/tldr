# ip maddress

> Управлять адресами многоадресной рассылки.
> Больше информации: <https://manned.org/ip-maddress>.

- Показать список адресов многоадресной рассылки и количество подписанных на них программ:

`ip {{[m|maddress]}}`

- Показать адреса для конкретного устройства:

`ip {{[m|maddress]}} {{[s|show]}} dev {{ethX}}`

- Статически присоединиться к группе многоадресной рассылки:

`sudo ip {{[m|maddress]}} {{[a|add]}} {{33:33:00:00:00:02}} dev {{ethX}}`

- Покинуть статическую группу многоадресной рассылки:

`sudo ip {{[m|maddress]}} {{[d|delete]}} {{33:33:00:00:00:02}} dev {{ethX}}`

- Показать справку:

`ip {{[m|maddress]}} {{[h|help]}}`
