# ufw status

> Показывать статус межсетевого экрана и его правил.
> Больше информации: <https://manned.org/ufw>.

- Показать, активен ли межсетевой экран, и вывести правила:

`sudo ufw status`

- Показать правила с номерами (полезно перед удалением правила по номеру):

`sudo ufw status numbered`

- Показать подробный статус, включая политики по умолчанию и прослушиваемые порты:

`sudo ufw status verbose`
