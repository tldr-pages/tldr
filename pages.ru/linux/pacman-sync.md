# pacman --sync

> Синхронизировать пакеты из удалённых репозиториев.
> Больше информации: <https://manned.org/pacman.8>.

- Установить новый пакет:

`sudo pacman -S {{пакет}}`

- [S]инхронизировать и обновить ([y]) базу данных пакетов с обновлением [u] системы (добавьте `--downloadonly` для загрузки пакетов без их обновления):

`sudo pacman -Syu`

- Обновить [u] все пакеты и установить новый без подтверждения:

`sudo pacman -Syu --noconfirm {{пакет}}`

- И[s]кать в базе данных пакетов по `regex` или ключевому слову:

`pacman -Ss "{{шаблон_поиска}}"`

- Показать [i] информацию о пакете:

`pacman -Si {{пакет}}`

- Перезаписать конфликтующие файлы при обновлении пакета:

`sudo pacman -Syu --overwrite {{путь/к/файлу}}`

- Удалить неустановленные пакеты и неиспользуемые репозитории из кэша (используйте флаги `Scc` для очистки [c] всех пакетов):

`sudo pacman -Sc`

- Указать версию пакета для установки:

`sudo pacman -S {{пакет}}={{версия}}`
