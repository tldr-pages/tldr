# pacman --files

> Запрашивать локальную базу данных файлов.
> Смотрите также: `pkgfile`.
> Больше информации: <https://manned.org/pacman.8>.

- Обновить базу данных пакетов:

`sudo pacman -Fy`

- Найти пакет, которому принадлежит конкретный [F]айл:

`pacman -F {{имя_файла}}`

- Найти пакет, которому принадлежит конкретный [F]айл, используя `rege[x]`:

`pacman -Fx '{{регулярное_выражение}}'`

- Вывести только имена пакетов:

`pacman -Fq {{имя_файла}}`

- Вывести [l] [F]айлы, принадлежащие конкретному пакету:

`pacman -Fl {{пакет}}`

- Показать [h] справку:

`pacman -Fh`
