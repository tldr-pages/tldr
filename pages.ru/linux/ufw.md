# ufw

> Простой межсетевой экран (Uncomplicated Firewall).
> Интерфейс для `iptables`, упрощающий настройку межсетевого экрана.
> Некоторые подкоманды, такие как `allow`, `enable`, `delete` и др., имеют собственную документацию по использованию.
> Больше информации: <https://manned.org/ufw>.

- Включить/Отключить `ufw`:

`sudo ufw {{enable|disable}}`

- Показать правила `ufw` вместе с их номерами:

`sudo ufw status numbered`

- Разрешить входящий трафик на порт 5432 на данном хосте с комментарием, идентифицирующим сервис:

`sudo ufw allow 5432 comment "{{Сервис}}"`

- Разрешить только TCP-трафик от 192.168.0.4 на любой адрес данного хоста, на порт 22:

`sudo ufw allow proto tcp from 192.168.0.4 to any port 22`

- Разрешить трафик с любого IP в подсети 192.168.0.0/24 на данном хосте, через порт 53, только на интерфейсе eth0:

`sudo ufw allow in on eth0 from 192.168.0.0/24 to any port 53`

- Запретить трафик на порт 80 на данном хосте:

`sudo ufw deny 80`

- Запретить весь UDP-трафик на порты в диапазоне 8412:8500:

`sudo ufw deny proto udp from any to any port 8412:8500`

- Удалить конкретное правило. Номер правила можно получить из команды `ufw status numbered`:

`sudo ufw delete {{номер_правила}}`
