# ip link

> Управлять сетевыми интерфейсами.
> Больше информации: <https://manned.org/ip-link>.

- Показать информацию обо всех сетевых интерфейсах:

`ip {{[l|link]}}`

- Показать информацию о конкретном сетевом интерфейсе:

`ip {{[l|link]}} {{[sh|show]}} {{ethX}}`

- Включить или выключить сетевой интерфейс:

`sudo ip {{[l|link]}} {{[s|set]}} {{ethX}} {{up|down}}`

- Присвоить понятное имя сетевому интерфейсу:

`sudo ip {{[l|link]}} {{[s|set]}} {{ethX}} {{[al|alias]}} "{{LAN Interface}}"`

- Изменить MAC-адрес сетевого интерфейса:

`sudo ip {{[l|link]}} {{[s|set]}} {{ethX}} {{[a|address]}} {{ff:ff:ff:ff:ff:ff}}`

- Изменить размер MTU сетевого интерфейса для использования jumbo-кадров:

`sudo ip {{[l|link]}} {{[s|set]}} {{ethX}} mtu {{9000}}`

- Включить или выключить неразборчивый режим (promisc) для устройства:

`sudo ip {{[l|link]}} {{[s|set]}} {{ethX}} promisc {{on|off}}`

- Удалить устройство:

`sudo ip {{[l|link]}} {{[d|delete]}} {{ethX}}`
