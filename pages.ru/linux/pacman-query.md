# pacman --query

> Запрашивать локальную базу данных пакетов.
> Больше информации: <https://manned.org/pacman.8>.

- [Q] Запросить локальную базу данных пакетов и вывести установленные пакеты и версии:

`pacman -Q`

- Вывести только [e] явно установленные пакеты без номеров версий:

`pacman -Qeq`

- Найти, какому пакету принадлежит [o] файл:

`pacman -Qo {{имя_файла}}`

- Показать [i] информацию об установленном пакете:

`pacman -Qi {{пакет}}`

- Показать [l] список файлов, принадлежащих конкретному пакету:

`pacman -Ql {{пакет}}`

- Вывести пакеты-сироты (установленные как зависимости [d], но не требующиеся ([t]) ни одному пакету, в тихом [q] режиме (показывается только имя пакета)):

`pacman -Qdtq`

- Вывести установленные пакеты, отсутствующие ([m]) в базе данных репозитория:

`pacman -Qm`

- Вывести пакеты, которые можно обновить [u]:

`pacman -Qu`
