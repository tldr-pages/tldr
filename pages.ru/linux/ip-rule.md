# ip rule

> Управлять базой данных политик IP-маршрутизации.
> Смотрите также: `ip route`.
> Больше информации: <https://manned.org/ip-rule>.

- Показать политику маршрутизации:

`ip {{[ru|rule]}}`

- Создать новое общее правило маршрутизации с приоритетом выше `main`:

`sudo ip {{[ru|rule]}} {{[a|add]}} from all lookup {{идентификатор_таблицы}}`

- Добавить новое правило на основе адресов источника пакетов:

`sudo ip {{[ru|rule]}} {{[a|add]}} from {{192.168.178.2/32}} lookup {{идентификатор_таблицы}}`

- Добавить новое правило на основе адресов назначения пакетов:

`sudo ip {{[ru|rule]}} {{[a|add]}} to {{192.168.178.2/32}} lookup {{идентификатор_таблицы}}`

- Удалить правило на основе адресов источника пакетов:

`sudo ip {{[ru|rule]}} {{[d|delete]}} from {{192.168.178.2/32}}`

- Удалить все правила маршрутизации:

`sudo ip {{[ru|rule]}} {{[f|flush]}}`

- Сохранить все правила в файл:

`ip {{[ru|rule]}} {{[s|save]}} >{{путь/к/ip_rules.dat}}`

- Восстановить все правила из файла:

`sudo ip <{{путь/к/ip_rules.dat}} {{[ru|rule]}} {{[r|restore]}}`
