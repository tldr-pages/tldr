# ip monitor

> Отслеживать изменения состояния сети.
> Больше информации: <https://manned.org/ip-monitor>.

- Запустить мониторинг всех изменений состояния сети:

`ip {{[mo|monitor]}}`

- Указать тип объектов для мониторинга:

`ip {{[mo|monitor]}} {{link|address|route|neigh|rule|maddress|...}}`

- Воспроизвести файл событий (можно сгенерировать с помощью `rtmon`):

`ip {{[mo|monitor]}} {{[f|file]}} {{путь/к/файлу}}`
