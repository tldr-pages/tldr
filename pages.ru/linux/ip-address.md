# ip address

> Подкоманда для управления IP-адресами.
> Больше информации: <https://manned.org/ip-address>.

- Показать список сетевых интерфейсов и связанных с ними IP-адресов:

`ip {{[a|address]}}`

- Показать только активные сетевые интерфейсы:

`ip {{[a|address]}} {{[s|show]}} up`

- Показать информацию о конкретном сетевом интерфейсе:

`ip {{[a|address]}} {{[s|show]}} {{ethX}}`

- Добавить IP-адрес сетевому интерфейсу:

`sudo ip {{[a|address]}} {{[a|add]}} {{ip_адрес}} dev {{ethX}}`

- Удалить IP-адрес с сетевого интерфейса:

`sudo ip {{[a|address]}} {{[d|delete]}} {{ip_адрес}} dev {{ethX}}`

- Удалить все IP-адреса из указанной области действия (scope) для сетевого интерфейса:

`sudo ip {{[a|address]}} {{[f|flush]}} {{ethX}} scope {{global|host|link}}`
