# ip route add

> Добавлять новый сетевой маршрут.
> Больше информации: <https://manned.org/ip-route>.

- Добавить маршрут по умолчанию через шлюз:

`sudo ip {{[r|route]}} {{[a|add]}} default via {{ip_адрес_шлюза}}`

- Добавить маршрут по умолчанию через `ethX`:

`sudo ip {{[r|route]}} {{[a|add]}} default dev {{ethX}}`

- Добавить статический маршрут:

`sudo ip {{[r|route]}} {{[a|add]}} {{ip_адрес_назначения}} via {{ip_адрес_шлюза}} dev {{ethX}}`

- Добавить маршрут в конкретную таблицу маршрутизации:

`sudo ip {{[r|route]}} {{[a|add]}} {{ip_адрес_назначения}} dev {{ethX}} {{[t|table]}} {{ip_адрес}}`

- Направить интернет-трафик через конкретное устройство, оставив локальный трафик без изменений (также требуется создание правила):

`sudo ip {{[r|route]}} {{[a|add]}} default via {{ip_адрес_шлюза}} dev {{ethX}} table {{идентификатор_таблицы}}`
