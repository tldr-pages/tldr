# git merge

> Выполнять слияние веток.
> Больше информации: <https://git-scm.com/docs/git-merge>.

- Выполнить слияние веток в текущую ветку:

`git merge {{имя_ветки1 имя_ветки2 ...}}`

- Отредактировать сообщение слияния:

`git merge {{[-e|--edit]}} {{имя_ветки}}`

- Выполнить слияние ветки и создать коммит слияния:

`git merge --no-ff {{имя_ветки}}`

- Подготовить результат слияния ветки без создания коммита:

`git merge --squash {{имя_ветки}}`

- Прервать слияние в случае конфликтов:

`git merge --abort`

- Выполнить слияние с использованием определённой стратегии:

`git merge {{[-s|--strategy]}} {{стратегия}} {{[-X|--strategy-option]}} {{параметр_стратегии}} {{имя_ветки}}`
