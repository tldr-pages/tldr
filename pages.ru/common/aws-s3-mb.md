# aws s3 mb

> Создавать бакеты S3.
> Больше информации: <https://docs.aws.amazon.com/cli/latest/reference/s3/mb.html>.

- Создать бакет S3:

`aws s3 mb s3://{{имя_бакета}}`

- Создать бакет S3 в определённом регионе:

`aws s3 mb s3://{{имя_бакета}} --region {{регион}}`

- Показать справку:

`aws s3 mb help`
