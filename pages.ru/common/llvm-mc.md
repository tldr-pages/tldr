# llvm-mc

> Площадка для машинного кода LLVM. Предоставляет набор инструментов для работы с машинным кодом LLVM.
> Часть LLVM.
> Больше информации: <https://llvm.org/docs/CommandGuide/llvm-mc.html>.

- Ассемблировать файл с ассемблерным кодом в объектный файл с машинным кодом:

`llvm-mc --filetype=obj -o {{путь/к/выходному_файлу.o}} {{путь/к/входному_файлу.s}}`

- Дизассемблировать объектный файл с машинным кодом в файл с ассемблерным кодом:

`llvm-mc --disassemble -o {{путь/к/выходному_файлу.s}} {{путь/к/входному_файлу.o}}`

- Скомпилировать файл LLVM Bitcode в ассемблерный код:

`llvm-mc -o {{путь/к/выходному_файлу.s}} {{путь/к/входному_файлу.bc}}`

- Ассемблировать ассемблерный код из `stdin` и показать кодировку в `stdout`:

`echo "{{addl %eax, %ebx}}" | llvm-mc -show-encoding -show-inst`

- Дизассемблировать машинный код из `stdin` для указанной целевой тройки:

`echo "{{0xCD 0x21}}" | llvm-mc --disassemble -triple={{имя_целевой_платформы}}`
