# nxc smb

> Тестировать на проникновение и эксплуатировать SMB-серверы.
> Больше информации: <https://www.netexec.wiki/smb-protocol/generate-hosts-file>.

- Найти действительные учётные данные домена, перебирая все комбинации из указанных списков имён пользователей и паролей:

`nxc smb {{192.168.178.2}} {{[-u|--username]}} {{путь/к/именам_пользователей.txt}} {{[-p|--password]}} {{путь/к/паролям.txt}}`

- Найти действительные учётные данные для локальных учётных записей вместо доменных:

`nxc smb {{192.168.178.2}} {{[-u|--username]}} {{путь/к/именам_пользователей.txt}} {{[-p|--password]}} {{путь/к/паролям.txt}} --local-auth`

- Перечислить общие ресурсы SMB и права доступа указанных пользователей к ним на целевых хостах:

`nxc smb {{192.168.178.0/24}} {{[-u|--username]}} {{имя_пользователя}} {{[-p|--password]}} {{пароль}} --shares`

- Перечислить сетевые интерфейсы на целевых хостах, выполняя аутентификацию через pass-the-hash:

`nxc smb {{192.168.178.30-45}} {{[-u|--username]}} {{имя_пользователя}} {{[-H|--hash]}} {{NTLM_хеш}} --interfaces`

- Просканировать целевые хосты на наличие распространённых уязвимостей:

`nxc smb {{путь/к/списку_целей.txt}} {{[-u|--username]}} '' {{[-p|--password]}} '' {{[-M|--module]}} zerologon {{[-M|--module]}} petitpotam`

- Попытаться выполнить команду на целевых хостах:

`nxc smb {{192.168.178.2}} {{[-u|--username]}} {{имя_пользователя}} {{[-p|--password]}} {{пароль}} -x {{команда}}`
