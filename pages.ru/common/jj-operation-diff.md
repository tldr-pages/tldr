# jj operation diff

> Сравнивать изменения в репозитории между двумя операциями.
> Больше информации: <https://docs.jj-vcs.dev/latest/cli-reference/#jj-operation-diff>.

- Сравнить изменения в репозитории для конкретной операции с её родительской:

`jj {{[op|operation]}} diff {{[--op|--operation]}} {{идентификатор_операции}}`

- Сравнить изменения в репозитории между двумя конкретными операциями:

`jj {{[op|operation]}} diff {{[-f|--from]}} {{исходная_операция}} {{[-t|--to]}} {{целевая_операция}}`

- Показать diff с патчем модификаций изменений:

`jj {{[op|operation]}} diff {{[-p|--patch]}} {{[--op|--operation]}} {{идентификатор_операции}}`

- Показать diff в виде гистограммы изменений:

`jj {{[op|operation]}} diff --stat {{[--op|--operation]}} {{идентификатор_операции}}`

- Показать diff без графа:

`jj {{[op|operation]}} diff {{[-G|--no-graph]}} {{[--op|--operation]}} {{идентификатор_операции}}`
