# zapier versions

> Выводить список версий интеграции Zapier.
> Больше информации: <https://github.com/zapier/zapier-platform/blob/main/packages/cli/docs/cli.md#validate>.

- Показать версии интеграции:

`zapier versions`

- Включить устаревшие версии:

`zapier versions {{[-a|--all]}}`

- Показать дополнительную отладочную информацию:

`zapier versions {{[-d|--debug]}}`

- Показать версии в другом формате вывода:

`zapier versions {{[-f|--format]}} {{plain|json|raw|row|table}}`
