# docker image tag

> Присваивать теги существующим образам Docker.
> Больше информации: <https://docs.docker.com/reference/cli/docker/image/tag/>.

- Присвоить имя и тег определённому идентификатору образа:

`docker {{[tag|image tag]}} {{идентификатор_образа}} {{имя}}:{{тег}}`

- Присвоить тег определённому образу:

`docker {{[tag|image tag]}} {{образ}}:{{текущий_тег}} {{образ}}:{{новый_тег}}`

- Показать справку:

`docker {{[tag|image tag]}}`
