# rabbitmqctl

> Управлять серверами RabbitMQ, настраивать и проверять их.
> Больше информации: <https://www.rabbitmq.com/docs/man/rabbitmqctl.8>.

- Показать статус текущего узла:

`rabbitmqctl status`

- Посмотреть документацию по командам кластера RabbitMQ:

`tldr rabbitmqctl cluster`

- Посмотреть документацию по командам пользователей RabbitMQ:

`tldr rabbitmqctl users`

- Посмотреть документацию по командам виртуальных хостов RabbitMQ:

`tldr rabbitmqctl vhosts`

- Узнать больше о конкретной команде:

`rabbitmqctl help {{команда}}`
