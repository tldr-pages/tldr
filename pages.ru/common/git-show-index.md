# git show-index

> Показывать индекс упакованного архива Git-репозитория.
> Больше информации: <https://git-scm.com/docs/git-show-index>.

- Прочитать IDX-файл упакованного файла Git и вывести его содержимое в `stdout`:

`git show-index {{путь/к/файлу.idx}}`

- Указать алгоритм хеширования для индексного файла (экспериментально):

`git show-index --object-format {{sha1|sha256}} {{путь/к/файлу}}`
