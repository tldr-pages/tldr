# glab

> Удобно работать с GitLab.
> Некоторые подкоманды, такие как `config`, имеют собственную документацию по использованию.
> Больше информации: <https://gitlab.com/gitlab-org/cli/-/tree/main/docs/source>.

- Клонировать репозиторий GitLab локально:

`glab repo clone {{владелец}}/{{репозиторий}}`

- Создать новую задачу:

`glab issue create`

- Просмотреть и отфильтровать открытые задачи текущего репозитория:

`glab issue list`

- Открыть задачу в браузере по умолчанию ([w]eb):

`glab issue view {{[-w|--web]}} {{номер_задачи}}`

- Создать запрос на слияние:

`glab mr create`

- Открыть запрос на слияние в браузере по умолчанию ([w]eb):

`glab mr view {{[-w|--web]}} {{номер_запроса}}`

- Переключиться на ветку конкретного запроса на слияние локально:

`glab {{[co|mr checkout]}} {{номер_запроса}}`
