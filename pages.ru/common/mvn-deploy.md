# mvn deploy

> Добавлять артефакт в удалённый репозиторий.
> Больше информации: <https://manned.org/mvn>.

- Скопировать итоговый артефакт в удалённый репозиторий, настроенный в файле `settings.xml`:

`mvn deploy`

- Скопировать артефакт, не собранный с помощью Maven, в удалённый репозиторий:

`mvn deploy:deploy-file {{[-D|--define]}} url={{url_удалённого_репозитория}} {{[-D|--define]}} repositoryId={{id_сервера_из_settings_xml}} {{[-D|--define]}} file={{путь/к/файлу}}`
