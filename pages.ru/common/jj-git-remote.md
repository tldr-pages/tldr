# jj git remote

> Управлять удалёнными Git-репозиториями.
> Больше информации: <https://docs.jj-vcs.dev/latest/cli-reference/#jj-git-remote>.

- Вывести список всех удалённых Git-репозиториев:

`jj git remote list`

- Добавить удалённый Git-репозиторий:

`jj git remote add {{имя_удалённого_репозитория}} {{url_удалённого_репозитория}}`

- Добавить удалённый Git-репозиторий с отдельным URL для отправки:

`jj git remote add --push-url {{url_для_отправки}} {{имя_удалённого_репозитория}} {{url_удалённого_репозитория}}`

- Изменить URL удалённого Git-репозитория:

`jj git remote set-url {{имя_удалённого_репозитория}} {{url_удалённого_репозитория}}`

- Установить URL для отправки в удалённый Git-репозиторий:

`jj git remote set-url --push {{url_для_отправки}} {{имя_удалённого_репозитория}}`

- Установить URL для получения и отправки в удалённый Git-репозиторий:

`jj git remote set-url --fetch {{url_для_получения}} --push {{url_для_отправки}} {{имя_удалённого_репозитория}}`

- Удалить удалённый Git-репозиторий:

`jj git remote remove {{имя_удалённого_репозитория}}`

- Переименовать удалённый Git-репозиторий:

`jj git remote rename {{старое_имя}} {{новое_имя}}`
