# docker network

> Создавать сети Docker и управлять ими.
> Больше информации: <https://docs.docker.com/reference/cli/docker/network/>.

- Вывести список всех доступных и настроенных сетей в демоне Docker:

`docker network ls`

- Создать пользовательскую сеть:

`docker network create {{[-d|--driver]}} {{имя_драйвера}} {{имя_сети}}`

- Показать подробную информацию об одной или нескольких сетях:

`docker network inspect {{имя_сети1 имя_сети2 ...}}`

- Подключить контейнер к сети по имени или идентификатору:

`docker network connect {{имя_сети}} {{имя_контейнера|идентификатор}}`

- Отключить контейнер от сети:

`docker network disconnect {{имя_сети}} {{имя_контейнера|идентификатор}}`

- Удалить все неиспользуемые сети (не связанные ни с одним контейнером):

`docker network prune`

- Удалить одну или несколько неиспользуемых сетей:

`docker network rm {{имя_сети1 имя_сети2 ...}}`
