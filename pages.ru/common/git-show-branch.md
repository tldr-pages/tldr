# git show-branch

> Показывать ветки и их коммиты.
> Больше информации: <https://git-scm.com/docs/git-show-branch>.

- Показать сводку последнего коммита в ветке:

`git show-branch {{имя_ветки|ссылка|коммит}}`

- Сравнить коммиты в истории нескольких коммитов или веток:

`git show-branch {{имя_ветки1|ссылка1|коммит1 имя_ветки2|ссылка2|коммит2 ...}}`

- Сравнить все удалённые отслеживаемые ветки:

`git show-branch {{[-r|--remotes]}}`

- Сравнить локальные и удалённые отслеживаемые ветки:

`git show-branch {{[-a|--all]}}`

- Вывести список последних коммитов во всех ветках:

`git show-branch {{[-a|--all]}} --list`

- Сравнить указанную ветку с текущей веткой:

`git show-branch --current {{коммит|имя_ветки|ссылка}}`

- Показать имя коммита вместо относительного имени:

`git show-branch --sha1-name --current {{текущий|имя_ветки|ссылка}}`

- Продолжить на указанное количество коммитов после общего предка:

`git show-branch --more {{5}} {{имя_ветки1|ссылка1|коммит1 имя_ветки2|ссылка2|коммит2 ...}}`
