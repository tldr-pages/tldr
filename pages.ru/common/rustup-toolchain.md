# rustup toolchain

> Управлять наборами инструментов Rust.
> Подробнее см. `rustup help toolchain`.
> Больше информации: <https://rust-lang.github.io/rustup/>.

- Установить или обновить указанный набор инструментов:

`rustup toolchain install {{набор_инструментов}}`

- Удалить набор инструментов:

`rustup toolchain uninstall {{набор_инструментов}}`

- Показать установленные наборы инструментов:

`rustup toolchain list`

- Создать пользовательский набор инструментов с помощью символической ссылки на каталог:

`rustup toolchain link {{имя_набора_инструментов}} {{путь/к/каталогу}}`
