# mvn package

> Упаковывать скомпилированный код проекта Maven в формат для распространения (такой как `.jar` или `.war`).
> Больше информации: <https://manned.org/mvn>.

- Упаковать проект:

`mvn package`

- Упаковать проект, пропуская выполнение тестов:

`mvn package {{[-D|--define]}} skipTests`

- Упаковать проект и принудительно обновить все зависимости:

`mvn package {{[-U|--update-snapshots]}}`
