# pixi config

> Управлять файлом конфигурации.
> Больше информации: <https://pixi.sh/latest/reference/cli/#config>.

- Отредактировать файл конфигурации:

`pixi config edit`

- Вывести список всех конфигураций:

`pixi config list`

- Добавить значение в начало списка конфигурационного ключа:

`pixi config prepend {{ключ}} {{значение}}`

- Добавить значение в конец списка конфигурационного ключа:

`pixi config append {{ключ}} {{значение}}`

- Установить значение конфигурационного ключа:

`pixi config set {{ключ}} {{значение}}`

- Сбросить конфигурационный ключ:

`pixi config unset {{ключ}}`
