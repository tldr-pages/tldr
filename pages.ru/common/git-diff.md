# git diff

> Показывать изменения в отслеживаемых файлах.
> Больше информации: <https://git-scm.com/docs/git-diff>.

- Показать непроиндексированные изменения:

`git diff`

- Показать все незафиксированные изменения (включая проиндексированные):

`git diff HEAD`

- Показать только проиндексированные (добавленные, но ещё не зафиксированные) изменения:

`git diff --staged`

- Показать изменения из всех коммитов с указанной даты/времени (выражение даты, например "1 week 2 days" или дата в формате ISO):

`git diff 'HEAD@{{{3 months|weeks|days|hours|seconds ago}}}'`

- Показать статистику различий, такую как изменённые файлы, гистограмму и общее количество вставленных/удалённых строк:

`git diff --stat {{коммит}}`

- Вывести сводку о создании, переименовании файлов и изменении режимов с указанного коммита:

`git diff --summary {{коммит}}`

- Сравнить один файл между двумя ветками или коммитами:

`git diff {{ветка_1}}..{{ветка_2}} {{путь/к/файлу}}`

- Сравнить разные файлы из текущей ветки с другой веткой:

`git diff {{другая_ветка}}:{{путь/к/файлу2}} {{путь/к/файлу1}}`
