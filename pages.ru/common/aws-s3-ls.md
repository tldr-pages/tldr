# aws s3 ls

> Выводить список бакетов AWS S3, каталогов (префиксов) и файлов (объектов).
> Больше информации: <https://docs.aws.amazon.com/cli/latest/reference/s3/ls.html>.

- Вывести список всех бакетов:

`aws s3 ls`

- Вывести список файлов и каталогов в корне бакета (`s3://` необязателен):

`aws s3 ls s3://{{имя_бакета}}`

- Вывести список файлов и каталогов непосредственно внутри каталога:

`aws s3 ls {{имя_бакета}}/{{путь/к/каталогу}}/`

- Вывести список всех файлов в бакете:

`aws s3 ls --recursive {{имя_бакета}}`

- Вывести список всех файлов по указанному пути с заданным префиксом:

`aws s3 ls --recursive {{имя_бакета}}/{{путь/к/каталогу}}/{{префикс}}`

- Показать справку:

`aws s3 ls help`
