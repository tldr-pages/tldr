# git mergetool

> Запускать инструменты разрешения конфликтов слияния для разрешения конфликтов слияния.
> Больше информации: <https://git-scm.com/docs/git-mergetool>.

- Запустить инструмент слияния по умолчанию для разрешения конфликтов:

`git mergetool`

- Вывести список допустимых инструментов слияния:

`git mergetool --tool-help`

- Запустить инструмент слияния, указанный по имени:

`git mergetool {{[-t|--tool]}} {{имя_инструмента}}`

- Не запрашивать подтверждение перед каждым вызовом инструмента слияния:

`git mergetool {{[-y|--no-prompt]}}`

- Явно использовать графический инструмент слияния (см. переменную конфигурации `merge.guitool`):

`git mergetool {{[-g|--gui]}}`

- Явно использовать обычный инструмент слияния (см. переменную конфигурации `merge.tool`):

`git mergetool --no-gui`
