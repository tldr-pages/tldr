# rabbitmq-plugins

> Управлять плагинами RabbitMQ.
> Больше информации: <https://www.rabbitmq.com/docs/man/rabbitmq-plugins.8>.

- Вывести список плагинов:

`rabbitmq-plugins list`

- Включить плагин:

`rabbitmq-plugins enable {{плагин}}`

- Отключить плагин:

`rabbitmq-plugins disable {{плагин}}`

- Включить плагин и отключить остальные:

`rabbitmq-plugins set {{плагин}}`
