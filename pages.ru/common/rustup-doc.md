# rustup doc

> Открывать локальную документацию Rust для текущего набора инструментов.
> Существует множество других страниц документации, не упомянутых здесь. Подробнее см. `rustup help doc`.
> Больше информации: <https://rust-lang.github.io/rustup/>.

- Открыть главную страницу:

`rustup doc`

- Открыть документацию по конкретной теме (модуль стандартной библиотеки, тип, ключевое слово и т.д.):

`rustup doc {{std::fs|usize|fn|...}}`

- Открыть книгу The Rust Programming Language:

`rustup doc --book`

- Открыть книгу Cargo:

`rustup doc --cargo`

- Открыть справочник Rust:

`rustup doc --reference`
