# npm unstar

> Удалять отметку избранного у пакета.
> Больше информации: <https://docs.npmjs.com/cli/v11/npm-unstar>.

- Удалить из избранного публичный пакет из реестра по умолчанию:

`npm unstar {{имя_пакета}}`

- Удалить из избранного пакет в определённой области видимости:

`npm unstar @{{область_видимости}}/{{имя_пакета}}`

- Удалить из избранного пакет из определённого реестра:

`npm unstar {{имя_пакета}} --registry {{url_реестра}}`

- Удалить из избранного приватный пакет, требующий аутентификации:

`npm unstar {{имя_пакета}} --auth-type {{legacy|oauth|web|saml}}`

- Удалить пакет из избранного, указав одноразовый пароль для двухфакторной аутентификации:

`npm unstar {{имя_пакета}} --otp {{одноразовый_пароль}}`

- Удалить пакет из избранного с определённым уровнем логирования:

`npm unstar {{имя_пакета}} --loglevel {{silent|error|warn|notice|http|timing|info|verbose|silly}}`
