# pixi project

> Изменять файл конфигурации проекта.
> Больше информации: <https://pixi.sh/latest/reference/cli/#project>.

- Управлять каналами проекта:

`pixi project channel {{команда}}`

- Управлять описанием проекта:

`pixi project description {{команда}}`

- Управлять платформой проекта:

`pixi project platform {{команда}}`

- Управлять версией проекта:

`pixi project version {{команда}}`

- Управлять окружением проекта:

`pixi project environment {{команда}}`
