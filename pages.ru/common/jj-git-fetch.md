# jj git fetch

> Получать объекты и ссылки из удалённого Git-репозитория.
> Больше информации: <https://docs.jj-vcs.dev/latest/cli-reference/#jj-git-fetch>.

- Получить последние изменения из удалённого репозитория по умолчанию:

`jj git fetch`

- Получить последние изменения из указанного удалённого репозитория:

`jj git fetch --remote {{удалённый_репозиторий}}`

- Получить последние изменения только из указанных веток:

`jj git fetch {{[-b|--branch]}} {{ветка}}`

- Получить последние изменения из всех удалённых репозиториев:

`jj git fetch --all-remotes`
