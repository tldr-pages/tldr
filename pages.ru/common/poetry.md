# poetry

> Управлять пакетами и зависимостями Python.
> Некоторые подкоманды, такие как `about`, `check`, `env` и другие, имеют собственную документацию по использованию.
> Смотрите также: `asdf`, `pipenv`, `hatch`.
> Больше информации: <https://python-poetry.org/docs/cli/>.

- Создать новый проект Poetry в каталоге с указанным именем:

`poetry new {{имя_проекта}}`

- Установить зависимость и добавить её вместе с подзависимостями в файл `pyproject.toml` в текущем каталоге:

`poetry add {{зависимость}}`

- Установить зависимости проекта, используя файл `pyproject.toml` в текущем каталоге:

`poetry install`

- Интерактивно (добавьте `-n` для неинтерактивного режима) инициализировать текущий каталог как новый проект Poetry:

`poetry init`

- Получить последние версии всех зависимостей и обновить `poetry.lock`:

`poetry update`

- Выполнить команду внутри виртуального окружения проекта:

`poetry run {{команда}}`

- Повысить версию проекта в `pyproject.toml`:

`poetry version {{patch|minor|major|prepatch|preminor|premajor|prerelease}}`

- Запустить оболочку внутри виртуального окружения проекта (для версий ниже 2.0 используйте `poetry shell`):

`eval "$(poetry env activate)"`
