# tailscale

> Сервис частной сети на основе WireGuard.
> Некоторые подкоманды, такие как `up`, имеют собственную документацию по использованию.
> Больше информации: <https://tailscale.com/kb/1080/cli>.

- Разрешить текущему пользователю управлять демоном Tailscale:

`sudo tailscale set --operator $USER`

- Управлять подключением к Tailscale (подключиться, отключиться, проверить статус):

`tailscale {{up|down|status}}`

- Предложить текущую машину в качестве выходного узла для интернет-трафика:

`tailscale set --advertise-exit-node`

- Использовать конкретный выходной узел для интернет-трафика:

`tailscale set --exit-node {{ip_адрес|имя_хоста}}`

- Пропинговать одноранговый узел на уровне Tailscale и показать, какой маршрут был использован для каждого ответа:

`tailscale ping {{ip_адрес|имя_хоста}}`

- Проанализировать состояние локальной сети и показать результат:

`tailscale netcheck`

- Запустить веб-сервер для управления демоном Tailscale:

`tailscale web`

- Показать общий идентификатор для диагностики проблем:

`tailscale bugreport`
