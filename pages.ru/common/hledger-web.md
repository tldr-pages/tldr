# hledger-web

> Веб-интерфейс и API для `hledger`, надёжного и удобного приложения для учёта финансов в текстовом формате.
> Больше информации: <https://hledger.org/hledger-web.html>.

- Запустить веб-приложение и, если возможно, браузер, только для локального просмотра и добавления записей:

`hledger-web`

- Запустить веб-приложение с конкретным файлом, разрешив редактирование существующих данных:

`hledger-web {{[-f|--file]}} {{путь/к/файлу.journal}} --allow edit`

- Запустить только веб-приложение и принимать входящие подключения к указанному хосту и порту:

`hledger-web --serve --host {{my.host.name}} --port 8000`

- Запустить только JSON API веб-приложения и разрешить доступ только для чтения:

`hledger-web --serve-api --host {{my.host.name}} --allow view`

- Показать суммы, конвертированные в текущую рыночную стоимость в базовой валюте, если известна:

`hledger-web --value now --infer-market-prices`

- Показать руководство в формате Info, если доступно:

`hledger-web --info`

- Показать справку:

`hledger-web {{[-h|--help]}}`
