# hledger-ui

> Терминальный интерфейс (TUI) для `hledger`, надёжного и удобного приложения для учёта финансов в текстовом формате.
> Больше информации: <https://hledger.org/hledger-ui.html>.

- Запустить в главном меню, читая из файла журнала по умолчанию:

`hledger-ui`

- Запустить с другой цветовой темой:

`hledger-ui --theme {{terminal|greenterm|dark}}`

- Запустить на экране балансового отчёта, показывая иерархию до 3-го уровня:

`hledger-ui --bs {{[-t|--tree]}} {{[-3|--depth 3]}}`

- Запустить на экране данного счёта, показывая подтверждённые транзакции, с автообновлением при изменениях:

`hledger-ui --register {{assets:bank:checking}} {{[-C|--cleared]}} {{[-w|--watch]}}`

- Прочитать два файла журнала и показать суммы в текущей стоимости, если известна:

`hledger-ui {{[-f|--file]}} {{путь/к/2024.journal}} {{[-f|--file]}} {{путь/к/2024-prices.journal}} --value now`

- Показать руководство в формате Info, если доступно:

`hledger-ui --info`

- Показать справку:

`hledger-ui {{[-h|--help]}}`
