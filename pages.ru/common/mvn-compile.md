# mvn compile

> Компилировать исходный код проекта Maven.
> Больше информации: <https://manned.org/mvn>.

- Скомпилировать исходный код проекта:

`mvn compile`

- Очистить скомпилированные файлы и перекомпилировать:

`mvn clean compile`

- Скомпилировать конкретный модуль в многомодульном проекте:

`mvn compile {{[-pl|--projects]}} {{имя_модуля}}`

- Пропустить тесты при компиляции:

`mvn compile {{[-D|--define]}} skipTests`
