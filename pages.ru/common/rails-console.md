# rails console

> Взаимодействовать с приложением Rails.
> Больше информации: <https://guides.rubyonrails.org/command_line.html#bin-rails-console>.

- Запустить консоль Rails:

`rails console`

- Запустить консоль Rails с откатом всех изменений данных при выходе:

`rails console {{[-s|--sandbox]}}`

- Запустить консоль Rails в конкретном окружении:

`rails console {{[-e|--environment]}} {{dev|test|production|...}}`

- Показать справку:

`rails console {{[-h|--help]}}`
