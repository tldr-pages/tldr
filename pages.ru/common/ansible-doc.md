# ansible-doc

> Отображать информацию о модулях, установленных в библиотеках Ansible.
> Выводить краткий список плагинов и их описания.
> Больше информации: <https://docs.ansible.com/projects/ansible/latest/cli/ansible-doc.html>.

- Вывести список доступных плагинов действий (модулей):

`ansible-doc {{[-l|--list]}}`

- Вывести список доступных плагинов определённого типа:

`ansible-doc {{[-t|--type]}} {{become|cache|callback|cliconf|connection|...}} {{[-l|--list]}}`

- Показать информацию об определённом плагине действия (модуле):

`ansible-doc {{имя_плагина}}`

- Показать информацию о плагине определённого типа:

`ansible-doc {{[-t|--type]}} {{become|cache|callback|cliconf|connection|...}} {{имя_плагина}}`

- Показать фрагмент playbook для плагина действия (модуля):

`ansible-doc {{[-s|--snippet]}} {{имя_плагина}}`

- Показать информацию о плагине действия (модуле) в формате JSON:

`ansible-doc {{[-j|--json]}} {{имя_плагина}}`
