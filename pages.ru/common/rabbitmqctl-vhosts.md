# rabbitmqctl-vhosts

> Управлять виртуальными хостами (vhosts) в RabbitMQ.
> Виртуальные хосты используются для разделения нескольких логических брокеров на одном сервере RabbitMQ.
> Больше информации: <https://www.rabbitmq.com/docs/vhosts>.

- Вывести список всех виртуальных хостов:

`rabbitmqctl list_vhosts`

- Добавить новый виртуальный хост:

`rabbitmqctl add_vhost {{имя_виртуального_хоста}}`

- Удалить виртуальный хост:

`rabbitmqctl delete_vhost {{имя_виртуального_хоста}}`

- Установить разрешения для пользователя на конкретном виртуальном хосте:

`rabbitmqctl set_permissions {{[-p|--vhost]}} {{имя_виртуального_хоста}} {{имя_пользователя}} {{чтение}} {{запись}} {{настройка}}`

- Очистить разрешения для пользователя на конкретном виртуальном хосте:

`rabbitmqctl clear_permissions {{[-p|--vhost]}} {{имя_виртуального_хоста}} {{имя_пользователя}}`
