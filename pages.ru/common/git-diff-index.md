# git diff-index

> Сравнивать рабочий каталог с коммитом или объектом дерева.
> Больше информации: <https://git-scm.com/docs/git-diff-index>.

- Сравнить рабочий каталог с определённым коммитом:

`git diff-index {{коммит}}`

- Сравнить определённый файл или каталог в рабочем каталоге с коммитом:

`git diff-index {{коммит}} {{путь/к/файлу_или_каталогу}}`

- Сравнить рабочий каталог с индексом (областью подготовки) для проверки проиндексированных изменений:

`git diff-index --cached {{коммит}}`

- Подавить вывод и вернуть код завершения для проверки наличия различий:

`git diff-index --quiet {{коммит}}`
