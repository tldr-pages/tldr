# bun pm pack

> Создавать архив `.tgz`, содержащий файлы, которые будут опубликованы в npm (аналог `npm pack`).
> Больше информации: <https://bun.com/docs/pm/cli/pm#pack>.

- Создать архив из текущего рабочего пространства:

`bun pm pack`

- Симулировать создание архива, выполнив все этапы без записи на диск:

`bun pm pack --dry-run`

- Сохранить архив в указанный каталог:

`bun pm pack --destination {{путь/к/каталогу}}`

- Указать точное имя файла архива:

`bun pm pack --filename {{имя_файла}}`

- Пропустить скрипты prepack, postpack и prepare:

`bun pm pack --ignore-scripts`

- Установить уровень сжатия `gzip` (0-9, по умолчанию: 9):

`bun pm pack --gzip-level 5`

- Вывести только имя файла архива без подробных логов:

`bun pm pack --quiet`
