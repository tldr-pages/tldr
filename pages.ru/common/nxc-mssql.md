# nxc mssql

> Тестировать на проникновение и эксплуатировать серверы Microsoft SQL.
> Больше информации: <https://www.netexec.wiki/mssql-protocol/mssql-passwordspray>.

- Найти действительные учётные данные, перебирая все комбинации из указанных списков имён пользователей и паролей:

`nxc mssql {{192.168.178.2}} {{[-u|--username]}} {{путь/к/именам_пользователей.txt}} {{[-p|--password]}} {{путь/к/паролям.txt}}`

- Выполнить указанный SQL-запрос на целевом сервере:

`nxc mssql {{192.168.178.2}} {{[-u|--username]}} {{имя_пользователя}} {{[-p|--password]}} {{пароль}} {{[-q|--query]}} '{{SELECT * FROM sys.databases;}}'`

- Выполнить указанную команду оболочки на целевом сервере через MSSQL:

`nxc mssql {{192.168.178.2}} {{[-u|--username]}} {{имя_пользователя}} {{[-p|--password]}} {{пароль}} -x {{whoami}}`

- Выполнить указанную команду PowerShell на целевом сервере через MSSQL без получения вывода:

`nxc mssql {{192.168.178.2}} {{[-u|--username]}} {{имя_пользователя}} {{[-p|--password]}} {{пароль}} -X {{whoami}} --no-output`

- Скачать удалённый файл с целевого сервера и сохранить в указанное расположение:

`nxc mssql {{192.168.178.2}} {{[-u|--username]}} {{имя_пользователя}} {{[-p|--password]}} {{пароль}} --get-file {{C:\путь\к\удалённому_файлу}} {{путь/к/локальному_файлу}}`

- Загрузить локальный файл в указанное расположение на целевом сервере:

`nxc mssql {{192.168.178.2}} {{[-u|--username]}} {{имя_пользователя}} {{[-p|--password]}} {{пароль}} --put-file {{путь/к/локальному_файлу}} {{C:\путь\к\удалённому_файлу}}`
