# openssl speed

> Тестировать производительность алгоритмов OpenSSL.
> Больше информации: <https://docs.openssl.org/master/man1/openssl-speed/>.

- Протестировать все доступные алгоритмы:

`openssl speed`

- Протестировать наиболее распространённые алгоритмы:

`openssl speed {{md5 sha1 sha256 aes rsa}}`

- Протестировать конкретный шифр EVP:

`openssl speed -evp {{aes-256-cbc}}`

- Протестировать алгоритмы в течение указанного времени (в секундах):

`openssl speed -seconds {{10}}`

- Протестировать с использованием реального времени вместо пользовательского процессорного времени:

`openssl speed -elapsed`

- Вывести результат в машиночитаемом формате:

`openssl speed -mr`

- Протестировать несколько алгоритмов параллельно, используя все доступные ядра процессора:

`openssl speed -multi $(nproc)`
