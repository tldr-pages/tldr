# jj config get

> Получать значение указанного параметра конфигурации.
> В отличие от `jj config list`, результат выводится без дополнительного форматирования для использования в скриптах.
> Смотрите также: `jj config list`.
> Больше информации: <https://docs.jj-vcs.dev/latest/cli-reference/#jj-config-get>.

- Получить значение параметра конфигурации:

`jj config {{[g|get]}} {{имя}}`

- Получить настроенное имя пользователя:

`jj config {{[g|get]}} user.name`

- Получить настроенный адрес электронной почты пользователя:

`jj config {{[g|get]}} user.email`

- Получить набор ревизий по умолчанию для команды log:

`jj config {{[g|get]}} revsets.log`
