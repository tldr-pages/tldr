# javac

> Компилятор Java-приложений.
> Больше информации: <https://docs.oracle.com/en/java/javase/25/docs/specs/man/javac.html>.

- Скомпилировать файл `.java`:

`javac {{путь/к/файлу.java}}`

- Скомпилировать несколько файлов `.java`:

`javac {{путь/к/файлу1.java путь/к/файлу2.java ...}}`

- Скомпилировать все файлы `.java` в текущем каталоге:

`javac {{*.java}}`

- Скомпилировать файл `.java` и поместить итоговый class-файл в указанный каталог:

`javac -d {{путь/к/каталогу}} {{путь/к/файлу.java}}`
