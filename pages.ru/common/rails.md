# rails

> Серверный MVC-фреймворк, написанный на Ruby.
> Некоторые подкоманды, такие как `generate`, имеют собственную документацию по использованию.
> Больше информации: <https://guides.rubyonrails.org/command_line.html>.

- Создать новый проект Rails:

`rails new "{{имя_проекта}}"`

- Сгенерировать каркас для модели Post, задав атрибуты title и body:

`rails generate scaffold Post title:string body:text`

- Запустить миграции:

`rails db:migrate`

- Вывести список всех маршрутов:

`rails routes`

- Запустить локальный сервер для текущего проекта на порту 3000:

`rails server`

- Запустить локальный сервер для текущего проекта на конкретном порту:

`rails server {{[-p|--port]}} "{{порт}}"`

- Открыть консоль для взаимодействия с приложением из командной строки:

`rails console`

- Показать версию:

`rails {{[-v|--version]}}`
