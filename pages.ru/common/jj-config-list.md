# jj config list

> Выводить список переменных, заданных в файлах конфигурации, вместе с их значениями.
> Смотрите также: `jj config get`.
> Больше информации: <https://docs.jj-vcs.dev/latest/cli-reference/#jj-config-list>.

- Вывести список всех переменных конфигурации и их значений:

`jj config {{[l|list]}}`

- Вывести конкретный параметр конфигурации:

`jj config {{[l|list]}} {{имя}}`

- Вывести список переменных конфигурации уровня пользователя:

`jj config {{[l|list]}} --user`

- Вывести список переменных конфигурации уровня репозитория:

`jj config {{[l|list]}} --repo`

- Вывести список переменных конфигурации, включая встроенные значения по умолчанию:

`jj config {{[l|list]}} --include-defaults`

- Вывести список переменных конфигурации, включая переопределённые значения:

`jj config {{[l|list]}} --include-overridden`

- Вывести список переменных конфигурации с пользовательским шаблоном:

`jj config {{[l|list]}} {{[-T|--template]}} {{шаблон}}`
