# jj file track

> Начинать отслеживание указанных путей в рабочей копии репозитория `jj`.
> Смотрите также: `jj file untrack`.
> Больше информации: <https://docs.jj-vcs.dev/latest/cli-reference/#jj-file-track>.

- Начать отслеживание всех неотслеживаемых файлов в рабочей копии:

`jj file track`

- Начать отслеживание конкретного файла или каталога:

`jj file track {{путь/к/файлу_или_каталогу}}`

- Начать отслеживание нескольких путей:

`jj file track {{путь/к/файлу1 путь/к/каталогу2 ...}}`

- Начать отслеживание путей, даже если они игнорируемые или превышают максимальный размер файла:

`jj file track --include-ignored {{путь/к/файлу_или_каталогу}}`
