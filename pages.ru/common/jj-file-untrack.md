# jj file untrack

> Прекращать отслеживание указанных путей в рабочей копии репозитория `jj`.
> Пути уже должны быть игнорируемыми (например, через `.gitignore`).
> Смотрите также: `jj file track`.
> Больше информации: <https://docs.jj-vcs.dev/latest/cli-reference/#jj-file-untrack>.

- Прекратить отслеживание игнорируемого файла или каталога:

`jj file untrack {{путь/к/файлу_или_каталогу}}`

- Прекратить отслеживание нескольких игнорируемых путей:

`jj file untrack {{путь/к/файлу1 путь/к/каталогу2 ...}}`
