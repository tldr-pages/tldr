# git ls-tree

> Выводить содержимое объекта дерева.
> Больше информации: <https://git-scm.com/docs/git-ls-tree>.

- Вывести содержимое дерева ветки:

`git ls-tree {{имя_ветки}}`

- Вывести содержимое дерева коммита, рекурсивно обходя поддеревья:

`git ls-tree -r {{хеш_коммита}}`

- Вывести только имена файлов дерева коммита:

`git ls-tree --name-only {{хеш_коммита}}`

- Вывести имена файлов текущей ветки HEAD в виде древовидной структуры (Примечание: `tree --fromfile` не поддерживается в Windows):

`git ls-tree -r --name-only HEAD | tree --fromfile`
