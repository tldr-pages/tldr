# hledger import

> Импортировать новые транзакции из одного или нескольких файлов данных в основной журнал.
> Больше информации: <https://hledger.org/hledger.html#import>.

- Импортировать новые транзакции из `bank.csv`, используя `bank.csv.rules` для преобразования:

`hledger import {{путь/к/bank.csv}}`

- Сымитировать импорт из этих двух файлов, показав, что будет импортировано:

`hledger import {{путь/к/bank1.csv}} {{путь/к/bank2.csv}} --dry-run`

- Импортировать новые транзакции из всех CSV-файлов, используя одни и те же правила для всех:

`hledger import --rules-file {{common.rules}} *.csv`

- Показать ошибки преобразования или результаты при редактировании `bank.csv.rules`:

`watchexec -- hledger {{[-f|--file]}} {{путь/к/bank.csv}} print`

- Пометить текущие данные `bank.csv` как просмотренные, как если бы они уже были импортированы:

`hledger import --catchup {{путь/к/bank.csv}}`

- Пометить `bank.csv` как полностью новый, как если бы он ещё не был импортирован:

`rm {{[-f|--force]}} .latest.bank.csv`
