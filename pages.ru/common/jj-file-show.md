# jj file show

> Выводить содержимое файлов в ревизии репозитория `jj`.
> Больше информации: <https://docs.jj-vcs.dev/latest/cli-reference/#jj-file-show>.

- Вывести содержимое файла в рабочей копии:

`jj file show {{путь/к/файлу}}`

- Вывести содержимое файла в конкретной ревизии:

`jj file show {{[-r|--revision]}} {{ревизия}} {{путь/к/файлу}}`

- Вывести содержимое всех файлов в каталоге рекурсивно:

`jj file show {{путь/к/каталогу}}`

- Вывести метаданные файла с использованием пользовательского шаблона:

`jj file show {{[-T|--template]}} "{{шаблон}}" {{путь/к/файлу}}`
