# docker node

> Управлять узлами Docker Swarm.
> Больше информации: <https://docs.docker.com/reference/cli/docker/node/>.

- Вывести список узлов в swarm:

`docker node ls`

- Вывести список задач, выполняющихся на одном или нескольких узлах (по умолчанию текущий узел):

`docker node ps {{узел1 узел2 узел3 ...}}`

- Показать подробную информацию об одном или нескольких узлах:

`docker node inspect {{узел1 узел2 узел3 ...}}`

- Повысить один или несколько узлов до менеджера в swarm:

`docker node promote {{узел1 узел2 узел3 ...}}`

- Понизить один или несколько узлов с менеджера в swarm:

`docker node demote {{узел1 узел2 узел3 ...}}`

- Удалить один или несколько узлов из swarm:

`docker node rm {{узел1 узел2 узел3 ...}}`

- Обновить метаданные узла, такие как доступность, метки или роли:

`docker node update --{{availability|role|label-add|...}} {{active|worker|...}} {{узел1}}`
