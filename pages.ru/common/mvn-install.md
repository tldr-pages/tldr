# mvn install

> Устанавливать сторонние зависимости Maven и собирать проект.
> Больше информации: <https://manned.org/mvn>.

- Скомпилировать, протестировать, упаковать и установить проект в локальный репозиторий:

`mvn install`

- Пропустить тесты во время установки:

`mvn install {{[-D|--define]}} skipTests`

- Принудительно обновить зависимости перед установкой:

`mvn install {{[-U|--update-snapshots]}}`

- Пропустить компиляцию и выполнение тестов:

`mvn install {{[-D|--define]}} maven.test.skip=true`
