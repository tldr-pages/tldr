# elasticsearch-syskeygen

> Создавать файл системного ключа в каталоге конфигурации Elasticsearch.
> Больше информации: <https://www.elastic.co/docs/reference/elasticsearch/command-line-tools/syskeygen>.

- Сгенерировать файл `system_key` в каталоге `$ES_HOME/config` по умолчанию:

`elasticsearch-syskeygen`
