# git difftool

> Показывать изменения файлов с помощью внешних инструментов сравнения. Принимает те же опции и аргументы, что и `git diff`.
> Смотрите также: `git diff`.
> Больше информации: <https://git-scm.com/docs/git-difftool>.

- Вывести список доступных инструментов сравнения:

`git difftool --tool-help`

- Установить Meld в качестве инструмента сравнения по умолчанию:

`git config --global diff.tool "meld"`

- Использовать инструмент сравнения по умолчанию для показа проиндексированных изменений:

`git difftool --staged`

- Использовать определённый инструмент для показа изменений с указанного коммита:

`git difftool {{[-t|--tool]}} {{opendiff}} {{коммит}}`
