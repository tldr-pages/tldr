# jj file search

> Искать содержимое в файлах в репозитории `jj`.
> Больше информации: <https://docs.jj-vcs.dev/latest/cli-reference/#jj-file-search>.

- Найти файлы со строками, соответствующими `regex`, в рабочей копии:

`jj file search {{[-p|--pattern]}} "{{regex}}"`

- Найти файлы со строками, соответствующими шаблону `glob`, в рабочей копии:

`jj file search {{[-p|--pattern]}} "{{glob:*шаблон*}}"`

- Найти содержимое в файлах в конкретной ревизии:

`jj file search {{[-r|--revision]}} {{ревизия}} {{[-p|--pattern]}} "{{шаблон}}"`

- Выполнить поиск только в указанных путях или файлах:

`jj file search {{[-p|--pattern]}} "{{шаблон}}" {{путь/к/файлу_или_каталогу}}`
