# git diff-files

> Сравнивать файлы, используя их sha1-хеши и режимы.
> Больше информации: <https://git-scm.com/docs/git-diff-files>.

- Сравнить все изменённые файлы:

`git diff-files`

- Сравнить только указанные файлы:

`git diff-files {{путь/к/файлу}}`

- Показать только имена изменённых файлов:

`git diff-files --name-only`

- Вывести сводку расширенной информации заголовков:

`git diff-files --summary`
