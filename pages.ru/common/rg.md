# rg

> Ripgrep — рекурсивный построчный инструмент поиска.
> Стремится быть более быстрой альтернативой `grep`.
> Больше информации: <https://github.com/BurntSushi/ripgrep/blob/master/GUIDE.md>.

- Рекурсивно искать шаблон (`regex`) в текущем каталоге:

`rg {{шаблон}}`

- Рекурсивно искать шаблон в файле или каталоге:

`rg {{шаблон}} {{путь/к/файлу_или_каталогу}}`

- Искать строку буквально, без интерпретации шаблона ([F]ixed-strings):

`rg {{[-F|--fixed-strings]}} -- {{строка}}`

- Включить в поиск скрытые файлы и записи, перечисленные в `.gitignore`:

`rg {{[-.|--hidden]}} --no-ignore {{шаблон}}`

- Искать только в файлах, соответствующих [g]lob-шаблонам (например, `README.*`; используйте `!шаблон_имени_файла` для исключения):

`rg {{шаблон}} {{[-g|--glob]}} {{глоб_шаблон_имени_файла}}`

- Рекурсивно вывести имена файлов в текущем каталоге, соответствующие шаблону:

`rg --files | rg {{шаблон}}`

- Вывести только имена файлов с совпадениями ([l]ist; полезно при передаче вывода другим командам):

`rg {{[-l|--files-with-matches]}} {{шаблон}}`

- Показать строки, не соответствующие шаблону (in[v]ert-match):

`rg {{[-v|--invert-match]}} {{шаблон}}`
