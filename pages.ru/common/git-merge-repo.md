# git merge-repo

> Выполнять слияние историй двух репозиториев.
> Часть `git-extras`.
> Больше информации: <https://github.com/tj/git-extras/blob/main/Commands.md#git-merge-repo>.

- Выполнить слияние ветки репозитория в каталог текущего репозитория:

`git merge-repo {{путь/к/репозиторию}} {{имя_ветки}} {{путь/к/каталогу}}`

- Выполнить слияние ветки удалённого репозитория в каталог текущего репозитория без сохранения истории:

`git merge-repo {{путь/к/удалённому_репозиторию}} {{имя_ветки}} .`
