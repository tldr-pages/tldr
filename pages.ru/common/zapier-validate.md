# zapier validate

> Проверять интеграцию Zapier.
> Больше информации: <https://github.com/zapier/zapier-platform/blob/main/packages/cli/docs/cli.md#validate>.

- Проверить интеграцию:

`zapier validate`

- Проверить интеграцию без проверки стиля:

`zapier validate --without-style`

- Проверить интеграцию без выполнения скрипта сборки:

`zapier validate --skip-build`

- Проверить интеграцию с дополнительной отладочной информацией:

`zapier validate {{[-d|--debug]}}`

- Проверить интеграцию с другим форматом вывода:

`zapier validate {{[-f|--format]}} {{plain|json|raw|row|table}}`
