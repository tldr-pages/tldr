# git merge-base

> Находить общего предка двух коммитов.
> Больше информации: <https://git-scm.com/docs/git-merge-base>.

- Вывести лучшего общего предка двух коммитов:

`git merge-base {{коммит_1}} {{коммит_2}}`

- Вывести всех лучших общих предков двух коммитов:

`git merge-base {{[-a|--all]}} {{коммит_1}} {{коммит_2}}`

- Проверить, является ли коммит предком определённого коммита:

`git merge-base --is-ancestor {{коммит_предок}} {{коммит}}`
