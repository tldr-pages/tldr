# jj config path

> Выводить пути к файлам конфигурации.
> Смотрите также: `jj config edit`.
> Больше информации: <https://docs.jj-vcs.dev/latest/cli-reference/#jj-config-path>.

- Вывести путь к файлу конфигурации уровня пользователя:

`jj config {{[p|path]}} --user`

- Вывести путь к файлу конфигурации уровня репозитория:

`jj config {{[p|path]}} --repo`

- Вывести путь к файлу конфигурации уровня рабочего пространства:

`jj config {{[p|path]}} --workspace`
