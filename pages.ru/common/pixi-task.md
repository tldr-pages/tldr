# pixi task

> Управлять задачами в окружении проекта.
> Больше информации: <https://pixi.sh/latest/reference/cli/#task>.

- Создать новую задачу:

`pixi task add {{имя_задачи}} {{команда_задачи}}`

- Вывести список всех задач в проекте:

`pixi task list`

- Удалить задачу:

`pixi task remove {{имя_задачи}}`

- Создать псевдоним для задачи:

`pixi task alias {{имя_псевдонима}} {{задача1 задача2 ...}}`
