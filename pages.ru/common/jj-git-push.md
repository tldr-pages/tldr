# jj git push

> Отправлять изменения в удалённый Git-репозиторий.
> Больше информации: <https://docs.jj-vcs.dev/latest/cli-reference/#jj-git-push>.

- Отправить закладку в указанный удалённый репозиторий:

`jj git push {{[-b|--bookmark]}} {{закладка}} --remote {{удалённый_репозиторий}}`

- Отправить новую закладку:

`jj git push {{[-b|--bookmark]}} {{закладка}} {{[-N|--allow-new]}}`

- Отправить все отслеживаемые закладки:

`jj git push --tracked`

- Отправить все закладки (включая новые):

`jj git push --all`

- Отправить все закладки, указывающие на заданные ревизии:

`jj git push {{[-r|--revisions]}} {{revset}}`

- Отправить изменения/коммиты, создавая новые закладки (формат имён определяется настройкой `templates.git_push_bookmark`, по умолчанию `"push-" ++ change_id.short()`):

`jj git push {{[-c|--change]}} {{revset}}`

- Создать закладку с указанным именем для ревизии и отправить её в удалённый репозиторий:

`jj git push --named {{имя}}={{ревизия}}`
