# nxc winrm

> Тестировать на проникновение и эксплуатировать Windows Remote Management (WinRM).
> Больше информации: <https://www.netexec.wiki/winrm-protocol/password-spraying>.

- Найти действительные учётные данные, перебирая все комбинации из указанных списков имён пользователей и паролей:

`nxc winrm {{192.168.178.2}} {{[-u|--username]}} {{путь/к/именам_пользователей.txt}} {{[-p|--password]}} {{путь/к/паролям.txt}}`

- Указать домен для аутентификации (без предварительного SMB-подключения):

`nxc winrm {{192.168.178.2}} {{[-u|--username]}} {{имя_пользователя}} {{[-p|--password]}} {{пароль}} -d {{имя_домена}}`

- Выполнить указанную команду на хосте:

`nxc winrm {{192.168.178.2}} {{[-u|--username]}} {{имя_пользователя}} {{[-p|--password]}} {{пароль}} -x {{whoami}}`

- Выполнить указанную команду PowerShell на хосте от имени администратора с использованием LAPS:

`nxc winrm {{192.168.178.2}} {{[-u|--username]}} {{имя_пользователя}} {{[-p|--password]}} {{пароль}} --laps -X {{whoami}}`
