# hyperfine

> Инструмент для замера производительности.
> Больше информации: <https://manned.org/hyperfine>.

- Выполнить базовый замер, проведя не менее 10 запусков:

`hyperfine '{{make}}'`

- Выполнить сравнительный замер:

`hyperfine '{{make target1}}' '{{make target2}}'`

- Изменить минимальное количество запусков:

`hyperfine {{[-m|--min-runs]}} {{7}} '{{make}}'`

- Выполнить замер с предварительным прогревом (warmup):

`hyperfine {{[-w|--warmup]}} {{5}} '{{make}}'`

- Выполнить команду перед каждым запуском замера (например, для очистки кэша):

`hyperfine {{[-p|--prepare]}} '{{make clean}}' '{{make}}'`

- Выполнить замер, изменяя один параметр при каждом запуске:

`hyperfine {{[-p|--prepare]}} '{{make clean}}' {{[-P|--parameter-scan]}} {{количество_потоков}} {{1}} {{10}} '{{make --jobs {количество_потоков}}}'`
