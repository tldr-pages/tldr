# glab repo

> Работать с репозиториями GitLab.
> Больше информации: <https://gitlab.com/gitlab-org/cli/-/blob/main/docs/source/repo/_index.md>.

- Создать новый репозиторий (если имя репозитория не указано, по умолчанию используется имя текущего каталога):

`glab repo create {{имя}}`

- Клонировать репозиторий:

`glab repo clone {{владелец}}/{{репозиторий}}`

- Создать форк репозитория и клонировать его:

`glab repo fork {{владелец}}/{{репозиторий}} {{[-c|--clone]}}`

- Открыть репозиторий в браузере по умолчанию:

`glab repo view {{владелец}}/{{репозиторий}} {{[-w|--web]}}`

- Найти репозитории в экземпляре GitLab:

`glab repo search {{[-s|--search]}} {{строка_поиска}}`
