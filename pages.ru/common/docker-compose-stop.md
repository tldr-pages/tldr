# docker compose stop

> Останавливать запущенные контейнеры без их удаления.
> Больше информации: <https://docs.docker.com/reference/cli/docker/compose/stop>.

- Остановить все запущенные сервисы:

`docker compose stop`

- Остановить определённые сервисы:

`docker compose stop {{сервис_1 сервис_2 ...}}`

- Остановить с пользовательским таймаутом завершения в секундах:

`docker compose stop {{[-t|--timeout]}} {{секунды}}`

- Остановить сервисы, определённые в конкретном compose-файле:

`docker compose {{[-f|--file]}} {{путь/к/compose_файлу}} stop`

- Симулировать выполнение операций без их фактического выполнения:

`docker compose stop --dry-run`

- Остановить определённые сервисы с пользовательским таймаутом:

`docker compose stop {{[-t|--timeout]}} {{секунды}} {{сервис_1 сервис_2 ...}}`
