# aws s3 presign

> Генерировать предподписанные URL-адреса для объектов Amazon S3.
> Больше информации: <https://docs.aws.amazon.com/cli/latest/reference/s3/presign.html>.

- Сгенерировать предподписанный URL-адрес для конкретного объекта S3, действительный в течение одного часа:

`aws s3 presign s3://{{имя_бакета}}/{{путь/к/файлу}}`

- Сгенерировать предподписанный URL-адрес, действительный в течение указанного времени:

`aws s3 presign s3://{{имя_бакета}}/{{путь/к/файлу}} --expires-in {{длительность_в_секундах}}`

- Показать справку:

`aws s3 presign help`
