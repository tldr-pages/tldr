# pixi

> Управление рабочим процессом разработки и окружениями проектов.
> Больше информации: <https://pixi.prefix.dev/latest/getting_started/>.

- Инициализировать новый проект:

`pixi init {{путь/к/проекту}}`

- Добавить зависимости проекта:

`pixi add {{зависимость1 зависимость2 ...}}`

- Запустить оболочку pixi в окружении проекта:

`pixi shell`

- Выполнить задачу в окружении проекта:

`pixi run {{задача}}`

- Управлять задачами в окружении проекта:

`pixi task {{команда}}`

- Очистить окружение и кэш задач:

`pixi clean`

- Показать справку:

`pixi {{команда}} --help`
