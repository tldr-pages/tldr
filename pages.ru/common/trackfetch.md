# trackfetch

> Скачивать песни, перечисленные в текстовом файле или в командной строке, как файлы MP3, M4A или Opus с тегами, используя настраиваемые источники метаданных и звук из YouTube.
> Требуются `yt-dlp`, `ffmpeg` и `deno`. Spotify необязателен и используется только при явном выборе.
> Больше информации: <https://github.com/ByteMe6/trackfetch#usage>.

- Скачать каждую песню из файла, где на каждой строке `Исполнитель - Название`, в текущий каталог:

`trackfetch {{путь/к/файлу.txt}}`

- Скачать песни в конкретный каталог:

`trackfetch {{путь/к/файлу.txt}} {{[-o|--output]}} {{путь/к/каталогу}}`

- Скачать один или несколько треков, переданных аргументами, вместо текстового файла:

`trackfetch {{"Исполнитель1 - Название1" "Исполнитель2 - Название2" ...}}`

- Выбрать источники метаданных (по умолчанию используется `itunes`):

`trackfetch {{путь/к/файлу.txt}} {{[-s|--metadata-sources]}} {{deezer,itunes,musicbrainz}}`

- Выбрать формат аудио (по умолчанию — `m4a`; `m4a` и `opus` сохраняют оригинальный звук YouTube):

`trackfetch {{путь/к/файлу.txt}} {{[-f|--format]}} {{mp3|m4a|opus}}`

- Использовать файл конфигурации со значениями по умолчанию:

`trackfetch {{путь/к/файлу.txt}} --config {{путь/к/файлу_конфигурации.ini}}`

- Подождать несколько секунд между песнями, чтобы избежать ограничения частоты запросов:

`trackfetch {{путь/к/файлу.txt}} --delay {{3}}`

- Повторить попытку для песен, которые не удались при предыдущем запуске:

`cut {{[-d|--delimiter]}} '|' {{[-f|--fields]}} 1 {{путь/к/каталогу}}/failed.txt >{{путь/к/файлу_для_повтора.txt}} && trackfetch {{путь/к/файлу_для_повтора.txt}} {{[-o|--output]}} {{путь/к/каталогу}}`
