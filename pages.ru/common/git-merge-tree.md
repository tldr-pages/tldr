# git merge-tree

> Выполнять слияние веток без изменения файлов.
> Больше информации: <https://git-scm.com/docs/git-merge-tree>.

- Показать результат слияния двух веток:

`git merge-tree {{ветка1}} {{ветка2}}`

- Выполнить слияние и записать результирующее дерево:

`git merge-tree --write-tree {{ветка1}} {{ветка2}}`
