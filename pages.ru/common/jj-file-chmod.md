# jj file chmod

> Устанавливать или снимать бит исполняемости для путей в репозитории `jj`.
> Больше информации: <https://docs.jj-vcs.dev/latest/cli-reference/#jj-file-chmod>.

- Сделать файл исполняемым в рабочей копии:

`jj file chmod {{[x|executable]}} {{путь/к/файлу}}`

- Сделать файл неисполняемым (обычным) в рабочей копии:

`jj file chmod {{[n|normal]}} {{путь/к/файлу}}`

- Сделать несколько файлов исполняемыми:

`jj file chmod {{[x|executable]}} {{путь/к/файлу1 путь/к/файлу2 ...}}`

- Сделать файл исполняемым в конкретной ревизии:

`jj file chmod {{[-r|--revision]}} {{ревизия}} {{[x|executable]}} {{путь/к/файлу}}`
