# docker secret

> Управлять секретами Docker swarm.
> Больше информации: <https://docs.docker.com/reference/cli/docker/secret/>.

- Создать новый секрет из `stdin`:

`{{команда}} | docker secret create {{имя_секрета}} -`

- Создать новый секрет из файла:

`docker secret create {{имя_секрета}} {{путь/к/файлу}}`

- Вывести список всех секретов:

`docker secret ls`

- Показать подробную информацию об одном или нескольких секретах в удобочитаемом формате:

`docker secret inspect --pretty {{имя_секрета1 имя_секрета2 ...}}`

- Удалить один или несколько секретов:

`docker secret rm {{имя_секрета1 имя_секрета2 ...}}`
