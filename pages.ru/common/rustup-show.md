# rustup show

> Показывать установленные наборы инструментов, целевые платформы и версию `rustc`.
> Больше информации: <https://rust-lang.github.io/rustup/>.

- Показать всю информацию:

`rustup show`

- Показать активный набор инструментов:

`rustup show active-toolchain`

- Показать каталог данных rustup:

`rustup show home`
