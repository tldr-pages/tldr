# rabbitmqctl-users

> Управлять пользователями RabbitMQ, их разрешениями и тегами.
> Больше информации: <https://www.rabbitmq.com/docs/management>.

- Вывести список всех пользователей:

`rabbitmqctl list_users`

- Добавить нового пользователя с паролем:

`rabbitmqctl add_user {{имя_пользователя}} {{пароль}}`

- Удалить существующего пользователя:

`rabbitmqctl delete_user {{имя_пользователя}}`

- Изменить пароль пользователя:

`rabbitmqctl change_password {{имя_пользователя}} {{новый_пароль}}`

- Установить разрешения для пользователя на конкретном виртуальном хосте:

`rabbitmqctl set_permissions {{[-p|--vhost]}} {{виртуальный_хост}} {{имя_пользователя}} {{чтение}} {{запись}} {{настройка}}`

- Очистить все разрешения для пользователя на конкретном виртуальном хосте:

`rabbitmqctl clear_permissions {{[-p|--vhost]}} {{виртуальный_хост}} {{имя_пользователя}}`

- Назначить один или несколько тегов (например, administrator) пользователю:

`rabbitmqctl set_user_tags {{имя_пользователя}} {{тег1 тег2 ...}}`
