# openssl dgst

> Генерировать значения дайджестов и выполнять операции подписи.
> Больше информации: <https://docs.openssl.org/master/man1/openssl-dgst/>.

- Вычислить дайджест SHA256 для файла, сохранив результат в указанный файл:

`openssl dgst -sha256 -binary -out {{выходной_файл}} {{входной_файл}}`

- Подписать файл с помощью ключа RSA, сохранив результат в указанный файл:

`openssl dgst -sign {{файл_приватного_ключа}} -sha256 -sigopt rsa_padding_mode:pss -out {{выходной_файл}} {{входной_файл}}`

- Проверить подпись RSA:

`openssl dgst -verify {{файл_публичного_ключа}} -signature {{файл_подписи}} -sigopt rsa_padding_mode:pss {{файл_подписанного_сообщения}}`

- Подписать файл с помощью ключа ECDSA:

`openssl dgst -sign {{файл_приватного_ключа}} -sha256 -out {{выходной_файл}} {{входной_файл}}`

- Проверить подпись ECDSA:

`openssl dgst -verify {{файл_публичного_ключа}} -signature {{файл_подписи}} {{файл_подписанного_сообщения}}`
