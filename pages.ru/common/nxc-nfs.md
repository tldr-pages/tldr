# nxc nfs

> Тестировать на проникновение и эксплуатировать NFS-серверы. В настоящее время поддерживается только анонимный режим.
> Больше информации: <https://www.netexec.wiki/nfs-protocol/enumeration>.

- Определить версию удалённого NFS-сервера:

`nxc nfs {{192.168.178.0/24}}`

- Вывести список доступных общих ресурсов NFS:

`nxc nfs {{192.168.178.2}} --shares`

- Перечислить доступные общие ресурсы рекурсивно до указанной глубины:

`nxc nfs {{192.168.178.2}} --enum-shares {{5}}`

- Скачать указанный удалённый файл:

`nxc nfs {{192.168.178.2}} --get-file {{путь/к/удалённому_файлу}} {{путь/к/локальному_файлу}}`

- Загрузить указанный локальный файл на удалённый общий ресурс:

`nxc nfs {{192.168.178.2}} --put-file {{путь/к/локальному_файлу}} {{путь/к/удалённому_файлу}}`
