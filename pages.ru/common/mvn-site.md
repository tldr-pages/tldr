# mvn site

> Генерировать веб-сайт проекта на основе информации из файла `pom.xml`.
> Больше информации: <https://maven.apache.org/plugins/maven-site-plugin/usage.html>.

- Сгенерировать сайт проекта с помощью плагина site:

`mvn site`

- Сгенерировать сайт для конкретного проекта Maven (многомодульная сборка):

`mvn site {{[-pl|--projects]}} {{имя_модуля}}`

- Очистить предыдущий сайт перед генерацией нового:

`mvn clean site`

- Пропустить тесты при генерации сайта:

`mvn site {{[-D|--define]}} skipTests`

- Сгенерировать и развернуть сайт на удалённом сервере:

`mvn site-deploy`
