# jj git export

> Обновлять базовый Git-репозиторий изменениями, сделанными в репозитории Jujutsu.
> В совмещённых рабочих пространствах экспорт происходит автоматически.
> Смотрите также: `jj git import`.
> Больше информации: <https://docs.jj-vcs.dev/latest/cli-reference/#jj-git-export>.

- Экспортировать изменения в базовый Git-репозиторий:

`jj git export`

- Принудительно экспортировать изменения в совмещённом рабочем пространстве:

`jj git export --ignore-working-copy`
