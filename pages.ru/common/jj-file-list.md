# jj file list

> Выводить список файлов в ревизии репозитория `jj`.
> Больше информации: <https://docs.jj-vcs.dev/latest/cli-reference/#jj-file-list>.

- Вывести список всех файлов в текущей рабочей копии:

`jj file list`

- Вывести список всех файлов в конкретной ревизии:

`jj file list {{[-r|--revision]}} {{ревизия}}`

- Вывести список файлов, соответствующих указанному префиксу или пути:

`jj file list {{путь/к/каталогу}}`

- Вывести список файлов с использованием пользовательского шаблона:

`jj file list {{[-T|--template]}} "{{шаблон}}"`
