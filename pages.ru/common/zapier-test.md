# zapier test

> Тестировать интеграцию Zapier с помощью скрипта `test` из `package.json`.
> Больше информации: <https://github.com/zapier/zapier-platform/blob/main/packages/cli/docs/cli.md#test>.

- Протестировать интеграцию:

`zapier test`

- Протестировать интеграцию, пропустив валидацию:

`zapier test --skip-validate`

- Протестировать интеграцию с дополнительной отладочной информацией:

`zapier test {{[-d|--debug]}}`
