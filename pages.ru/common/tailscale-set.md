# tailscale set

> Изменять указанные настройки.
> Эти параметры также можно изменить при начальной настройке.
> Эта команда может устанавливать все параметры, описанные на странице `tailscale up`.
> Больше информации: <https://tailscale.com/kb/1080/cli#set>.

- Посмотреть документацию по `tailscale up`:

`tldr tailscale up`
