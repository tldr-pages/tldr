# pnpm

> Быстрый и экономящий место на диске менеджер пакетов для Node.js.
> Управляет проектами Node.js и их зависимостями.
> Больше информации: <https://pnpm.io/pnpm-cli>.

- Создать файл `package.json`:

`pnpm init`

- Скачать все пакеты, перечисленные в `package.json` как зависимости:

`pnpm {{[i|install]}}`

- Скачать определённую версию пакета и добавить её в список зависимостей в `package.json`:

`pnpm add {{имя_модуля}}@{{версия}}`

- Скачать пакет и добавить его в список dev-зависимостей в `package.json`:

`pnpm add {{имя_модуля}} {{[-D|--save-dev]}}`

- Скачать пакет и установить его глобально:

`pnpm add {{имя_модуля}} {{[-g|--global]}}`

- Удалить пакет и убрать его из списка зависимостей в `package.json`:

`pnpm {{[rm|remove]}} {{имя_модуля}}`

- Вывести дерево локально установленных модулей:

`pnpm {{[ls|list]}}`

- Вывести глобально установленные модули верхнего уровня:

`pnpm {{[ls|list]}} {{[-g|--global]}} --depth {{0}}`
