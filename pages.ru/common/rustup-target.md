# rustup target

> Управлять поддерживаемыми целевыми платформами набора инструментов.
> Без опции `--toolchain` `rustup` использует набор инструментов по умолчанию. Подробнее см. `rustup help toolchain`.
> Больше информации: <https://rust-lang.github.io/rustup/>.

- Добавить целевую платформу в набор инструментов:

`rustup target add --toolchain {{набор_инструментов}} {{целевая_платформа}}`

- Удалить целевую платформу из набора инструментов:

`rustup target remove --toolchain {{набор_инструментов}} {{целевая_платформа}}`

- Показать доступные и установленные целевые платформы для набора инструментов:

`rustup target list --toolchain {{набор_инструментов}}`

- Показать установленные целевые платформы для набора инструментов:

`rustup target list --toolchain {{набор_инструментов}} --installed`
