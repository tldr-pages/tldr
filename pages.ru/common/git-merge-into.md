# git merge-into

> Выполнять слияние одной ветки в другую ветку.
> Часть `git-extras`.
> Больше информации: <https://github.com/tj/git-extras/blob/main/Commands.md#git-merge-into>.

- Выполнить слияние исходной ветки в указанную целевую ветку:

`git merge-into {{исходная_ветка}} {{целевая_ветка}}`

- Выполнить слияние текущей ветки в указанную целевую ветку:

`git merge-into {{целевая_ветка}}`
