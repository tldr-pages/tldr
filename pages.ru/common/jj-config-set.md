# jj config set

> Устанавливать значение параметра конфигурации.
> Значение задаётся в виде выражения TOML.
> Смотрите также: `jj config unset`.
> Больше информации: <https://docs.jj-vcs.dev/latest/cli-reference/#jj-config-set>.

- Установить имя пользователя в конфигурации уровня пользователя:

`jj config {{[s|set]}} --user user.name "{{имя}}"`

- Установить адрес электронной почты пользователя в конфигурации уровня пользователя:

`jj config {{[s|set]}} --user user.email "{{электронная_почта}}"`

- Установить параметр конфигурации в конфигурации уровня репозитория:

`jj config {{[s|set]}} --repo {{имя}} {{значение}}`

- Установить параметр конфигурации в конфигурации уровня рабочего пространства:

`jj config {{[s|set]}} --workspace {{имя}} {{значение}}`

- Установить логический параметр конфигурации:

`jj config {{[s|set]}} --user {{имя}} {{true|false}}`
