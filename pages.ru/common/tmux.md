# tmux

> Терминальный мультиплексор.
> Позволяет работать с несколькими сессиями, содержащими окна, панели и не только.
> Смотрите также: `zellij`, `screen`, `herdr`.
> Больше информации: <https://github.com/tmux/tmux>.

- Запустить новую сессию:

`tmux`

- Запустить новую именованную сессию ([s]ession):

`tmux {{[new|new-session]}} -s {{имя}}`

- Вывести список существующих сессий:

`tmux {{[ls|list-sessions]}}`

- Подключиться к последней использованной сессии:

`tmux {{[a|attach]}}`

- Отключиться от текущей сессии (внутри сессии tmux):

`<Ctrl b><d>`

- Создать новое окно (внутри сессии tmux):

`<Ctrl b><c>`

- Переключиться между сессиями и окнами (внутри сессии tmux):

`<Ctrl b><w>`

- Завершить сессию с указанным именем ([t]arget):

`tmux kill-session -t {{имя}}`
