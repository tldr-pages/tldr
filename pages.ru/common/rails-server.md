# rails server

> Запускать приложение Rails в текущем каталоге с помощью веб-сервера Puma, поставляемого вместе с Rails.
> Больше информации: <https://guides.rubyonrails.org/command_line.html#bin-rails-server>.

- Запустить веб-сервер:

`rails server`

- Запустить веб-сервер на конкретном порту:

`rails server {{[-p|--port]}} {{номер_порта}}`

- Запустить веб-сервер на конкретном IP-адресе:

`rails server {{[-b|--binding]}} {{ip_адрес}}`

- Запустить веб-сервер в конкретном окружении:

`rails server {{[-e|--environment]}} {{окружение}}`

- Показать справку:

`rails server {{[-h|--help]}}`
