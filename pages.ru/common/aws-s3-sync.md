# aws s3 sync

> Рекурсивно синхронизировать файлы и каталоги между локальной системой и бакетом S3 или между бакетами S3.
> Больше информации: <https://docs.aws.amazon.com/cli/latest/reference/s3/sync.html>.

- Синхронизировать файлы из локального каталога в бакет:

`aws s3 sync {{путь/к/каталогу}} s3://{{имя_бакета}}/{{путь/к/удалённому_расположению}}`

- Синхронизировать файлы из бакета в локальный каталог:

`aws s3 sync s3://{{имя_бакета}}/{{путь/к/удалённому_расположению}} {{путь/к/каталогу}}`

- Синхронизировать объекты между двумя бакетами:

`aws s3 sync s3://{{имя_исходного_бакета}}/{{путь/к/удалённому_расположению}} s3://{{имя_целевого_бакета}}/{{путь/к/удалённому_расположению}}`

- Синхронизировать локальные файлы в S3, исключив определённые файлы или каталоги:

`aws s3 sync {{путь/к/каталогу}} s3://{{имя_бакета}}/{{путь/к/удалённому_расположению}} --exclude {{путь/к/файлу}} --exclude {{путь/к/каталогу}}/*`

- Синхронизировать объекты между бакетами и удалить файлы в целевом бакете, отсутствующие в исходном:

`aws s3 sync s3://{{имя_исходного_бакета}}/{{путь/к/удалённому_расположению}} s3://{{имя_целевого_бакета}}/{{путь/к/удалённому_расположению}} --delete`

- Синхронизировать в S3 с дополнительными параметрами (задать ACL и класс хранилища):

`aws s3 sync {{путь/к/локальному_каталогу}} s3://{{имя_бакета}}/{{путь/к/удалённому_расположению}} --acl {{private|public-read}} --storage-class {{STANDARD_IA|GLACIER}}`

- Синхронизировать файлы в S3, пропуская неизменённые (сравнение по размеру и времени изменения):

`aws s3 sync {{путь/к/каталогу}} s3://{{имя_бакета}}/{{путь/к/удалённому_расположению}} --size-only`

- Показать справку:

`aws s3 sync help`
