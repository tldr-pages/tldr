# jj config edit

> Открывать редактор для файла конфигурации.
> Смотрите также: `jj config path`.
> Больше информации: <https://docs.jj-vcs.dev/latest/cli-reference/#jj-config-edit>.

- Открыть редактор для файла конфигурации уровня пользователя:

`jj config {{[e|edit]}} --user`

- Открыть редактор для файла конфигурации уровня репозитория:

`jj config {{[e|edit]}} --repo`

- Открыть редактор для файла конфигурации уровня рабочего пространства:

`jj config {{[e|edit]}} --workspace`
