# dotnet tool

> Управлять инструментами .NET и искать опубликованные инструменты в NuGet.
> Больше информации: <https://learn.microsoft.com/dotnet/core/tools/global-tools>.

- Установить глобальный инструмент (не используйте `--global` для локальных инструментов):

`dotnet tool install {{[-g|--global]}} {{dotnetsay}}`

- Установить инструменты, определённые в локальном манифесте инструментов:

`dotnet tool restore`

- Обновить конкретный глобальный инструмент (не используйте `--global` для локальных инструментов):

`dotnet tool update {{[-g|--global]}} {{имя_инструмента}}`

- Удалить глобальный инструмент (не используйте `--global` для локальных инструментов):

`dotnet tool uninstall {{[-g|--global]}} {{имя_инструмента}}`

- Вывести список установленных глобальных инструментов (не используйте `--global` для локальных инструментов):

`dotnet tool list {{[-g|--global]}}`

- Найти инструменты в NuGet:

`dotnet tool search {{поисковый_запрос}}`

- Показать справку:

`dotnet tool {{[-h|--help]}}`
