# magick compare

> Создавать изображение сравнения для визуального отображения различий между двумя изображениями.
> Больше информации: <https://imagemagick.org/script/compare.php>.

- Сравнить два изображения:

`magick compare {{путь/к/изображению1.png}} {{путь/к/изображению2.png}} {{путь/к/различиям.png}}`

- Сравнить два изображения, используя указанную метрику:

`magick compare -verbose -metric {{PSNR}} {{путь/к/изображению1.png}} {{путь/к/изображению2.png}} {{путь/к/различиям.png}}`
