# npm stars

> Просматривать пакеты, отмеченные как избранные.
> Больше информации: <https://docs.npmjs.com/cli/v11/npm-stars>.

- Показать все избранные пакеты текущего авторизованного пользователя:

`npm stars`

- Показать избранные пакеты из определённого реестра:

`npm stars --registry {{url_реестра}}`

- Показать пакеты, отмеченные определённым пользователем:

`npm stars {{имя_пользователя}}`

- Показать пакеты, отмеченные определённым пользователем, из определённого реестра:

`npm stars {{имя_пользователя}} --registry {{url_реестра}}`

- Показать справку:

`npm stars {{[-h|--help]}}`
