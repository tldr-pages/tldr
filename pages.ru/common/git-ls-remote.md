# git ls-remote

> Команда Git для вывода списка ссылок в удалённом репозитории по имени или URL.
> Если имя или URL не указаны, будет использоваться настроенная вышестоящая ветка или удалённый репозиторий origin, если первая не настроена.
> Больше информации: <https://git-scm.com/docs/git-ls-remote>.

- Показать все ссылки в удалённом репозитории по умолчанию:

`git ls-remote`

- Показать только ссылки на ветки в удалённом репозитории по умолчанию:

`git ls-remote --heads`

- Показать только ссылки на теги в удалённом репозитории по умолчанию:

`git ls-remote {{[-t|--tags]}}`

- Показать все ссылки из удалённого репозитория по имени или URL:

`git ls-remote {{URL_репозитория}}`

- Показать ссылки из удалённого репозитория, отфильтрованные по шаблону:

`git ls-remote {{имя_репозитория}} "{{шаблон}}"`
