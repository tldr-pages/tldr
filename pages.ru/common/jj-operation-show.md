# jj operation show

> Показывать изменения в репозитории для операции.
> Больше информации: <https://docs.jj-vcs.dev/latest/cli-reference/#jj-operation-show>.

- Показать изменения в репозитории для текущей операции по сравнению с родительской:

`jj {{[op|operation]}} show`

- Показать изменения в репозитории для конкретной операции:

`jj {{[op|operation]}} show {{идентификатор_операции}}`

- Показать изменения в репозитории с деталями патча:

`jj {{[op|operation]}} show {{[-p|--patch]}} {{идентификатор_операции}}`

- Показать сводку изменённых путей в операции:

`jj {{[op|operation]}} show {{[-s|--summary]}} {{идентификатор_операции}}`

- Показать гистограмму изменений в операции:

`jj {{[op|operation]}} show --stat {{идентификатор_операции}}`

- Показать изменения без графа:

`jj {{[op|operation]}} show {{[-G|--no-graph]}} {{идентификатор_операции}}`
