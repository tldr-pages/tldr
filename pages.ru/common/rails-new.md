# rails new

> Создавать новое приложение Rails.
> Больше информации: <https://guides.rubyonrails.org/command_line.html#rails-new>.

- Создать приложение Rails с именем `blog` в текущем каталоге:

`rails new blog`

- Создать приложение Rails с конфигурацией только для API:

`rails new {{имя_приложения}} --api`

- Создать приложение Rails с `postgresql` в качестве базы данных:

`rails new {{имя_приложения}} {{[-d|--database]}} postgresql`

- Создать приложение Rails без генерации файлов JavaScript:

`rails new {{имя_приложения}} {{[-J|--skip-javascript]}}`

- Показать справку:

`rails new {{[-h|--help]}}`
