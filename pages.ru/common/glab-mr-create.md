# glab mr create

> Управлять запросами на слияние GitLab.
> Больше информации: <https://gitlab.com/gitlab-org/cli/-/blob/main/docs/source/mr/create.md>.

- Создать запрос на слияние в интерактивном режиме:

`glab mr create`

- Создать запрос на слияние, определив заголовок и описание из сообщений коммитов текущей ветки:

`glab mr create {{[-f|--fill]}}`

- Создать черновой запрос на слияние:

`glab mr create --draft`

- Создать запрос на слияние с указанием целевой ветки, заголовка и описания:

`glab mr create {{[-b|--target-branch]}} {{целевая_ветка}} {{[-t|--title]}} "{{заголовок}}" {{[-d|--description]}} "{{описание}}"`

- Начать создание запроса на слияние в браузере по умолчанию:

`glab mr create {{[-w|--web]}}`
