# nxc ssh

> Тестировать на проникновение и эксплуатировать SSH-серверы.
> Смотрите также: `hydra`.
> Больше информации: <https://www.netexec.wiki/ssh-protocol/password-spraying>.

- Распылить указанный пароль по списку имён пользователей на указанной цели:

`nxc ssh {{192.168.178.2}} {{[-u|--username]}} {{путь/к/именам_пользователей.txt}} {{[-p|--password]}} {{пароль}}`

- Найти действительные учётные данные, перебирая все комбинации из указанных списков имён пользователей и паролей:

`nxc ssh {{192.168.178.2}} {{[-u|--username]}} {{путь/к/именам_пользователей.txt}} {{[-p|--password]}} {{путь/к/паролям.txt}}`

- Использовать указанный приватный ключ для аутентификации, используя заданный пароль в качестве парольной фразы ключа:

`nxc ssh {{192.186.178.2}} {{[-u|--username]}} {{путь/к/именам_пользователей.txt}} {{[-p|--password]}} {{пароль}} --key-file {{путь/к/id_rsa}}`

- Попробовать комбинацию имени пользователя и пароля на нескольких целях:

`nxc ssh {{192.168.178.0/24}} {{[-u|--username]}} {{имя_пользователя}} {{[-p|--password]}} {{пароль}}`

- Проверить наличие привилегий `sudo` при успешном входе:

`nxc ssh {{192.168.178.2}} {{[-u|--username]}} {{имя_пользователя}} {{[-p|--password]}} {{путь/к/паролям.txt}} --sudo-check`
