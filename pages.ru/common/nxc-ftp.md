# nxc ftp

> Тестировать на проникновение и эксплуатировать FTP-серверы.
> Больше информации: <https://www.netexec.wiki/ftp-protocol/password-spraying>.

- Найти действительные учётные данные, перебирая все комбинации из указанных списков имён пользователей и паролей:

`nxc ftp {{192.168.178.2}} {{[-u|--username]}} {{путь/к/именам_пользователей.txt}} {{[-p|--password]}} {{путь/к/паролям.txt}}`

- Продолжить поиск действительных учётных данных даже после их обнаружения:

`nxc ftp {{192.168.178.2}} {{[-u|--username]}} {{путь/к/именам_пользователей.txt}} {{[-p|--password]}} {{путь/к/паролям.txt}} --continue-on-success`

- Вывести содержимое каталогов на каждом FTP-сервере, к которому подходят указанные учётные данные:

`nxc ftp {{192.168.178.0/24}} {{[-u|--username]}} {{имя_пользователя}} {{[-p|--password]}} {{пароль}} --ls`

- Скачать указанный файл с целевого сервера:

`nxc ftp {{192.168.178.2}} {{[-u|--username]}} {{имя_пользователя}} {{[-p|--password]}} {{пароль}} --get {{путь/к/файлу}}`

- Загрузить указанный файл на целевой сервер в указанное расположение:

`nxc ftp {{192.168.178.2}} {{[-u|--username]}} {{имя_пользователя}} {{[-p|--password]}} {{пароль}} --put {{путь/к/локальному_файлу}} {{путь/к/удалённому_расположению}}`
