# git show-tree

> Показывать декорированный граф-дерево всех веток Git-репозитория с аннотациями.
> Часть `git-extras`.
> Больше информации: <https://github.com/tj/git-extras/blob/main/Commands.md#git-show-tree>.

- Показать декорированный граф-дерево для всех веток с аннотациями тегов и имён веток:

`git show-tree`
