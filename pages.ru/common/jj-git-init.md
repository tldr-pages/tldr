# jj git init

> Создавать новый репозиторий Jujutsu с поддержкой Git.
> Примечание: без `--colocate` репозиторий не является валидным Git-репозиторием и команды `git` не могут использоваться в нём.
> Больше информации: <https://docs.jj-vcs.dev/latest/cli-reference/#jj-git-init>.

- Создать новый репозиторий с поддержкой Git в текущем каталоге:

`jj git init`

- Создать новый репозиторий с поддержкой Git в указанном каталоге:

`jj git init {{путь/к/каталогу}}`

- Инициализировать репозиторий Jujutsu как валидный Git-репозиторий (позволяя использовать команды `jj` и `git` в одном каталоге):

`jj git init --colocate`

- Инициализировать репозиторий Jujutsu на основе существующего Git-репозитория:

`jj git init --git-repo {{git_репозиторий}}`
