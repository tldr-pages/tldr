# rails destroy

> Удалять ресурсы Rails.
> Больше информации: <https://guides.rubyonrails.org/command_line.html#bin-rails-destroy>.

- Вывести список всех доступных генераторов для удаления:

`rails destroy`

- Удалить модель Post:

`rails destroy model {{Post}}`

- Удалить контроллер Posts:

`rails destroy controller {{Posts}}`

- Удалить миграцию, создающую Posts:

`rails destroy migration {{CreatePosts}}`

- Удалить каркас для модели Post:

`rails destroy scaffold {{Post}}`
