# ansible-vault

> Шифровать и расшифровывать значения, структуры данных и файлы в проектах Ansible.
> Больше информации: <https://docs.ansible.com/projects/ansible/latest/vault_guide/index.html>.

- Создать новый зашифрованный файл хранилища с запросом пароля:

`ansible-vault create {{путь/к/файлу_хранилища}}`

- Отредактировать, просмотреть или перешифровать существующий зашифрованный файл хранилища с запросом пароля:

`ansible-vault {{edit|view|rekey}} {{путь/к/файлу_хранилища}}`

- Создать новый зашифрованный файл хранилища, используя файл пароля для шифрования:

`ansible-vault create --vault-password-file {{путь/к/файлу_пароля}} {{путь/к/файлу_хранилища}}`

- Зашифровать существующий текстовый файл на месте, используя файл пароля:

`ansible-vault encrypt --vault-password-file {{путь/к/файлу_пароля}} {{путь/к/файлу}}`

- Зашифровать строку в формате зашифрованной строки Ansible с интерактивными запросами:

`ansible-vault encrypt_string`

- Просмотреть зашифрованный файл хранилища, используя файл пароля для расшифровки:

`ansible-vault view --vault-password-file {{путь/к/файлу_пароля}} {{путь/к/файлу_хранилища}}`

- Перешифровать существующий зашифрованный файл хранилища с новым файлом пароля:

`ansible-vault rekey --vault-password-file {{путь/к/старому_файлу_пароля}} --new-vault-password-file {{путь/к/новому_файлу_пароля}} {{путь/к/файлу_хранилища}}`
