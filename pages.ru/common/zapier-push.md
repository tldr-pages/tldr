# zapier push

> Собирать и загружать интеграцию Zapier.
> Больше информации: <https://platform.zapier.com/reference/cli#push>.

- Загрузить интеграцию в Zapier:

`zapier push`

- Отключить автоматическое определение зависимостей (будут включены только файлы, необходимые для `index.js`):

`zapier push --disable-dependency-detection`

- Показать дополнительную отладочную информацию:

`zapier push {{[-d|--debug]}}`
