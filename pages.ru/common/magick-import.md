# magick import

> Захватывать часть или весь экран X-сервера и сохранять изображение в файл.
> Больше информации: <https://imagemagick.org/script/import.php>.

- Захватить весь экран X-сервера в файл PostScript:

`magick import -window root {{путь/к/выходному_файлу.ps}}`

- Захватить содержимое экрана удалённого X-сервера в PNG-изображение:

`magick import -window root -display {{удалённый_хост}}:{{экран}}.{{дисплей}} {{путь/к/выходному_файлу.png}}`

- Захватить конкретное окно по его идентификатору, отображаемому `xwininfo`, в JPEG-изображение:

`magick import -window {{идентификатор_окна}} {{путь/к/выходному_файлу.jpg}}`
