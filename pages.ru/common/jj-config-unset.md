# jj config unset

> Удалять параметр конфигурации.
> Смотрите также: `jj config set`.
> Больше информации: <https://docs.jj-vcs.dev/latest/cli-reference/#jj-config-unset>.

- Удалить параметр конфигурации из конфигурации уровня пользователя:

`jj config {{[u|unset]}} --user {{имя}}`

- Удалить параметр конфигурации из конфигурации уровня репозитория:

`jj config {{[u|unset]}} --repo {{имя}}`

- Удалить параметр конфигурации из конфигурации уровня рабочего пространства:

`jj config {{[u|unset]}} --workspace {{имя}}`
