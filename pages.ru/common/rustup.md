# rustup

> Устанавливать, управлять и обновлять наборы инструментов Rust.
> Некоторые подкоманды, такие как `toolchain`, `target`, `update` и др., имеют собственную документацию по использованию.
> Больше информации: <https://rust-lang.github.io/rustup/>.

- Установить ночной набор инструментов для текущей системы:

`rustup install nightly`

- Переключить набор инструментов по умолчанию на ночной, чтобы команды `cargo` и `rustc` использовали его:

`rustup default nightly`

- Использовать ночной набор инструментов в текущем проекте, не меняя глобальные настройки:

`rustup override set nightly`

- Обновить все наборы инструментов:

`rustup update`

- Показать установленные наборы инструментов:

`rustup show`

- Запустить `cargo build` с определённым набором инструментов:

`rustup run {{набор_инструментов}} cargo build`

- Открыть локальную документацию Rust в браузере по умолчанию:

`rustup doc`
