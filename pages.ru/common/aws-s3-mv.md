# aws s3 mv

> Перемещать локальные файлы или объекты S3 в другое расположение локально или в S3.
> Больше информации: <https://docs.aws.amazon.com/cli/latest/reference/s3/mv.html>.

- Переместить файл из локальной системы в указанный бакет:

`aws s3 mv {{путь/к/локальному_файлу}} s3://{{имя_бакета}}/{{путь/к/удалённому_файлу}}`

- Переместить конкретный объект S3 в другой бакет:

`aws s3 mv s3://{{имя_бакета1}}/{{путь/к/файлу}} s3://{{имя_бакета2}}/{{путь/к/цели}}`

- Переместить конкретный объект S3 в другой бакет, сохранив исходное имя:

`aws s3 mv s3://{{имя_бакета1}}/{{путь/к/файлу}} s3://{{имя_бакета2}}`

- Показать справку:

`aws s3 mv help`
