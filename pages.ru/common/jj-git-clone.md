# jj git clone

> Создавать новый репозиторий на основе клона Git-репозитория.
> Примечание: без `--colocate` репозиторий не является валидным Git-репозиторием и команды `git` не могут использоваться в нём.
> Больше информации: <https://docs.jj-vcs.dev/latest/cli-reference/#jj-git-clone>.

- Создать новый репозиторий на основе клона Git-репозитория (каталогом по умолчанию является имя репозитория):

`jj git clone {{источник}}`

- Создать новый репозиторий на основе клона Git-репозитория в конкретный каталог:

`jj git clone {{источник}} {{путь/к/каталогу}}`

- Создать клон и использовать указанное имя для нового удалённого репозитория:

`jj git clone --remote {{имя_удалённого_репозитория}} {{источник}}`

- Клонировать Git-репозиторий, загружая только 10 последних коммитов:

`jj git clone --depth 10 {{источник}}`

- Клонировать с совмещением репозиториев Jujutsu и Git (позволяя использовать команды `jj` и `git` в одном каталоге):

`jj git clone --colocate {{источник}}`
