# bun pm pkg

> Управлять данными `package.json` с помощью операций `get`, `set`, `delete` и `fix`.
> Больше информации: <https://bun.com/docs/pm/cli/pm#pkg>.

- Получить все свойства из `package.json`:

`bun pm pkg get`

- Получить одно свойство:

`bun pm pkg get {{свойство}}`

- Получить несколько свойств:

`bun pm pkg get {{свойство1 свойство2 свойство3 ...}}`

- Получить вложенное свойство:

`bun pm pkg get {{свойство}}.{{атрибут}}`

- Задать свойство:

`bun pm pkg set {{свойство}}="{{значение}}"`

- Удалить свойство:

`bun pm pkg delete {{свойство}}`

- Автоматически исправить распространённые ошибки в `package.json`:

`bun pm pkg fix`
