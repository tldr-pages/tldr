# ffmpeg

> Инструмент для конвертации видео.
> Смотрите также: `gst-launch-1.0`.
> Больше информации: <https://ffmpeg.org/ffmpeg.html#Options>.

- Извлечь звук из видео и сохранить его в MP3:

`ffmpeg -i {{путь/к/видео.mp4}} -vn {{путь/к/звуку.mp3}}`

- Перекодировать FLAC-файл в формат Red Book CD (44100 кГц, 16 бит):

`ffmpeg -i {{путь/к/входному_аудио.flac}} -ar 44100 -sample_fmt s16 {{путь/к/выходному_аудио.wav}}`

- Сохранить видео как GIF, отмасштабировав высоту до 1000 пикселей и установив частоту кадров 15:

`ffmpeg -i {{путь/к/видео.mp4}} {{[-vf|-filter:v]}} 'scale=-1:1000' -r 15 {{путь/к/выходному.gif}}`

- Объединить пронумерованные изображения (`кадр_1.jpg`, `кадр_2.jpg` и т. д.) в видео или GIF:

`ffmpeg -i {{путь/к/кадру_%d.jpg}} -f image2 {{видео.mpg|видео.gif}}`

- Обрезать видео от указанного времени начала мм:сс до времени окончания мм2:сс2 (опустите флаг `-to`, чтобы обрезать до конца):

`ffmpeg -i {{путь/к/входному_видео.mp4}} -ss {{мм:сс}} -to {{мм2:сс2}} {{[-c|-codec]}} copy {{путь/к/выходному_видео.mp4}}`

- Преобразовать видео AVI в MP4. Аудио AAC @ 128 кбит, видео h264 @ CRF 23:

`ffmpeg -i {{путь/к/входному_видео}}.avi {{[-c|-codec]}}:a aac -b:a 128k {{[-c|-codec]}}:v libx264 -crf 23 {{путь/к/выходному_видео}}.mp4`

- Переупаковать видео из MKV в MP4 без перекодирования аудио- и видеопотоков:

`ffmpeg -i {{путь/к/входному_видео}}.mkv {{[-c|-codec]}} copy {{путь/к/выходному_видео}}.mp4`

- Преобразовать видео MP4 в кодек VP9. Для наилучшего качества используйте значение CRF (рекомендуемый диапазон 15-35), а `-b:v` обязательно должен быть равен 0:

`ffmpeg -i {{путь/к/входному_видео}}.mp4 {{[-c|-codec]}}:v libvpx-vp9 -crf {{30}} -b:v 0 {{[-c|-codec]}}:a libopus -vbr on -threads {{количество_потоков}} {{путь/к/выходному_видео}}.webm`
