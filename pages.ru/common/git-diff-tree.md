# git diff-tree

> Сравнивать содержимое и режим блобов, найденных через два объекта дерева.
> Больше информации: <https://git-scm.com/docs/git-diff-tree>.

- Сравнить два объекта дерева:

`git diff-tree {{tree-ish1}} {{tree-ish2}}`

- Показать изменения между двумя определёнными коммитами:

`git diff-tree -r {{коммит1}} {{коммит2}}`

- Показать изменения в формате патча:

`git diff-tree {{[-p|--patch]}} {{tree-ish1}} {{tree-ish2}}`

- Отфильтровать изменения по определённому пути:

`git diff-tree {{tree-ish1}} {{tree-ish2}} -- {{путь/к/файлу_или_каталогу}}`
