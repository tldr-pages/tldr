# hledger add

> Записывать новые транзакции с помощью интерактивных подсказок в консоли.
> Больше информации: <https://hledger.org/hledger.html#add>.

- Записать новые транзакции, сохраняя в файл журнала по умолчанию:

`hledger add`

- Добавить транзакции в `2024.journal`, загрузив также `2023.journal` для автодополнения:

`hledger add {{[-f|--file]}} {{путь/к/2024.journal}} {{[-f|--file]}} {{путь/к/2023.journal}}`

- Предоставить ответы на первые четыре запроса:

`hledger add {{today}} '{{best buy}}' {{expenses:supplies}} '{{$20}}'`

- Показать параметры и документацию `add` с помощью `$PAGER`:

`hledger add {{[-h|--help]}}`

- Показать документацию `add` с помощью `info` или `man`, если доступно:

`hledger help add`
