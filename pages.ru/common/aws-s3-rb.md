# aws s3 rb

> Удалять пустой бакет S3.
> Больше информации: <https://docs.aws.amazon.com/cli/latest/reference/s3/rb.html>.

- Удалить пустой бакет S3:

`aws s3 rb s3://{{имя_бакета}}`

- Принудительно удалить бакет S3 и его неверсионированные объекты (не удастся, если в бакете есть версионированные объекты):

`aws s3 rb s3://{{имя_бакета}} --force`
