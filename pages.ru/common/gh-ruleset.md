# gh ruleset

> Управлять наборами правил репозитория GitHub.
> Больше информации: <https://cli.github.com/manual/gh_ruleset>.

- Вывести список всех наборов правил для текущего репозитория:

`gh {{[rs|ruleset]}} {{[ls|list]}}`

- Вывести список всех наборов правил для указанной организации:

`gh {{[rs|ruleset]}} {{[ls|list]}} {{[-o|--org]}} {{имя_организации}}`

- Проверить правила, применяемые к текущей ветке:

`gh {{[rs|ruleset]}} check`

- Проверить правила, применяемые к указанной ветке в другом репозитории:

`gh {{[rs|ruleset]}} check {{имя_ветки}} {{[-R|--repo]}} {{владелец}}/{{репозиторий}}`

- Интерактивно выбрать и просмотреть набор правил для текущего репозитория:

`gh {{[rs|ruleset]}} view`

- Просмотреть указанный набор правил по его ID:

`gh {{[rs|ruleset]}} view {{идентификатор_набора_правил}}`

- Просмотреть набор правил уровня организации по его ID:

`gh {{[rs|ruleset]}} view {{идентификатор_набора_правил}} {{[-o|--org]}} {{имя_организации}}`

- Открыть список наборов правил для указанного репозитория в браузере:

`gh {{[rs|ruleset]}} {{[ls|list]}} {{[-R|--repo]}} {{владелец}}/{{репозиторий}} {{[-w|--web]}}`
