# docker buildx use

> Устанавливать текущий экземпляр сборщика.
> Больше информации: <https://docs.docker.com/reference/cli/docker/buildx/use>.

- Установить определённый экземпляр сборщика как текущий:

`docker buildx use {{имя_сборщика}}`

- Установить сборщик по умолчанию для текущего контекста:

`docker buildx use --default {{имя_сборщика}}`

- Установить сборщик и сохранить изменения для всех контекстов:

`docker buildx use --global {{имя_сборщика}}`
