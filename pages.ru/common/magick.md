# magick

> Создавать, редактировать, компоновать и конвертировать изображения между форматами.
> Этот инструмент заменяет `convert` в ImageMagick 7+. Смотрите `magick convert` для использования старого инструмента в версиях 7+.
> Некоторые подкоманды, такие как `mogrify`, имеют собственную документацию по использованию.
> Больше информации: <https://imagemagick.org/script/magick.php>.

- Конвертировать между форматами изображений:

`magick {{путь/к/входному_изображению.png}} {{путь/к/выходному_изображению.jpg}}`

- Изменить размер изображения, создав новую копию:

`magick {{путь/к/входному_изображению.jpg}} -resize {{100x100}} {{путь/к/выходному_изображению.jpg}}`

- Изменить размер изображения в процентах:

`magick {{путь/к/входному_изображению.png}} -resize {{50}}% {{путь/к/выходному_изображению.png}}`

- Масштабировать изображение до указанного размера файла:

`magick {{путь/к/входному_изображению.png}} -define jpeg:extent={{512kb}} {{путь/к/выходному_изображению.jpg}}`

- Объединить изображения вертикально/горизонтально, сделав пустое пространство прозрачным:

`magick convert -background none {{путь/к/изображению1.png путь/к/изображению2.png ...}} {{-append|+append}} {{путь/к/выходному_изображению.png}}`

- Создать GIF из всех JPEG-изображений в текущем каталоге:

`magick {{*.jpg}} {{путь/к/изображениям.gif}}`

- Создать шахматный узор:

`magick -size {{640x480}} pattern:checkerboard {{путь/к/шахматному_узору.png}}`

- Создать PDF-файл из всех JPEG-изображений в текущем каталоге:

`magick {{*.jpg}} -adjoin {{путь/к/файлу.pdf}}`
