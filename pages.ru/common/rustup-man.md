# rustup man

> Просматривать man-страницу команды, управляемой `rustup`.
> Больше информации: <https://rust-lang.github.io/rustup/examples.html>.

- Просмотреть man-страницу указанной команды из набора инструментов по умолчанию:

`rustup man {{команда}}`

- Просмотреть man-страницу указанной команды из указанного набора инструментов:

`rustup man --toolchain {{набор_инструментов}} {{команда}}`
