# sqlite3

> Интерфейс к SQLite 3 - автономному файловому встраиваемому SQL-движку.
> Больше информации: <https://sqlite.org/cli.html>.

- Запустить интерактивную оболочку с новой базой данных:

`sqlite3`

- Открыть интерактивную оболочку для существующей базы данных:

`sqlite3 {{путь/к/базе_данных.sqlite3}}`

- Выполнить SQL-выражение для базы данных и выйти:

`sqlite3 {{путь/к/базе_данных.sqlite3}} '{{SELECT * FROM имя_таблицы;}}'`
