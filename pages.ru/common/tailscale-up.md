# tailscale up

> Подключать клиент к сети Tailscale.
> Все описанные здесь параметры можно изменить позже с помощью `tailscale set --option argument`. Используйте `--option=false` для отключения параметров, не требующих аргументов.
> Примечание: выполните `sudo tailscale set --operator $USER`, чтобы разрешить текущему пользователю выполнять эти команды.
> Больше информации: <https://tailscale.com/kb/1080/cli/#up>.

- Подключиться к Tailscale:

`tailscale up`

- Подключиться и предложить текущую машину в качестве выходного узла для интернет-трафика:

`tailscale up --advertise-exit-node`

- Подключиться, используя конкретный узел для интернет-трафика:

`tailscale up --exit-node {{ip_выходного_узла}}`

- Подключиться и заблокировать входящие подключения к текущему узлу:

`tailscale up --shields-up`

- Подключиться и не принимать конфигурацию DNS из панели администрирования (по умолчанию `true`):

`tailscale up --accept-dns=false`

- Подключиться и настроить Tailscale в качестве маршрутизатора подсети:

`tailscale up --advertise-routes {{10.0.0.0/24,10.0.1.0/24,...}}`

- Подключиться и принять маршруты подсетей от Tailscale:

`tailscale up --accept-routes`

- Сбросить неуказанные настройки к значениям по умолчанию и подключиться:

`tailscale up --reset`
