# aws s3 rm

> Удалять объекты S3.
> Больше информации: <https://docs.aws.amazon.com/cli/latest/reference/s3/rm.html>.

- Удалить конкретный объект S3:

`aws s3 rm s3://{{имя_бакета}}/{{путь/к/файлу}}`

- Симулировать удаление конкретного объекта S3 без фактического удаления:

`aws s3 rm s3://{{имя_бакета}}/{{путь/к/файлу}} --dryrun`

- Удалить объект из конкретной точки доступа S3:

`aws s3 rm s3://arn:aws:s3:{{регион}}:{{идентификатор_учётной_записи}}:{{точка_доступа}}/{{имя_точки_доступа}}/{{ключ_объекта}}`

- Удалить все объекты из бакета (очистить бакет):

`aws s3 rm s3://{{имя_бакета}} --recursive`

- Показать справку:

`aws s3 rm help`
