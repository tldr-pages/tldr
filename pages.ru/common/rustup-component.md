# rustup component

> Управлять установленными компонентами набора инструментов.
> Без опции `--toolchain` `rustup` использует набор инструментов по умолчанию. Подробнее см. `rustup help toolchain`.
> Больше информации: <https://rust-lang.github.io/rustup/>.

- Добавить компонент в набор инструментов:

`rustup component add --toolchain {{набор_инструментов}} {{компонент}}`

- Удалить компонент из набора инструментов:

`rustup component remove --toolchain {{набор_инструментов}} {{компонент}}`

- Показать установленные и доступные компоненты для набора инструментов:

`rustup component list --toolchain {{набор_инструментов}}`

- Показать установленные компоненты для набора инструментов:

`rustup component list --toolchain {{набор_инструментов}} --installed`
