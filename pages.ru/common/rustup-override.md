# rustup override

> Управлять переопределениями набора инструментов для каталогов.
> Подробнее см. `rustup help toolchain`.
> Больше информации: <https://rust-lang.github.io/rustup/>.

- Показать переопределения наборов инструментов для каталогов:

`rustup override list`

- Установить переопределение набора инструментов для текущего каталога (т.е. указать `rustup` запускать `cargo`, `rustc` и т.д. из конкретного набора инструментов в этом каталоге):

`rustup override set {{набор_инструментов}}`

- Удалить переопределение набора инструментов для текущего каталога:

`rustup override unset`

- Удалить все переопределения наборов инструментов для несуществующих каталогов:

`rustup override unset --nonexistent`
