# git show-ref

> Команда Git для вывода списка ссылок.
> Больше информации: <https://git-scm.com/docs/git-show-ref>.

- Показать все ссылки в репозитории:

`git show-ref`

- Показать только ссылки на ветки:

`git show-ref --branches`

- Показать только ссылки на теги:

`git show-ref --tags`

- Проверить существование указанной ссылки:

`git show-ref --verify {{путь/к/ссылке}}`
