# jj git import

> Обновлять репозиторий Jujutsu изменениями, сделанными в базовом Git-репозитории.
> В совмещённых рабочих пространствах импорт происходит автоматически.
> Смотрите также: `jj git export`.
> Больше информации: <https://docs.jj-vcs.dev/latest/cli-reference/#jj-git-import>.

- Импортировать изменения из базового Git-репозитория:

`jj git import`

- Принудительно импортировать изменения в совмещённом рабочем пространстве:

`jj git import --ignore-working-copy`
