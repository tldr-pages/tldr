# jj git colocation

> Управлять совмещением репозиториев Jujutsu и Git.
> Смотрите также: `jj git init`.
> Больше информации: <https://docs.jj-vcs.dev/latest/cli-reference/#jj-git-colocation>.

- Показать текущий статус совмещения:

`jj git colocation status`

- Преобразовать в совмещённый репозиторий Jujutsu/Git:

`jj git colocation enable`

- Преобразовать в несовмещённый репозиторий Jujutsu/Git:

`jj git colocation disable`
