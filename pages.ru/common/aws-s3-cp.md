# aws s3 cp

> Копировать локальные файлы или объекты S3 в другое расположение локально или в S3.
> Больше информации: <https://docs.aws.amazon.com/cli/latest/reference/s3/cp.html>.

- Скопировать файл из локальной системы в указанный бакет:

`aws s3 cp {{путь/к/файлу}} s3://{{имя_бакета}}/{{путь/к/удалённому_файлу}}`

- Скопировать конкретный объект S3 в другой бакет:

`aws s3 cp s3://{{имя_бакета1}}/{{путь/к/файлу}} s3://{{имя_бакета2}}/{{путь/к/цели}}`

- Скопировать конкретный объект S3 в другой бакет, сохранив исходное имя:

`aws s3 cp s3://{{имя_бакета1}}/{{путь/к/файлу}} s3://{{имя_бакета2}}`

- Рекурсивно скопировать объекты S3 в локальный каталог:

`aws s3 cp s3://{{имя_бакета}} . --recursive`

- Показать справку:

`aws s3 cp help`
