# tailscale file

> Отправлять файлы между подключёнными устройствами в сети Tailscale.
> В настоящее время не поддерживается отправка файлов на устройства других пользователей, даже в той же сети Tailscale.
> Больше информации: <https://tailscale.com/kb/1106/taildrop>.

- Отправить файл на конкретный узел:

`tailscale file cp {{путь/к/файлу}} {{имя_хоста|ip_адрес}}:`

- Сохранить файлы, отправленные на текущий узел, в конкретный каталог:

`tailscale file get {{путь/к/каталогу}}`
