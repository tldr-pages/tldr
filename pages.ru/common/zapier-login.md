# zapier login

> Входить в учётную запись Zapier.
> Больше информации: <https://github.com/zapier/zapier-platform/blob/main/packages/cli/docs/cli.md#login>.

- Войти в учётную запись Zapier:

`zapier login`

- Войти в учётную запись Zapier с помощью ключа развёртывания для SSO:

`zapier login {{[-s|--sso]}}`

- Показать дополнительную отладочную информацию:

`zapier login {{[-d|--debug]}}`
