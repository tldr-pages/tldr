# pixi global

> Управлять глобальными пакетами.
> Больше информации: <https://pixi.sh/latest/reference/cli/#global>.

- Установить пакет глобально и добавить в PATH:

`pixi global install {{пакет1 пакет2 ...}}`

- Удалить глобальный пакет:

`pixi global remove {{пакет1 пакет2 ...}}`

- Вывести список всех глобально установленных пакетов:

`pixi global list`

- Обновить глобально установленный пакет:

`pixi global upgrade {{пакет}}`

- Обновить все глобально установленные пакеты:

`pixi global upgrade-all`
