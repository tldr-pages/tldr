# javadoc

> Генерировать документацию Java API в формате HTML из исходного кода.
> Больше информации: <https://docs.oracle.com/en/java/javase/25/docs/specs/man/javadoc.html>.

- Сгенерировать документацию для исходного кода Java и сохранить результат в каталог:

`javadoc -d {{путь/к/каталогу}}/ {{путь/к/исходному_коду_java}}`

- Сгенерировать документацию с указанной кодировкой:

`javadoc -docencoding {{UTF-8}} {{путь/к/исходному_коду_java}}`

- Сгенерировать документацию, исключив некоторые пакеты:

`javadoc -exclude {{список_пакетов}} {{путь/к/исходному_коду_java}}`
