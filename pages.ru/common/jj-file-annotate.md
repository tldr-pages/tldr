# jj file annotate

> Показывать исходное изменение для каждой строки целевого файла в репозитории `jj`.
> Больше информации: <https://docs.jj-vcs.dev/latest/cli-reference/#jj-file-annotate>.

- Аннотировать файл построчно в рабочей копии:

`jj file annotate {{путь/к/файлу}}`

- Аннотировать файл начиная с конкретной ревизии:

`jj file annotate {{[-r|--revision]}} {{ревизия}} {{путь/к/файлу}}`

- Аннотировать файл с использованием пользовательского шаблона:

`jj file annotate {{[-T|--template]}} "{{шаблон}}" {{путь/к/файлу}}`
