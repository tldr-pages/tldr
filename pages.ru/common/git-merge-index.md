# git merge-index

> Запускать программу слияния для файлов, требующих слияния.
> Больше информации: <https://git-scm.com/docs/git-merge-index>.

- Выполнить слияние всех файлов, требующих разрешения, с помощью стандартного помощника:

`git merge-index git-merge-one-file -a`

- Выполнить слияние определённого файла:

`git merge-index git-merge-one-file -- {{путь/к/файлу}}`

- Выполнить слияние нескольких файлов, продолжая при ошибках:

`git merge-index -o git-merge-one-file -- {{путь/к/файлу1 путь/к/файлу2 ...}}`

- Выполнить тихое слияние всех файлов с помощью пользовательской программы:

`git merge-index -q {{программа_слияния}} -a`

- Проверить входные данные слияния для файла с помощью `cat`:

`git merge-index cat -- {{путь/к/файлу}}`
