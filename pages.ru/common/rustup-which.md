# rustup which

> Показывать путь к исполняемому файлу команды, управляемой `rustup`.
> Аналог `which`, но выполняет поиск в наборе инструментов Rust вместо `$PATH`.
> Больше информации: <https://rust-lang.github.io/rustup/>.

- Показать путь к исполняемому файлу в наборе инструментов по умолчанию:

`rustup which {{команда}}`

- Показать путь к исполняемому файлу в указанном наборе инструментов (подробнее см. `rustup help toolchain`):

`rustup which --toolchain {{набор_инструментов}} {{команда}}`
