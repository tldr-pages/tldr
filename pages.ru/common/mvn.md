# mvn

> Apache Maven: собирать Java-проекты и управлять ими.
> Больше информации: <https://manned.org/mvn>.

- Скомпилировать проект:

`mvn compile`

- Скомпилировать и упаковать скомпилированный код в формат для распространения, такой как `jar`:

`mvn package`

- Скомпилировать и упаковать, пропуская модульные тесты:

`mvn package {{[-D|--define]}} skipTests`

- Установить собранный пакет в локальный репозиторий Maven. (Это также вызовет команды компиляции и упаковки):

`mvn install`

- Удалить артефакты сборки из целевого каталога:

`mvn clean`

- Выполнить очистку, а затем запустить фазу упаковки:

`mvn clean package`

- Очистить и упаковать код с заданным профилем сборки:

`mvn clean {{[-P|--activate-profiles]}} {{профиль}} package`

- Запустить класс с методом main:

`mvn exec:java {{[-D|--define]}} exec.mainClass="{{com.example.Main}}" {{[-D|--define]}} exec.args="{{аргумент1 аргумент2 ...}}"`
