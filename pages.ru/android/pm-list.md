# pm list

> Показывать пользователей, пакеты, разрешения, инструментацию, группы разрешений, функции и библиотеки, управляемые менеджером пакетов.
> Больше информации: <https://developer.android.com/tools/adb#pm>.

- Показать все установленные пакеты:

`pm list packages`

- Показать [s]истемные или сторонние ([3]) пакеты:

`pm list packages {{-s|-3}}`

- Показать всех пользователей системы:

`pm list users`

- Показать все известные группы разрешений:

`pm list permission-groups`

- Показать все известные разрешения:

`pm list permissions`

- Показать все тестовые пакеты:

`pm list instrumentation`

- Показать все функции системы:

`pm list features`

- Показать все библиотеки, поддерживаемые текущим устройством:

`pm list libraries`
