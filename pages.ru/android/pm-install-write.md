# pm install-write

> Добавлять пакеты в сессию установки.
> Смотрите также: `pm install-create`, `pm install-commit`.
> Больше информации: <https://developer.android.com/tools/adb#pm>.

- Добавить пакет в набор для установки:

`pm install-write {{идентификатор_сессии}} {{метка}} {{путь/к/пакету.apk}}`
