# screencap

> Делать снимки экрана мобильного дисплея.
> Примечание: эту команду можно использовать только через `adb shell`.
> Больше информации: <https://developer.android.com/tools/adb#screencap>.

- Сделать снимок экрана:

`screencap {{путь/к/изображению.png}}`

- Вывести содержимое файла в `stdout` в формате PNG:

`screencap -p`

- Сделать снимок экрана и сохранить его через соединение `adb`:

`adb shell screencap -p > {{путь/к/изображению.png}}`

- Показать справку:

`screencap -h`
