# sfc

> Проверить целостность системных файлов Windows.
> Больше информации: <https://learn.microsoft.com/windows-server/administration/windows-commands/sfc>.

- Проверить все системные файлы и по возможности исправить найденные проблемы:

`sfc /scannow`

- Проверить все системные файлы без попытки исправления:

`sfc /verifyonly`

- Проверить конкретный файл и по возможности исправить проблемы:

`sfc /scanfile={{путь\к\файлу}}`

- Проверить конкретный файл без попытки исправления:

`sfc /verifyfile={{путь\к\файлу}}`

- При офлайн-восстановлении указать загрузочную директорию:

`sfc /offbootdir={{путь\к\директории}}`

- При офлайн-восстановлении указать директорию Windows:

`sfc /offwindir={{путь\к\директории}}`

- Показать справку:

`sfc`
