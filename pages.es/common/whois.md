# whois

> Cliente para el protocolo WHOIS (RFC 3912).
> Más información: <https://manned.org/whois>.

- Obtiene información sobre un nombre de dominio:

`whois {{example.com}}`

- Obtiene información sobre una dirección IP:

`whois {{8.8.8.8}}`

- Obtiene los datos de contacto para denunciar abusos de una dirección IP:

`whois -b {{8.8.8.8}}`
