# sniffer.py

> Captura y muestra paquetes de red para los protocolos especificados utilizando sockets sin procesar.
> Forma parte del paquete Impacket.
> Más información: <https://github.com/fortra/impacket>.

- Captura paquetes para los protocolos predeterminados (ICMP, TCP, UDP):

`sniffer.py`

- Captura paquetes de protocolos específicos (p. ej., ICMP, TCP):

`sniffer.py {{protocolo1 protocolo2 ...}}`

- Captura paquetes de protocolos específicos (p. ej., TCP):

`sniffer.py tcp`
