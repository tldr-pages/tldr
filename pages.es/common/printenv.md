# printenv

> Muestra los valores de las variables de entorno.
> Más información: <https://www.gnu.org/software/coreutils/manual/html_node/printenv-invocation.html>.

- Muestra los pares clave-valor de todas las variables de entorno:

`printenv`

- Muestra el valor de una variable concreta:

`printenv {{HOME}}`

- Muestra el valor de una variable y terminar con un carácter NUL en lugar de un salto de línea:

`printenv {{[-0|--null]}} {{HOME}}`
