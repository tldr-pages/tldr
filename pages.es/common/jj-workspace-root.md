# jj workspace root

> Muestra el directorio raíz de un espacio de trabajo de Jujutsu.
> Vea también: `jj workspace`, `jj git root`.
> Más información: <https://docs.jj-vcs.dev/latest/cli-reference/#jj-workspace-root>.

- Muestra el directorio raíz del espacio de trabajo actual:

`jj workspace root`

- Muestra el directorio raíz de un espacio de trabajo específico:

`jj workspace root --name {{nombre_del_espacio_de_trabajo}}`
