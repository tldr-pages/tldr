# apt install

> Instala paquetes para distribuciones basadas en Debian.
> Más información: <https://manned.org/apt.8>.

- Instala un paquete o lo actualiza a la última versión:

`sudo apt install {{paquete}}`

- Muestra información detallada de las versiones de los paquetes durante la instalación o actualización:

`sudo apt install {{[-V|--verbose-versions]}} {{paquete}}`
