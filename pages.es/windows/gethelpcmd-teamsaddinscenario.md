# GetHelpCmd TeamsAddinScenario

> Soluciona problemas relacionados con la instalación del complemento de Microsoft Teams para Microsoft Outlook (clásico).
> Nota: Este comando está obsoleto y no funcionará en la nueva aplicación de Outlook.
> Forma parte de `GetHelpCmd.exe`, anteriormente `SaRAcmd.exe` (Asistente de soporte y recuperación de Microsoft).
> Más información: <https://learn.microsoft.com/troubleshoot/microsoft-365/admin/miscellaneous/get-help-teams-meeting-add-in-outlook>.

- Ejecuta el solucionador de problemas, cierra Outlook y acepta el Acuerdo de licencia de usuario final (EULA) de este comando:

`GetHelpCmd.exe -S TeamsAddinScenario -AcceptEula -CloseOutlook`
