# Set-Alias

> Un comando de PowerShell para establecer o modificar un alias.
> Nota: Se puede utilizar `sal` como alias de `Set-Alias`.
> Más información: <https://learn.microsoft.com/powershell/module/microsoft.powershell.utility/set-alias>.

- Crea o reasigna un nuevo alias:

`Set-Alias -Name {{texto}} -Value {{comando}}`

- Añade una descripción al alias:

`Set-Alias -Name {{texto}} -Value {{comando}} -Description "{{descripción}}"`
