# reg restore

> Restaura una clave y sus valores desde un archivo `.hiv` nativo.
> Consulta `reg-save` para más información.
> Más información: <https://learn.microsoft.com/windows-server/administration/windows-commands/reg-restore>.

- Sobrescribe una clave especificada con datos de un archivo de respaldo:

`reg restore {{nombre_de_clave}} {{ruta\al\archivo.hiv}}`
