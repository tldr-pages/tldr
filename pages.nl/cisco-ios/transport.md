# transport

> Beheer transportprotocollen van lijnen.
> Toegankelijk in de configuratiemodus onder `line`.
> Meer informatie: <https://www.cisco.com/c/en/us/td/docs/routers/sdwan/command/iosxe/qualified-cli-command-reference-guide/m-line-commands.pdf>.

- Beperk lijnprotocollen tot `ssh`:

`transport input ssh`

- Beperk lijnprotocollen tot `telnet`:

`transport input telnet`
