# show

> Toon diverse systeeminformatie.
> Meer informatie: <https://www.cisco.com/c/en/us/td/docs/switches/datacenter/nexus5000/sw/command/reference/fund/n5k-fund-cr/n5k-fund_cmds_show.html>.

- Toon de IP-adressen van de switch:

`{{[sh|show]}} ip interface brief`

- Toon de configuratie van een specifieke interface:

`{{[sh|show]}} ip interface {{vlan1}}`

- Toon de VLAN-configuratie:

`{{[sh|show]}} vlan`

- Toon de huidige actieve configuratie:

`{{[sh|show]}} running-config`

- Toon de SSH-configuratie:

`{{[sh|show]}} ip ssh`
