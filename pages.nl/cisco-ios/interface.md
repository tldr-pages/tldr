# interface

> Beheer interfaces.
> Toegankelijk in de configuratiemodus.
> Meer informatie: <https://www.cisco.com/c/en/us/td/docs/ios-xml/ios/interface/command/ir-cr-book/ir-i1.html>.

- Configureer een VLAN:

`interface vlan {{1}}`

- Stel een interface in als actief of inactief (dit wordt uitgevoerd binnen het `interface`-commando):

`{{no shutdown|shutdown}}`
