# BOOT

> Boot direct vanaf floppy- of harde schijf-images, waarbij OS-emulatie wordt overgeslagen.
> Meer informatie: <https://www.dosbox.com/wiki/BOOT>.

- Boot vanaf een floppy-image:

`BOOT {{pad/naar/floppy.img}}`

- Boot vanaf een harde schijf-image:

`BOOT {{pad/naar/harde_schijf.img}}`

- Boot meerdere floppy-images:

`BOOT {{pad/naar/floppy1.img pad/naar/floppy2.img ...}}`
