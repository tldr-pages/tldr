# times

> Print de cumulatieve CPU-gebruikstijd van de huidige shell.
> De eerste regel is het huidige CPU-gebruik van de shell voor User en System. De tweede regel is voor alle child-processen.
> Zie ook: `time`.
> Meer informatie: <https://www.gnu.org/software/bash/manual/bash.html#index-times>.

- Print het CPU-gebruik:

`times`
