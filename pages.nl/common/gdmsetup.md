# gdmsetup

> Start een GUI voor het configureren van de GNOME Display Manager (GDM).
> Resulteert in bewerkte bestanden in ofwel `/etc/X11/gdm/gdm.conf` of `/etc/gdm/gdm.conf`, afhankelijk van de distributie en omgeving.
> Zie ook: `gdm`, `gdm-binary`, `gdm-stop`, `gdm-restart`, `gdm-safe-restart`.
> Meer informatie: <https://manned.org/gdm>.

- Voer de GNOME Display Manager GUI-configuratietoepassing uit:

`gdmsetup`
