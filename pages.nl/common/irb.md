# irb

> Interactieve Ruby-shell.
> Meer informatie: <https://ruby.github.io/irb/>.

- Start de interactieve shell:

`irb`

- Start de interactieve shell met de eenvoudige prompt:

`irb --simple-prompt`

- Start de interactieve shell zonder het configuratiebestand te lezen:

`irb -f`

- Evalueer Ruby-code gelezen vanaf `stdin`:

`echo "{{puts 'Hello world'}}" | irb --noecho`

- Toon de help:

`irb {{[-h|--help]}}`

- Toon de versie:

`irb {{[-v|--version]}}`
