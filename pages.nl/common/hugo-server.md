# hugo server

> Bouw en serveer een site met de ingebouwde webserver van Hugo.
> Meer informatie: <https://gohugo.io/commands/hugo_server/>.

- Bouw en serveer een site:

`hugo server`

- Bouw en serveer een site op een opgegeven poortnummer:

`hugo server {{[-p|--port]}} {{poortnummer}}`

- Bouw en serveer een site en minify ondersteunde uitvoerformaten (HTML, XML, etc.):

`hugo server --minify`

- Bouw en serveer een site in de productieomgeving met volledige re-renders en minify ondersteunde formaten:

`hugo server {{[-e|--environment]}} {{production}} --disableFastRender --minify`

- Toon de help:

`hugo server {{[-h|--help]}}`
