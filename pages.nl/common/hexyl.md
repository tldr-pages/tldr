# hexyl

> Een eenvoudige hexviewer voor de terminal. Gebruikt gekleurde uitvoer om verschillende categorieën bytes te onderscheiden.
> Zie ook: `od`, `xxd`, `hexdump`.
> Meer informatie: <https://github.com/sharkdp/hexyl/blob/master/doc/hexyl.1.md>.

- Toon de hexadecimale representatie van een bestand:

`hexyl {{pad/naar/bestand}}`

- Toon de hexadecimale representatie van de eerste n bytes van een bestand:

`hexyl {{[-n|--length]}} {{n}} {{pad/naar/bestand}}`
