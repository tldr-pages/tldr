# Set-NodeInstallLocation

> Stel de standaard Node.js installatiemap in voor `ps-nvm`.
> Onderdeel van `ps-nvm` en kan alleen uitgevoerd worden in PowerShell.
> Meer informatie: <https://github.com/aaronpowell/ps-nvm>.

- Verander de Node.js installatielocatie naar een gespecificeerde map (`ps-nvm` zal een nieuwe `.nvm` submap maken om deze te kunnen installeren):

`Set-NodeInstallLocation {{pad/naar/map}}`
