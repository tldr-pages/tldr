# gvim

> Een grafische gebruikersomgeving versie van Vim (Vi IMproved), een command-line tekstbewerker.
> Dit commando is een alias van `vim -g`.
> Zie ook: `vimdiff`, `vimtutor`, `nvim`, `vim`.
> Meer informatie: <https://www.vim.org/>.

- Open `gvim`:

`gvim`

- Open een specifiek bestand:

`gvim {{pad/naar/bestand}}`
