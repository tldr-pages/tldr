# mpd

> Music Player Daemon.
> Zie ook: `mpc`, `ncmpcpp`.
> Meer informatie: <https://mpd.readthedocs.io/en/stable/mpd.1.html>.

- Start MPD:

`mpd`

- Start MPD zonder het configuratiebestand te lezen:

`mpd --no-config`

- Start MPD en koppel het niet los van de console:

`mpd --no-daemon`

- Beëindig de huidige actieve MPD-sessie:

`mpd --kill`
