# print

> `print` kan verwijzen naar meerdere commando's met dezelfde naam.

- Bekijk de documentatie voor de ingebouwde Zsh-functie:

`tldr print.zsh`

- Bekijk de documentatie voor de `print`-alias van `run-mailcap --action=print`:

`tldr {{[-p|--platform]}} linux run-mailcap`

- Bekijk de documentatie voor het afdrukken van tekstbestanden op Windows:

`tldr {{[-p|--platform]}} windows print.win`
