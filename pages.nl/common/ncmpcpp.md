# ncmpcpp

> Een muziekspelerclient voor de Music Player Daemon.
> Zie ook: `mpd`, `mpc`, `qmmp`, `termusic`.
> Meer informatie: <https://rybczak.net:443/ncmpcpp/>.

- Maak verbinding met een music player daemon op een gegeven host en poort:

`ncmpcpp --host {{ip_adres}} --port {{poort}}`

- Toon metadata van het huidige nummer op de console:

`ncmpcpp --current-song`

- Gebruik een opgegeven configuratiebestand:

`ncmpcpp --config {{bestand}}`

- Gebruik een andere set toetsenbindingen uit een bestand:

`ncmpcpp --bindings {{bestand}}`
