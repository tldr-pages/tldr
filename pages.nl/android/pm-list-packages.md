# pm list packages

> Toon geïnstalleerde, bekende of gefilterde pakketten op een Android-apparaat.
> Meer informatie: <https://developer.android.com/tools/adb#pm>.

- Toon alle geïnstalleerde pakketten:

`pm list packages`

- Toon alle pakketten en de bijbehorende APK-bestandspaden ([f]):

`pm list packages -f`

- Toon alleen uitgeschakelde pakketten ([d]isabled):

`pm list packages -d`

- Toon alleen ingeschakelde pakketten ([e]nabled):

`pm list packages -e`

- Toon alleen [s]ysteempakketten:

`pm list packages -s`

- Toon alleen pakketten van derden ([3]rd-party, niet-systeem):

`pm list packages -3`

- Toon de [i]nstaller voor elk pakket:

`pm list packages -i`
