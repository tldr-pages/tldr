# pm install-write

> Voeg pakketten toe aan de installatiesessie.
> Zie ook: `pm install-create`, `pm install-commit`.
> Meer informatie: <https://developer.android.com/tools/adb#pm>.

- Voeg een pakket toe aan de installatiebatch:

`pm install-write {{sessie_id}} {{label}} {{pad/naar/pakket.apk}}`
