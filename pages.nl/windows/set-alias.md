# Set-Alias

> PowerShell commando om een alias in te stellen of te wijzigen.
> Opmerking: `sal` kan gebruikt worden als een alias voor `Set-Alias`.
> Meer informatie: <https://learn.microsoft.com/powershell/module/microsoft.powershell.utility/set-alias>.

- Maak een nieuwe alias aan of wijs deze opnieuw toe:

`Set-Alias -Name {{tekst}} -Value {{commando}}`

- Voeg een beschrijving toe aan de alias:

`Set-Alias -Name {{tekst}} -Value {{commando}} -Description "{{beschrijving}}"`
