# termusic

> Een terminal muziekspeler geschreven in Rust die vim-achtige toetsenbindingen gebruikt.
> Zie ook: `cmus`, `ncmpcpp`, `audacious`.
> Meer informatie: <https://github.com/tramhao/termusic>.

- Open termusic in een specifieke map. (Dit kan permanent worden ingesteld in `~/.config/termusic/config.toml`):

`termusic {{pad/naar/map}}`

- Schakel het tonen van de albumhoes uit voor een specifiek bestand:

`termusic -c {{pad/naar/muziekbestand}}`

- Toon de help:

`termusic --help`
