# caligula

> Een gebruiksvriendelijke, lichtgewicht TUI voor disk imaging.
> Zie ook: `dd`.
> Meer informatie: <https://github.com/ifd3f/caligula>.

- Flash een ISO naar een schijf:

`caligula burn {{pad/naar/image.iso}}`

- Flash een ISO naar een schijf zonder de hash interactief in te voeren:

`caligula burn {{pad/naar/image.iso}} {{[-s|--hash]}} {{hash}}`
