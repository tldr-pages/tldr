# pipewire

> Start de PipeWire daemon.
> Meer informatie: <https://docs.pipewire.org/page_man_pipewire_1.html>.

- Start de PipeWire daemon:

`pipewire`

- Gebruik een ander configuratiebestand:

`pipewire --config {{pad/naar/bestand.conf}}`

- Stel het detailniveau in (error, warn, info, debug of trace):

`pipewire -{{v|vv|...|vvvvv}}`

- Toon de help:

`pipewire --help`
