# mount

> Підключення файлової системи до каталогу.
> Дивіться також: `udisksctl`.
> Більше інформації: <https://manned.org/mount.8>.

- Показати всі змонтовані файлові системи:

`mount`

- Монтувати пристрій до каталогу:

`mount {{шлях/до/пристрою}} {{шлях/до/цільового_каталогу}}`

- Створити окремий каталог, якщо його не існує, та змонтувати до нього пристрій:

`mount {{[-m|--mkdir]}} {{шлях/до/пристрою}} {{шлях/до/цільового_каталогу}}`

- Монтувати пристрій до каталогу для певного користувача:

`mount {{[-o|--options]}} uid={{id_користувача}},gid={{id_групи}} {{шлях/до/пристрою}} {{шлях/до/цільового_каталогу}}`

- Монтувати пристрій CD-ROM (з типом файлової системи ISO9660) до `/cdrom` (лише для читання):

`mount {{[-t|--types]}} iso9660 {{[-o|--options]}} ro {{/dev/cdrom}} /cdrom`

- Монтувати всі файлові системи, визначені в `/etc/fstab`:

`mount {{[-a|--all]}}`

- Монтувати певну файлову систему, описану в `/etc/fstab` (наприклад `/dev/sda1 /шлях/до/точки_монтування ext2 defaults 0 2`):

`mount {{/шлях/до/точки_монтування}}`

- Монтувати каталог до іншого каталогу:

`mount {{[-B|--bind]}} {{шлях/до/старого_каталогу}} {{шлях/до/нового_каталогу}}`
