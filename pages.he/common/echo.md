# echo

> הדפסת הארגומנטים שסופקו.
> ראו גם: `printf`.
> למידע נוסף: <https://www.gnu.org/software/coreutils/manual/html_node/echo-invocation.html>.

- הדפסת הודעת טקסט (הערה: המרכאות אופציונליות):

`echo "{{שלום עולם}}"`

- הדפסת הודעה עם משתני סביבה מורחבים:

`echo "{{נתיב הבית שלי הוא: $HOME}}"`

- הדפסת הודעה ללא ירידת שורה בסוף:

`echo -n "{{שלום עולם}}"`

- הדפסת הודעה עם תווים מיוחדים (כגון טאב או שורה חדשה):

`echo -e "{{שורה ראשונה\nשורה שנייה}}"`

- הדפסת מצב היציאה של הפקודה האחרונה שהורצה (הערה: ב-Windows Command Prompt וב-PowerShell הפקודות המקבילות הן echo %errorlevel% ו-$lastexitcode בהתאמה):

`echo $?`
