# qm status

> Affiche l’état d’une machine virtuelle.
> Plus d'informations : <https://pve.proxmox.com/pve-docs/qm.1.html#cli_qm_status>.

- Affiche l’état d’une machine virtuelle spécifique :

`qm {{[stat|status]}} {{100}}`

- Affiche l’état détaillé d’une machine virtuelle spécifique :

`qm {{[stat|status]}} {{100}} --verbose {{true}}`
