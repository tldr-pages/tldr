# dmesg

> Écrit les messages du noyau sur la sortie standard.
> Plus d'informations : <https://www.unix.com/man-page/sunos/1m/dmesg>.

- Affiche les messages du noyau :

`dmesg`

- Affiche la quantité de mémoire physique disponible sur ce système :

`dmesg | grep -i memory`

- Affiche les messages du noyau une page à la fois :

`dmesg | less`
