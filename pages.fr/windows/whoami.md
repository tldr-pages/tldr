# whoami

> Affiche des détails sur l'utilisateur actuel.
> Plus d'informations : <https://learn.microsoft.com/windows-server/administration/windows-commands/whoami>.

- Affiche le nom de l'utilisateur actuel :

`whoami`

- Affiche les groupes pour lesquels l'utilisateur actuel est un membre :

`whoami /groups`

- Affiche les droits de l'utilisateur actuel :

`whoami /priv`

- Affiche le nom principal d'utilisateur (UPN) de l'utilisateur actuel :

`whoami /upn`

- Affiche l'identifiant de connexion de l'utilisateur actuel :

`whoami /logonid`

- Affiche toutes les informations de l'utilisateur actuel :

`whoami /all`
