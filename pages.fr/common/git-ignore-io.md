# git ignore-io

> Génère le fichier `.gitignore` depuis des templates prédéfinis.
> Fait partie de `git-extras`.
> Plus d'informations : <https://github.com/tj/git-extras/blob/main/Commands.md#git-ignore-io>.

- Liste les templates disponibles :

`git ignore-io list`

- Génère un template `.gitignore` :

`git ignore-io {{item_a,item_b,item_n}}`
