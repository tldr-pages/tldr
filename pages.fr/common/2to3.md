# 2to3

> Conversion automatisé de code Python 2 vers 3.
> Remarque : Ce module est obsolète depuis la version 3.11 et a été supprimé depuis la version 3.13.
> Pour référence, voir : <https://github.com/python/cpython/blob/8d42e2d915c3096e7eac1c649751d1da567bb7c3/Doc/whatsnew/3.13.rst?plain=1#L188>.
> Plus d'informations : <https://manned.org/2to3>.

- Affiche les changements qui seront effectués sans les effectuer (coup d'essai) :

`2to3 {{chemin/vers/fichier.py}}`

- Convertit un fichier Python 2 en Python 3 :

`2to3 {{[-w|--write]}} {{chemin/vers/fichier.py}}`

- Convertit des fonctionnalités spécifiques de Python 2 vers Python 3 :

`2to3 {{[-w|--write]}} {{chemin/vers/fichier.py}} {{[-f|--fix]}} {{raw_input}} {{[-f|--fix]}} {{print}}`

- Convertit toutes les fonctionnalités de Python 2 vers Python 3 sauf exceptions spécifiques :

`2to3 {{[-w|--write]}} {{chemin/vers/fichier.py}} {{[-x|--nofix]}} {{has_key}} {{[-x|--nofix]}} {{isinstance}}`

- Affiche une liste de toutes les fonctionnalités de language qui peuvent être converties de Python 2 vers Python 3 :

`2to3 {{[-l|--list-fixes]}}`

- Convertit tous les fichiers Python2 vers Python 3 dans un répertoire :

`2to3 {{[-o|--output-dir]}} {{chemin/vers/répertoire_python3}} {{[-W|--write-unchanged-files]}} {{[-n|--nobackups]}} {{chemin/vers/répertoirer_python2}}`

- Exécute 2to3 avec plusieurs fils d'exécution :

`2to3 {{[-j|--processes]}} {{4}} {{[-o|--output-dir]}} {{chemin/vers/répertoire_python3}} {{[-w|--write]}} {{[-n|--nobackups]}} --no-diffs {{chemin/vers/répertoire_python2}}`
