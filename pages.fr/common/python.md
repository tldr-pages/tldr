# python

> Interpréteur du langage Python.
> Plus d'informations : <https://docs.python.org/using/cmdline.html>.

- Démarre un REPL (shell interactif) :

`python`

- Exécute un fichier Python spécifique :

`python {{chemin/vers/fichier.py}}`

- Exécute un fichier Python spécifique et démarre un REPL :

`python -i {{chemin/vers/fichier.py}}`

- Exécute une expression Python :

`python -c "{{expression}}"`

- Exécute le script du module de la bibliothèque spécifiée :

`python -m {{module}} {{arguments}}`

- Installe un paquet avec `pip` :

`python -m pip install {{paquet}}`

- Débogue un script Python de manière interactive :

`python -m pdb {{chemin/vers/fichier.py}}`

- Démarre le serveur HTTP intégré sur le port 8000 dans le répertoire courant :

`python -m http.server`
