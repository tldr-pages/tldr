# convert

> Cette commande est un alias de `magick convert`.
> Remarque : Cet alias est obsolète depuis ImageMagick 7. Il a été remplacé par `magick`.
> Utilisez `magick convert` si vous devez utiliser l’ancien outil dans les versions 7+.

- Affiche la documentation de la commande originale :

`tldr magick convert`
