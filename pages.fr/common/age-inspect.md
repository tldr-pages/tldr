# age-inspect

> Inspecte les fichiers chiffrés `age`.
> Voir aussi : `age`, `age-keygen`.
> Plus d'informations : <https://manned.org/age-inspect>.

- Affiche le type de destinataire,la taille du fichier et s'il utilise le chiffrement postquantique :

`age-inspect {{chemin/vers/fichier}}`

- Affiche la sortie sur `stdout` au format JSON :

`age-inspect --json {{chemin/vers/fichier}}`
