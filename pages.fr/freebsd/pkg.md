# pkg

> Gestionnaire de paquets FreeBSD.
>
> Plus d'informations : <https://man.freebsd.org/cgi/man.cgi?pkg>.

- Installe un nouveau paquet :

`pkg install {{paquet}}`

- Supprime un paquet :

`pkg delete {{paquet}}`

- Met à niveau tous les paquets :

`pkg upgrade`

- Recherche un paquet :

`pkg search {{mot-clé}}`

- Liste les paquets installés :

`pkg info`

- Supprime les dépendances inutiles :

`pkg autoremove`
