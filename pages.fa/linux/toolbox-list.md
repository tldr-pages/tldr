# toolbox list

> فهرست کردن کانتینرها و تصاویر موجود Toolbx.
> اطلاعات بیشتر: <https://manned.org/toolbox-list>.

- فهرست کردن همهٔ کانتینرها و تصاویر Toolbx:

`toolbox list`

- فهرست کردن فقط کانتینرهای Toolbx:

`toolbox list {{[-c|--containers]}}`

- فهرست کردن فقط تصاویر Toolbx:

`toolbox list {{[-i|--images]}}`
