# sos

> ابزار یکپارچه برای جمع‌آوری گزارش‌های سیستم و سایر اطلاعات اشکال‌زدایی.
> مدیران سیستم و نمایندگان پشتیبانی برای کمک به عیب‌یابی از آن استفاده می‌کنند.
> اطلاعات بیشتر: <https://github.com/sosreport/sos>.

- تولید بایگانی اطلاعات و پیکربندی سیستم:

`sudo sos report`

- تولید گزارش با شناسهٔ پروندهٔ پشتیبانی:

`sudo sos report --case-id {{case_id}}`

- تولید گزارش و بارگذاری آن در مقصد پشتیبانی توزیع:

`sudo sos report --upload`

- فهرست کردن همهٔ افزونه‌های موجود و گزینه‌های آن‌ها:

`sudo sos report {{[-l|--list-plugins]}}`

- جمع‌آوری گزارش‌های کامل بدون محدودیت اندازه:

`sudo sos report --all-logs`

- تولید غیرتعاملی گزارش بدون پرسش:

`sudo sos report --batch`

- افزودن برچسب دلخواه به نام بایگانی تولیدشده:

`sudo sos report --label {{label}}`

- ذخیرهٔ بایگانی تولیدشده در دایرکتوری مشخص:

`sudo sos report --tmp-dir {{path/to/directory}}`
