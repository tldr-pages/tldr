# koji help

> نمایش اطلاعات راهنمای دستورهای Koji.
> اطلاعات بیشتر: <https://docs.pagure.org/koji/HOWTO/#exploring-koji>.

- نمایش همهٔ دستورهای موجود:

`koji help`

- نمایش راهنمای دستهٔ مشخص (دسته‌های موجود: admin، all، bind، build، download، info، misc، monitor، search):

`koji help {{category}}`

- نمایش راهنما:

`koji help {{[-h|--help]}}`
