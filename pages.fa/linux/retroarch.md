# retroarch

> رابطی برای شبیه‌سازها، موتورهای بازی و پخش‌کننده‌های رسانه.
> پیاده‌سازی مرجع API مربوط به libretro.
> اطلاعات بیشتر: <https://manned.org/retroarch>.

- شروع در حالت منو:

`retroarch`

- شروع در حالت تمام‌صفحه:

`retroarch {{[-f|--fullscreen]}}`

- فهرست کردن همهٔ قابلیت‌های کامپایل‌شده:

`retroarch --features`

- تنظیم مسیر فایل پیکربندی:

`retroarch {{[-c|--config]}} {{path/to/config_file}}`

- نمایش راهنما:

`retroarch {{[-h|--help]}}`

- نمایش نسخه:

`retroarch --version`
