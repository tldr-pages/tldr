# rig

> ابزاری برای ترکیب نام، نام خانوادگی، شمارهٔ خیابان و آدرس تصادفی همراه با شهر، ایالت، کد پستی و کد منطقهٔ جغرافیایی سازگار با آن‌ها.
> اطلاعات بیشتر: <https://manned.org/rig>.

- نمایش نام تصادفی (مردانه یا زنانه) و آدرس:

`rig`

- نمایش نام تصادفی مردانه یا زنانه و آدرس:

`rig {{-m|-f}}`

- استفاده از فایل‌های داده از دایرکتوری مشخص (پیش‌فرض `/usr/share/rig`):

`rig -d {{path/to/directory}}`

- نمایش تعداد مشخصی هویت:

`rig -c {{number}}`

- نمایش تعداد مشخصی هویت زنانه:

`rig -f -c {{number}}`
