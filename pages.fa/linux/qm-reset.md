# qm reset

> بازنشانی ماشین مجازی در مدیر ماشین مجازی QEMU/KVM.
> اطلاعات بیشتر: <https://pve.proxmox.com/pve-docs/qm.1.html#cli_qm_reset>.

- بازنشانی ماشین مجازی:

`qm reset {{100}}`

- بازنشانی ماشین مجازی و صرف‌نظر از قفل (فقط root می‌تواند از این گزینه استفاده کند):

`qm reset {{100}} --skiplock {{true}}`
