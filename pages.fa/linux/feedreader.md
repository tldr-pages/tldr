# feedreader

> کارخواه RSS میزکار با رابط گرافیکی.
> توجه: FeedReader دیگر نگهداری نمی‌شود.
> اطلاعات بیشتر: <https://manned.org/feedreader>.

- چاپ تعداد مقاله‌های خوانده‌نشده:

`feedreader --unreadCount`

- افزودن URL یک خوراک برای دنبال کردن:

`feedreader --addFeed={{feed_url}}`

- دریافت یک مقالهٔ مشخص با استفاده از URL آن:

`feedreader --grabArticle={{article_url}}`

- دانلود همهٔ تصاویر یک مقالهٔ مشخص:

`feedreader --url={{feed_url}} --grabImages={{path/to/article}}`

- پخش رسانه از یک URL:

`feedreader --playMedia={{article_url}}`
