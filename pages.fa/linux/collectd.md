# collectd

> سرویس جمع‌آوری آمار سیستم.
> اطلاعات بیشتر: <https://manned.org/collectd>.

- آزمودن فایل پیکربندی و سپس خروج:

`collectd -t`

- آزمودن عملکرد جمع‌آوری دادهٔ افزونه و سپس خروج:

`collectd -T`

- شروع `collectd`:

`collectd`

- تعیین محل دلخواه فایل پیکربندی:

`collectd -C {{path/to/file}}`

- تعیین محل دلخواه فایل PID:

`collectd -P {{path/to/file}}`

- جدا نشدن در پس‌زمینه:

`collectd -f`

- نمایش راهنما و نسخه:

`collectd -h`
