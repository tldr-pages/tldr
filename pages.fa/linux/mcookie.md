# mcookie

> تولید اعداد تصادفی شانزده‌شانزدهی ۱۲۸ بیتی.
> اطلاعات بیشتر: <https://manned.org/mcookie>.

- تولید عدد تصادفی:

`mcookie`

- تولید عدد تصادفی با استفاده از محتویات فایل به‌عنوان بذر تصادفی‌سازی:

`mcookie {{[-f|--file]}} {{path/to/file}}`

- تولید عدد تصادفی با استفاده از تعداد بایت مشخصی از فایل به‌عنوان بذر تصادفی‌سازی:

`mcookie {{[-f|--file]}} {{path/to/file}} {{[-m|--max-size]}} {{number_of_bytes}}`

- چاپ جزئیات تصادفی‌سازی استفاده‌شده، مانند منشأ و بذر هر منبع:

`mcookie {{[-v|--verbose]}}`
