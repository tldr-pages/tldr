# toilet

> نمایش قلم‌های هنر ASCII.
> اطلاعات بیشتر: <http://caca.zoy.org/wiki/toilet>.

- تولید هنر ASCII برای متن مشخص:

`toilet {{input_text}}`

- تولید هنر ASCII با فایل قلم دلخواه:

`toilet {{input_text}} {{[-f|--font]}} {{font_filename}}`

- تولید هنر ASCII با فیلتر:

`toilet {{input_text}} {{[-F|--filter]}} {{filter_name}}`

- نمایش فیلترهای موجود toilet:

`toilet {{[-F|--filter]}} list`
