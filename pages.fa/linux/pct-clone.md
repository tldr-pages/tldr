# pct clone

> رونوشت‌گیری از کانتینر.
> اطلاعات بیشتر: <https://pve.proxmox.com/pve-docs/pct.1.html#cli_pct_clone>.

- رونوشت‌گیری از کانتینر:

`pct {{[cl|clone]}} {{100}} {{101}}`

- رونوشت‌گیری از کانتینر با نام دلخواه:

`pct {{[cl|clone]}} {{100}} {{101}} --hostname {{host_name}}`

- ایجاد رونوشت کامل به‌جای رونوشت پیوندی:

`pct {{[cl|clone]}} {{100}} {{101}} --full`
