# beep

> ابزاری برای پخش صدای بوق از بلندگوی رایانه.
> اطلاعات بیشتر: <https://manned.org/beep>.

- پخش یک بوق:

`beep`

- پخش یک بوق تکرارشونده:

`beep -r {{repetitions}}`

- پخش یک بوق با فرکانس مشخص (هرتز) و مدت مشخص (میلی‌ثانیه):

`beep -f {{frequency}} -l {{duration}}`

- پخش هر فرکانس و مدت جدید به‌صورت یک بوق مجزا:

`beep -f {{frequency}} -l {{duration}} {{[-n|--new]}} -f {{frequency}} -l {{duration}}`

- پخش گام دو ماژور:

`beep -f {{262}} {{[-n|--new]}} -f {{294}} {{[-n|--new]}} -f {{330}} {{[-n|--new]}} -f {{349}} {{[-n|--new]}} -f {{392}} {{[-n|--new]}} -f {{440}} {{[-n|--new]}} -f {{494}} {{[-n|--new]}} -f {{523}}`
