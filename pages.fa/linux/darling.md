# darling

> اجرای نرم‌افزارهای macOS در لینوکس.
> اطلاعات بیشتر: <https://docs.darlinghq.org/darling-shell.html>.

- اجرای یک دستور داخلی:

`darling shell {{uname}}`

- اجرای یک برنامهٔ مشخص با آرگومان‌ها:

`darling shell {{path/to/program}} {{program_argument_1 program_argument_2 ...}}`

- باز کردن پوستهٔ macOS:

`darling shell`

- خاموش کردن سرویس:

`darling shutdown`
