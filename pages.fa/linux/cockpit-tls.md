# cockpit-tls

> پراکسی HTTP خاتمه‌دهندهٔ TLS برای رمزگذاری ترافیک بین کارخواه و `cockpit-ws`.
> اطلاعات بیشتر: <https://cockpit-project.org/guide/latest/cockpit-tls.8.html>.

- پاسخ‌گویی به درخواست‌های HTTP روی یک درگاه مشخص به جای درگاه `9090`:

`cockpit-tls --port {{port}}`

- نمایش راهنما:

`cockpit-tls --help`
