# abrt-action-analyze-c

> محاسبهٔ UUID برای دایرکتوری داده‌های یک مشکل با استفاده از `coredump`.
> اطلاعات بیشتر: <https://manned.org/abrt-action-analyze-c>.

- محاسبه و ذخیرهٔ UUID برای دایرکتوری کاری فعلی:

`abrt-action-analyze-c`

- محاسبه و ذخیرهٔ UUID برای یک دایرکتوری مشخص:

`abrt-action-analyze-c -d {{path/to/directory}}`

- محاسبه و ذخیرهٔ UUID با خروجی مفصل:

`abrt-action-analyze-c -v`
