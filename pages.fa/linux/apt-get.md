# apt-get

> ابزار مدیریت بسته‌های دبیان و اوبونتو.
> جست‌وجوی بسته‌ها با استفاده از `apt-cache`.
> توصیه می‌شود برای استفادهٔ تعاملی در نسخه‌های 16.04 و جدیدتر اوبونتو از `apt` استفاده شود.
> اطلاعات بیشتر: <https://manned.org/apt-get.8>.

- به‌روزرسانی فهرست بسته‌ها و نسخه‌های موجود (توصیه می‌شود این دستور را پیش از دیگر دستورهای `apt-get` اجرا کنید):

`sudo apt-get update`

- نصب یک بسته یا به‌روزرسانی آن به آخرین نسخهٔ موجود:

`sudo apt-get install {{package}}`

- حذف یک بسته:

`sudo apt-get remove {{package}}`

- حذف یک بسته و فایل‌های پیکربندی آن:

`sudo apt-get purge {{package}}`

- ارتقای همهٔ بسته‌های نصب‌شده به آخرین نسخه‌های موجود:

`sudo apt-get upgrade`

- پاکسازی مخزن محلی: حذف فایل‌های بسته (`.deb`) از دانلودهای متوقف‌شده که دیگر قابل دانلود نیستند:

`sudo apt-get autoclean`

- حذف همهٔ بسته‌هایی که دیگر مورد نیاز نیستند:

`sudo apt-get autoremove`

- ارتقای بسته‌های نصب‌شده (مانند `upgrade`)، اما با حذف بسته‌های منسوخ و نصب بسته‌های اضافی برای برآورده کردن وابستگی‌های جدید:

`sudo apt-get dist-upgrade`
