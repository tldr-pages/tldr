# lid

> پرس‌وجوی پایگاه دادهٔ ID برای توکن‌های مطابق الگو.
> توجه: ابتدا باید پایگاه دادهٔ ID با `mkid` ساخته شود.
> اطلاعات بیشتر: <https://www.gnu.org/software/idutils/manual/idutils.html#lid-invocation>.

- فهرست کردن همهٔ توکن‌ها و محل فایل‌های آن‌ها در پایگاه دادهٔ ID:

`lid`

- یافتن فایل‌های حاوی توکن مشخص:

`lid {{token}}`

- یافتن توکن‌های مطابق الگو بدون توجه به بزرگی و کوچکی حروف:

`lid {{[-i|--ignore-case]}} {{token}}`

- یافتن توکن‌های مطابق `regex` توسعه‌یافته:

`lid {{[-r|--regexp]}} "{{pattern}}"`

- خروجی دادن خطوط مطابق در قالب مشابه grep:

`lid {{[-R|--result]}} grep {{token}}`

- یافتن توکن‌هایی که فقط یک بار ظاهر می‌شوند (مفید برای یافتن تعریف‌های استفاده‌نشده):

`lid {{[-F|--frequency]}} 1`
