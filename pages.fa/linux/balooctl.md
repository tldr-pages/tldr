# balooctl

> چارچوب نمایه‌سازی و جست‌وجوی فایل برای KDE Plasma.
> اطلاعات بیشتر: <https://wiki.archlinux.org/title/Baloo>.

- نمایش وضعیت نمایه‌ساز:

`balooctl status`

- فعال یا غیرفعال کردن نمایه‌ساز فایل:

`balooctl {{enable|disable}}`

- پاکسازی پایگاه دادهٔ نمایه:

`balooctl purge`

- تعلیق نمایه‌ساز فایل:

`balooctl suspend`

- از سر گرفتن نمایه‌سازی فایل:

`balooctl resume`

- نمایش فضای دیسک استفاده‌شده توسط Baloo:

`balooctl indexSize`

- بررسی فایل‌های نمایه‌نشده و نمایه‌سازی آن‌ها:

`balooctl check`

- نمایش راهنما:

`balooctl {{[-h|--help]}}`
