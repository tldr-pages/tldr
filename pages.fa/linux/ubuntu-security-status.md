# ubuntu-security-status

> نمایش اطلاعات پشتیبانی امنیتی بسته‌های نصب‌شدهٔ Ubuntu.
> اطلاعات بیشتر: <https://git.launchpad.net/ubuntu/+source/update-manager/tree/ubuntu-security-status>.

- نمایش تعداد بسته‌های پشتیبانی‌نشده:

`ubuntu-security-status`

- فهرست کردن بسته‌هایی که دیگر برای بارگیری موجود نیستند:

`ubuntu-security-status --unavailable`

- فهرست کردن بسته‌های شخص ثالث:

`ubuntu-security-status --thirdparty`
