# gksu

> رابط کاربری برای `su`.
> اجرای دستورهای گرافیکی نیازمند دسترسی ریشه بدون نیاز به اجرای شبیه‌ساز پایانهٔ X.
> توجه: این دستور منسوخ شده و دیگر نگهداری نمی‌شود؛ به جای آن از `pkexec` استفاده کنید.
> همچنین : `gksudo`.
> اطلاعات بیشتر: <https://manned.org/gksu>.

- اجرای یک دستور به‌عنوان کاربر مشخص:

`gksu {{[-u|--user]}} {{userid}} {{command}}`

- اجرای دستور با حفظ محیط فعلی:

`gksu {{[-u|--user]}} {{userid}} {{[-k|--preserve-env]}} {{command}}`

- وادار کردن `gksu` به استفاده از `su` برای اجرای دستور:

`gksu {{[-u|--user]}} {{userid}} {{[-w|--su-mode]}} {{command}}`

- وادار کردن `gksu` به استفاده از `sudo` برای اجرای دستور:

`gksu {{[-u|--user]}} {{userid}} {{[-S|--sudo-mode]}} {{command}}`

- چاپ اطلاعات اشکال‌زدایی برای دستور مشخص:

`gksu {{[-u|--user]}} {{userid}} {{[-d|--debug]}} {{command}}`
