# trace-cmd report

> نمایش رویدادهای ردیابی ضبط‌شده.
> همچنین ببینید: `trace-cmd list`, `trace-cmd record`.
> اطلاعات بیشتر: <https://manned.org/trace-cmd-report>.

- نمایش ردیابی ضبط‌شده:

`sudo trace-cmd report`

- نمایش ردیابی ضبط‌شده برای CPU مشخص:

`sudo trace-cmd report --cpu {{cpu_number}}`
