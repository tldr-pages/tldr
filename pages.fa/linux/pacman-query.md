# pacman --query

> پرس‌وجوی پایگاه دادهٔ محلی بسته‌ها.
> اطلاعات بیشتر: <https://manned.org/pacman.8>.

- پرس‌وجوی پایگاه دادهٔ محلی و فهرست کردن بسته‌ها و نسخه‌های نصب‌شده:

`pacman -Q`

- فهرست کردن فقط بسته‌های صریحاً نصب‌شده بدون شمارهٔ نسخه:

`pacman -Qeq`

- یافتن بستهٔ مالک فایل:

`pacman -Qo {{filename}}`

- نمایش اطلاعات بستهٔ نصب‌شده:

`pacman -Qi {{package}}`

- نمایش فهرست فایل‌های متعلق به بستهٔ مشخص:

`pacman -Ql {{package}}`

- فهرست کردن بسته‌های یتیم (نصب‌شده به‌عنوان وابستگی اما مورد نیاز هیچ بسته‌ای نیستند) در حالت کم‌صدا (فقط نام بسته نمایش داده می‌شود):

`pacman -Qdtq`

- فهرست کردن بسته‌های نصب‌شدهٔ خارج از پایگاه دادهٔ مخزن:

`pacman -Qm`

- فهرست کردن بسته‌های قابل ارتقا:

`pacman -Qu`
