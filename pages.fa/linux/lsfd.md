# lsfd

> فهرست کردن فایل‌های باز و فرایندهای مرتبط در لینوکس.
> اطلاعات بیشتر: <https://manned.org/lsfd>.

- فهرست کردن همهٔ توصیفگرهای فایل باز:

`lsfd`

- فهرست کردن همهٔ فایل‌هایی که توسط برنامهٔ مشخص باز نگه داشته شده‌اند:

`lsfd {{[-Q|--filter]}} 'PID == {{process_id}}'`

- بررسی اینکه کدام برنامه فایل مشخص را باز کرده است:

`lsfd {{[-Q|--filter]}} "NAME == '{{path/to/file}}'"`

- فهرست کردن سوکت‌های باز IPv4 یا IPv6:

`lsfd {{-i4|-i6}}`

- نمایش راهنما:

`lsfd {{[-h|--help]}}`
