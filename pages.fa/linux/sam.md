# sam

> رابط خط فرمان AWS Serverless Application Model (SAM).
> اطلاعات بیشتر: <https://docs.aws.amazon.com/serverless-application-model/latest/developerguide/using-sam-cli-corecommands.html>.

- مقداردهی اولیهٔ برنامهٔ بدون سرور:

`sam init`

- مقداردهی اولیهٔ برنامهٔ بدون سرور با محیط اجرای مشخص:

`sam init {{[-r|--runtime]}} {{python3.7}}`

- بسته‌بندی برنامهٔ SAM:

`sam package`

- ساخت کد تابع Lambda:

`sam build`

- اجرای محلی برنامهٔ بدون سرور:

`sam local start-api`

- استقرار برنامهٔ AWS SAM:

`sam deploy`
