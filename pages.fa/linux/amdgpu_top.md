# amdgpu_top

> ابزاری برای نمایش میزان استفاده از پردازندهٔ گرافیکی AMD و شاخص‌های سخت‌افزاری با استفاده از درایور AMDGPU.
> همچنین : `nvtop`, `radeontop`.
> اطلاعات بیشتر: <https://github.com/Umio-Yasuno/amdgpu_top#usage>.

- نمایش فهرست دستگاه‌های AMDGPU:

`amdgpu_top --list`

- چاپ همهٔ فرایندهای پردازندهٔ گرافیکی و میزان مصرف حافظهٔ هر فرایند:

`amdgpu_top {{[-p|--process]}}`

- انتخاب یک پردازندهٔ گرافیکی مشخص بر اساس گذرگاه PCI:

`amdgpu_top --pci "{{0000:01:00.0}}"`

- اجرای نمایشگر تعاملی با رابط متنی:

`amdgpu_top`

- اجرای نمایشگر با رابط گرافیکی:

`amdgpu_top --gui`

- اجرای یک نمای سادهٔ متنی شبیه SMI:

`amdgpu_top --smi`
