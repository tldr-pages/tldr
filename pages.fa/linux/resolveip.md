# resolveip

> تبدیل نام میزبان به آدرس IP و برعکس.
> اطلاعات بیشتر: <https://mariadb.com/docs/server/clients-and-utilities/networking-tools/resolveip>.

- تبدیل نام میزبان به آدرس IP:

`resolveip {{example.org}}`

- تبدیل آدرس IP به نام میزبان:

`resolveip {{1.1.1.1}}`

- تبدیل نام میزبان به آدرس IP با خروجی کمتر:

`resolveip {{[-s|--silent]}} {{example.org}}`
