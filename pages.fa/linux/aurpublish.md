# aurpublish

> انتشار بسته‌های مخزن کاربران آرچ.
> اطلاعات بیشتر: <https://github.com/eli-schwartz/aurpublish/blob/master/doc/aurpublish.1.asciidoc>.

- بررسی یکپارچگی `PKGBUILD`، تولید `.SRCINFO`، ایجاد قالب پیام کامیت و انتشار بسته در AUR:

`aurpublish {{package_name}}`

- افزودن هوک‌های Git به مخزن فعلی:

`aurpublish setup`

- نمایش راهنما:

`aurpublish {{[-h|--help]}}`
