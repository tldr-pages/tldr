# ikaros

> ابزار Vanilla OS برای مدیریت درایورهای دستگاه.
> اطلاعات بیشتر: <https://github.com/Vanilla-OS/Ikaros>.

- نصب تعاملی درایورهای دستگاه:

`ikaros install {{device}}`

- نصب خودکار درایورهای پیشنهادی دستگاه:

`ikaros auto-install {{device}}`

- فهرست کردن دستگاه‌ها:

`ikaros list-devices`
