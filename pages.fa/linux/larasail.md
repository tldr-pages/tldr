# larasail

> مدیریت Laravel روی سرورهای Digital Ocean.
> اطلاعات بیشتر: <https://github.com/thedevdojo/larasail#setup-your-server>.

- راه‌اندازی سرور با وابستگی‌های Laravel و نسخهٔ پیش‌فرض PHP:

`larasail setup`

- راه‌اندازی سرور با وابستگی‌های Laravel و نسخهٔ مشخص PHP:

`larasail setup {{php71}}`

- افزودن سایت جدید Laravel:

`larasail host {{domain}} {{path/to/site_directory}}`

- دریافت رمز عبور کاربر Larasail:

`larasail pass`

- دریافت رمز عبور MySQL مربوط به Larasail:

`larasail mysqlpass`
