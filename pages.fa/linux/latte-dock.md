# latte-dock

> داک جایگزین برای دسکتاپ Plasma.
> اطلاعات بیشتر: <https://github.com/KDE/latte-dock>.

- پاک کردن حافظهٔ نهان QML:

`latte-dock --clear-cache`

- وارد و بارگذاری کردن چیدمان پیش‌فرض هنگام شروع:

`latte-dock --default-layout`

- بارگذاری چیدمان مشخص هنگام شروع:

`latte-dock --layout {{layout_name}}`

- وارد و بارگذاری کردن چیدمان مشخص:

`latte-dock --import-layout {{path/to/file}}`
