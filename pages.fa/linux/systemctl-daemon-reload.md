# systemctl daemon-reload

> بارگذاری مجدد پیکربندی مدیر systemd.
> پس از ایجاد، تغییر یا حذف فایل‌های واحد از این دستور استفاده کنید.
> همچنین : `systemctl reload`.
> اطلاعات بیشتر: <https://www.freedesktop.org/software/systemd/man/latest/systemctl.html#daemon-reload>.

- بارگذاری مجدد systemd برای اعمال تغییرات فایل‌های واحد:

`systemctl daemon-reload`
