# gksudo

> رابط کاربری برای `sudo`.
> اجرای دستورهای گرافیکی نیازمند دسترسی ریشه بدون نیاز به اجرای شبیه‌ساز پایانهٔ X.
> توجه: این دستور منسوخ شده و دیگر نگهداری نمی‌شود؛ به جای آن از `pkexec` استفاده کنید.
> همچنین ببینید: `gksu`.
> اطلاعات بیشتر: <https://manned.org/gksudo>.

- اجرای یک دستور به‌عنوان کاربر مشخص:

`gksudo {{[-u|--user]}} {{userid}} {{command}}`

- اجرای دستور با حفظ محیط فعلی:

`gksudo {{[-u|--user]}} {{userid}} {{[-k|--preserve-env]}} {{command}}`

- وادار کردن `gksudo` به استفاده از `su` برای اجرای دستور:

`gksu {{[-u|--user]}} {{userid}} {{[-w|--su-mode]}} {{command}}`

- وادار کردن `gksudo` به استفاده از `sudo` برای اجرای دستور:

`gksudo {{[-u|--user]}} {{userid}} {{[-S|--sudo-mode]}} {{command}}`

- چاپ اطلاعات اشکال‌زدایی برای دستور مشخص:

`gksudo {{[-u|--user]}} {{userid}} {{[-d|--debug]}} {{command}}`
