# iftop

> نمایش مصرف پهنای باند یک واسط به تفکیک میزبان.
> اطلاعات بیشتر: <https://manned.org/iftop>.

- نمایش مصرف پهنای باند:

`sudo iftop`

- نمایش مصرف پهنای باند واسط مشخص:

`sudo iftop -i {{interface}}`

- نمایش مصرف پهنای باند همراه با اطلاعات پورت:

`sudo iftop -P`

- نمایش ندادن نمودارهای میله‌ای ترافیک:

`sudo iftop -b`

- جست‌وجو نکردن نام میزبان‌ها:

`sudo iftop -n`
