# switch_root

> استفاده از فایل‌سیستم متفاوت به‌عنوان ریشهٔ درخت اتصال.
> توجه: اگر ریشهٔ جدید ریشهٔ یک اتصال نباشد، `switch_root` کار نمی‌کند. برای رفع مشکل از bind mount استفاده کنید.
> همچنین : `chroot`, `mount`.
> اطلاعات بیشتر: <https://manned.org/switch_root>.

- انتقال `/proc`، `/dev`، `/sys` و `/run` به فایل‌سیستم مشخص، استفاده از آن به‌عنوان ریشهٔ جدید و شروع فرایند init مشخص:

`switch_root {{new_root}} {{/sbin/init}}`

- نمایش راهنما:

`switch_root {{[-h|--help]}}`
