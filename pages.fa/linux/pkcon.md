# pkcon

> کارخواه PackageKit که توسط Discover و نرم‌افزار Gnome استفاده می‌شود و جایگزینی برای `apt` است.
> اطلاعات بیشتر: <https://manned.org/pkcon>.

- نصب بسته:

`pkcon install {{package}}`

- حذف بسته:

`pkcon remove {{package}}`

- تازه‌سازی حافظهٔ نهان بسته‌ها:

`pkcon refresh`

- به‌روزرسانی بسته‌ها:

`pkcon update`

- جست‌وجوی بستهٔ مشخص:

`pkcon search {{package}}`

- فهرست کردن همهٔ بسته‌های موجود:

`pkcon get-packages`
