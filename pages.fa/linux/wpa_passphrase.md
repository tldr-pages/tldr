# wpa_passphrase

> تولید کلید WPA-PSK از عبارت عبور ASCII برای یک SSID.
> اطلاعات بیشتر: <https://manned.org/wpa_passphrase.1>.

- محاسبه و نمایش کلید WPA-PSK برای SSID مشخص با خواندن عبارت عبور از `stdin`:

`wpa_passphrase {{ssid}}`

- محاسبه و نمایش کلید WPA-PSK برای SSID مشخص با تعیین عبارت عبور به‌عنوان آرگومان:

`wpa_passphrase {{ssid}} {{passphrase}}`
