# htpdate

> همگام‌سازی تاریخ و زمان محلی از طریق سربرگ‌های HTTP وب‌سرورها.
> اطلاعات بیشتر: <https://www.vervest.org/htp/>.

- همگام‌سازی تاریخ و زمان:

`sudo htpdate {{host}}`

- شبیه‌سازی همگام‌سازی بدون انجام عمل:

`htpdate -q {{host}}`

- جبران رانش سیستماتیک ساعت:

`sudo htpdate -x {{host}}`

- تنظیم فوری زمان پس از همگام‌سازی:

`sudo htpdate -s {{host}}`
