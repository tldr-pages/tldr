# qm set

> تنظیم گزینه‌های ماشین مجازی.
> اطلاعات بیشتر: <https://pve.proxmox.com/pve-docs/qm.1.html#cli_qm_set>.

- تنظیم نام ماشین مجازی در رابط گرافیکی:

`qm {{[se|set]}} {{100}} --name {{vm_name}}`

- تنظیم شروع خودکار ماشین مجازی هنگام راه‌اندازی:

`qm {{[se|set]}} {{100}} --autostart {{0|1}}`

- تنظیم تعداد هسته‌های تخصیص‌یافته به ماشین مجازی:

`qm {{[se|set]}} {{100}} --cores {{4}}`

- تنظیم مقدار حافظهٔ تخصیص‌یافته:

`qm {{[se|set]}} {{100}} --memory {{8192}}`

- اختصاص دستگاه شبکه به ماشین مجازی و پل کردن آن به شبکهٔ میزبان:

`qm {{[se|set]}} {{100}} --net{{0}} {{virtio|e1000|rtl8139|vmxnet3}},bridge=vmbr{{0}}`

- حذف دستگاه:

`qm {{[se|set]}} {{100}} --delete {{device_name0,device_name1,...}}`

- عبور مستقیم دستگاه GPU به مهمان:

`qm {{[se|set]}} {{100}} --hostpci{{0}} {{0000:00:02}},x-vga=1 --bios ovmf`
