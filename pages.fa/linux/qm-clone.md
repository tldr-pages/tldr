# qm clone

> ایجاد نسخه‌ای از ماشین مجازی در مدیر ماشین مجازی QEMU/KVM.
> اطلاعات بیشتر: <https://pve.proxmox.com/pve-docs/qm.1.html#cli_qm_clone>.

- کپی ماشین مجازی:

`qm clone {{100}} {{101}}`

- کپی ماشین مجازی با نام مشخص:

`qm clone {{100}} {{101}} --name {{name}}`

- کپی ماشین مجازی با توضیح مشخص:

`qm clone {{100}} {{101}} --description {{description}}`

- کپی ماشین مجازی با ایجاد نسخهٔ کامل از همهٔ دیسک‌ها:

`qm clone {{100}} {{101}} --full`

- کپی ماشین مجازی با قالب مشخص ذخیره‌سازی فایل (نیازمند `--full`):

`qm clone {{100}} {{101}} --full --format {{qcow2|raw|vmdk}}`

- کپی ماشین مجازی و سپس افزودن آن به استخر مشخص:

`qm clone {{100}} {{101}} --pool {{pool_name}}`
