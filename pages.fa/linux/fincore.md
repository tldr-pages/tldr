# fincore

> نمایش میزان حافظهٔ نهان اشغال‌شده توسط یک فایل.
> همچنین : `fadvise`.
> اطلاعات بیشتر: <https://manned.org/fincore>.

- نمایش جزئیات حافظهٔ نهان برای یک فایل:

`fincore {{path/to/file}}`

- نمایش همهٔ ستون‌های دادهٔ ممکن:

`fincore --output-all {{path/to/file}}`

- نمایش راهنما:

`fincore {{[-h|--help]}}`
