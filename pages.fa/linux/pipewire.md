# pipewire

> شروع سرویس PipeWire.
> اطلاعات بیشتر: <https://docs.pipewire.org/page_man_pipewire_1.html>.

- شروع سرویس PipeWire:

`pipewire`

- استفاده از فایل پیکربندی دیگر:

`pipewire --config {{path/to/file.conf}}`

- تنظیم سطح جزئیات خروجی (error، warn، info، debug یا trace):

`pipewire -{{v|vv|...|vvvvv}}`

- نمایش راهنما:

`pipewire --help`
