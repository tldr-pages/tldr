# blight

> ابزاری برای تغییر روشنایی نمایشگر.
> اطلاعات بیشتر: <https://github.com/gutjuri/blight#usage>.

- تنظیم روشنایی نمایشگر روی ۵۰ درصد:

`blight set 50 {{[-r|--relative]}}`

- نمایش روشنایی فعلی نمایشگر:

`blight show`

- چاپ حداکثر روشنایی نمایشگر:

`blight max`

- افزایش روشنایی نمایشگر بر حسب درصد:

`blight inc {{number}} {{[-r|--relative]}}`

- کاهش روشنایی نمایشگر با واحدهای داخلی:

`blight dec {{number}}`
