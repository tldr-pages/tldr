# apt install

> نصب بسته‌ها برای توزیع‌های مبتنی بر دبیان.
> اطلاعات بیشتر: <https://manned.org/apt.8>.

- نصب یک بسته یا به‌روزرسانی آن به آخرین نسخه:

`sudo apt install {{package}}`

- نمایش اطلاعات مفصل نسخهٔ بسته هنگام نصب یا به‌روزرسانی:

`sudo apt install {{[-V|--verbose-versions]}} {{package}}`
