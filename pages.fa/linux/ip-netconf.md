# ip netconf

> نمایش پارامترهای پیکربندی.
> اطلاعات بیشتر: <https://manned.org/ip-netconf>.

- نمایش پیکربندی شبکه برای همهٔ واسط‌ها:

`ip {{[netc|netconf]}}`

- نمایش پیکربندی شبکه برای واسط مشخص:

`ip {{[netc|netconf]}} {{[s|show]}} dev {{network_interface}}`

- نمایش فقط پیکربندی شبکهٔ IPv4:

`ip -4 {{[netc|netconf]}}`

- نمایش فقط پیکربندی شبکهٔ IPv6:

`ip -6 {{[netc|netconf]}}`
