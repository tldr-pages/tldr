# lvmdiskscan

> پویش دستگاه‌هایی که می‌توانند به‌عنوان حجم فیزیکی توسط LVM استفاده شوند.
> توجه: این دستور منسوخ شده است؛ به‌جای آن از `pvs` استفاده کنید.
> اطلاعات بیشتر: <https://manned.org/lvmdiskscan>.

- پویش همهٔ دستگاه‌ها:

`lvmdiskscan`

- نمایش فقط حجم‌های فیزیکی (PV):

`lvmdiskscan {{[-l|--lvmpartition]}}`

- افزایش جزئیات خروجی (برای جزئیات بیشتر تکرار کنید):

`lvmdiskscan {{[-v|--verbose]}}`
