# cfdisk

> مدیریت جدول‌های پارتیشن و پارتیشن‌های دیسک سخت با رابط curses.
> همچنین ببینید: `parted`.
> اطلاعات بیشتر: <https://manned.org/cfdisk>.

- شروع ابزار مدیریت پارتیشن برای یک دستگاه مشخص:

`sudo cfdisk {{/dev/sdX}}`

- ایجاد و مدیریت جدول پارتیشن جدید برای یک دستگاه مشخص:

`sudo cfdisk {{[-z|--zero]}} {{/dev/sdX}}`
