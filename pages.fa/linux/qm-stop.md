# qm stop

> توقف ماشین مجازی.
> اطلاعات بیشتر: <https://pve.proxmox.com/pve-docs/qm.1.html#cli_qm_stop>.

- توقف فوری ماشین مجازی:

`qm stop {{100}}`

- توقف ماشین مجازی و انتظار حداکثر ۱۰ ثانیه:

`qm stop {{100}} --timeout 10`

- توقف ماشین مجازی با صرف‌نظر از قفل (فقط root می‌تواند از این گزینه استفاده کند):

`qm stop {{100}} --skiplock true`

- توقف ماشین مجازی بدون غیرفعال کردن حجم‌های ذخیره‌سازی:

`qm stop {{100}} --keepActive true`
