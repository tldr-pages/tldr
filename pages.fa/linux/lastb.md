# lastb

> فهرست کردن آخرین کاربران واردشده.
> اطلاعات بیشتر: <https://manned.org/lastb>.

- فهرست کردن آخرین کاربران واردشده:

`sudo lastb`

- فهرست کردن همهٔ آخرین کاربران واردشده از زمان مشخص:

`sudo lastb {{[-s|--since]}} {{YYYY-MM-DD}}`

- فهرست کردن همهٔ آخرین کاربران واردشده تا زمان مشخص:

`sudo lastb {{[-t|--until]}} {{YYYY-MM-DD}}`

- فهرست کردن همهٔ کاربران واردشده در زمان مشخص:

`sudo lastb {{[-p|--present]}} {{hh:mm}}`

- فهرست کردن همهٔ آخرین کاربران واردشده و تبدیل IP به نام میزبان:

`sudo lastb {{[-d|--dns]}}`
