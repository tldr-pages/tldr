# knockd

> سرویس port knocking برای گوش دادن به درخواست‌های کوبیدن پورت و اجرای اسکریپت‌ها.
> اطلاعات بیشتر: <https://manned.org/knockd>.

- شروع سرویس سیستمی knockd:

`knockd {{[-d|--daemon]}}`

- استفاده از فایل پیکربندی مشخص برای knockd:

`knockd {{[-c|--config]}} {{path/to/file}}.configuration`
