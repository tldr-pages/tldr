# caligula

> رابط پایانه‌ای سبک و کاربرپسند برای نوشتن تصاویر دیسک.
> همچنین : `dd`.
> اطلاعات بیشتر: <https://github.com/ifd3f/caligula>.

- نوشتن یک تصویر ISO روی یک درایو:

`caligula burn {{path/to/image.iso}}`

- نوشتن یک تصویر ISO روی یک درایو بدون وارد کردن تعاملی هش:

`caligula burn {{path/to/image.iso}} {{[-s|--hash]}} {{hash}}`
