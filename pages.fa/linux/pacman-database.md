# pacman --database

> عملیات روی پایگاه دادهٔ بسته‌های Arch Linux.
> تغییر برخی ویژگی‌های بسته‌های نصب‌شده.
> اطلاعات بیشتر: <https://manned.org/pacman.8>.

- علامت‌گذاری بسته به‌عنوان نصب‌شده به‌صورت ضمنی:

`sudo pacman -D --asdeps {{package}}`

- علامت‌گذاری بسته به‌عنوان نصب‌شده به‌صورت صریح:

`sudo pacman -D --asexplicit {{package}}`

- بررسی نصب بودن همهٔ وابستگی‌های بسته‌ها:

`pacman -Dk`

- بررسی پایگاه دادهٔ همگام‌سازی برای اطمینان از موجود بودن همهٔ وابستگی‌های مشخص بسته‌های قابل بارگیری:

`pacman -Dkk`

- بررسی و نمایش در حالت کم‌صدا (فقط پیام‌های خطا نمایش داده می‌شوند):

`pacman -Dkq`

- نمایش راهنما:

`pacman -Dh`
