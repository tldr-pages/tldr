# qm showcmd

> نمایش خط فرمان مورد استفاده برای شروع ماشین مجازی (اطلاعات اشکال‌زدایی).
> اطلاعات بیشتر: <https://pve.proxmox.com/pve-docs/qm.1.html#cli_qm_showcmd>.

- نمایش خط فرمان ماشین مجازی مشخص:

`qm {{[sho|showcmd]}} {{100}}`

- قرار دادن هر گزینه در خط جدید برای خوانایی بیشتر:

`qm {{[sho|showcmd]}} {{100}} --pretty {{true}}`

- دریافت مقادیر پیکربندی از snapshot مشخص:

`qm {{[sho|showcmd]}} {{100}} --snapshot {{string}}`
