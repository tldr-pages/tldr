# gnome-software

> افزودن و حذف برنامه‌ها و به‌روزرسانی سیستم.
> اطلاعات بیشتر: <https://manned.org/gnome-software>.

- اجرای رابط گرافیکی GNOME Software اگر از قبل در حال اجرا نباشد:

`gnome-software`

- اجرای رابط گرافیکی GNOME Software در صورت باز نبودن و رفتن به صفحهٔ مشخص:

`gnome-software --mode {{updates|updated|installed|overview}}`

- اجرای رابط گرافیکی GNOME Software در صورت باز نبودن و مشاهدهٔ جزئیات بستهٔ مشخص:

`gnome-software --details {{package}}`

- نمایش نسخه:

`gnome-software --version`
