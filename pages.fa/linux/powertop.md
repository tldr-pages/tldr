# powertop

> بهینه‌سازی مصرف توان باتری.
> اطلاعات بیشتر: <https://github.com/fenrus75/powertop>.

- کالیبره کردن اندازه‌گیری‌های مصرف توان:

`sudo powertop --calibrate`

- تولید گزارش HTML مصرف توان در دایرکتوری فعلی:

`sudo powertop --html={{power_report.html}}`

- تنظیم برای حالت بهینه:

`sudo powertop --auto-tune`

- تولید گزارش برای تعداد ثانیهٔ مشخص (به‌جای پیش‌فرض ۲۰):

`sudo powertop --time={{5}}`
