# ego

> ابزار رسمی Funtoo برای مدیریت شخصیت سیستم.
> اطلاعات بیشتر: <https://funtoo-ego.readthedocs.io/en/develop/>.

- همگام‌سازی درخت Portage:

`ego sync`

- به‌روزرسانی پیکربندی بارگذار راه‌انداز:

`ego boot update`

- خواندن صفحهٔ ویکی Funtoo بر اساس نام:

`ego doc {{wiki_page}}`

- چاپ پروفایل فعلی:

`ego profile show`

- فعال یا غیرفعال کردن mix-inها:

`ego profile mix-in +{{gnome}} -{{kde-plasma-5}}`

- پرس‌وجوی خطاهای Funtoo مرتبط با یک بستهٔ مشخص:

`ego query bug {{package}}`
