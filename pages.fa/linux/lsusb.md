# lsusb

> نمایش اطلاعات گذرگاه‌های USB و دستگاه‌های متصل به آن‌ها.
> اطلاعات بیشتر: <https://manned.org/lsusb>.

- فهرست کردن همهٔ دستگاه‌های USB موجود:

`lsusb`

- نمایش سلسله‌مراتب USB به‌شکل درختی:

`lsusb {{[-t|--tree]}}`

- فهرست کردن اطلاعات مفصل دستگاه‌های USB:

`sudo lsusb {{[-v|--verbose]}}`

- فهرست کردن اطلاعات دقیق یک دستگاه USB:

`sudo lsusb {{[-v|--verbose]}} -s {{bus}}:{{device_number}}`

- فهرست کردن فقط دستگاه‌های دارای شناسهٔ سازنده و محصول مشخص:

`lsusb -d {{vendor}}:{{product}}`
