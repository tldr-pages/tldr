# conntrack

> تعامل با سامانهٔ ردیابی اتصال Netfilter.
> جست‌وجو، فهرست، بررسی، تغییر و حذف جریان‌های اتصال.
> اطلاعات بیشتر: <https://manned.org/conntrack>.

- فهرست کردن همهٔ اتصال‌های در حال ردیابی:

`conntrack {{[-L|--dump]}}`

- نمایش گزارش رویداد بلادرنگ تغییرات اتصال:

`conntrack {{[-E|--event]}}`

- نمایش گزارش رویداد بلادرنگ تغییرات اتصال همراه با زمان‌های مربوط:

`conntrack {{[-E|--event]}} {{[-o|--output]}} timestamp`

- نمایش گزارش رویداد بلادرنگ تغییرات اتصال برای یک آدرس IP مشخص:

`conntrack {{[-E|--event]}} {{[-s|--orig-src]}} {{ip_address}}`

- حذف همهٔ جریان‌ها برای یک آدرس IP مبدأ مشخص:

`conntrack {{[-D|--delete]}} {{[-s|--orig-src]}} {{ip_address}}`
