# xdg-desktop-menu

> نصب یا حذف موارد منوی دسکتاپ.
> اطلاعات بیشتر: <https://manned.org/xdg-desktop-menu>.

- نصب برنامه در سیستم منوی دسکتاپ:

`xdg-desktop-menu install {{path/to/file.desktop}}`

- نصب برنامه در سیستم منوی دسکتاپ با غیرفعال کردن بررسی پیشوند فروشنده:

`xdg-desktop-menu install --novendor {{path/to/file.desktop}}`

- حذف برنامه از سیستم منوی دسکتاپ:

`xdg-desktop-menu uninstall {{path/to/file.desktop}}`

- به‌روزرسانی اجباری سیستم منوی دسکتاپ:

`xdg-desktop-menu forceupdate --mode {{user|system}}`
