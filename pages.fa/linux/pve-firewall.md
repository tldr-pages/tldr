# pve-firewall

> مدیریت دیوار آتش Proxmox VE.
> اطلاعات بیشتر: <https://pve.proxmox.com/wiki/Firewall>.

- کامپایل و چاپ همهٔ قوانین دیوار آتش:

`pve-firewall {{[c|compile]}}`

- نمایش اطلاعات شبکهٔ محلی:

`pve-firewall {{[l|localnet]}}`

- راه‌اندازی مجدد سرویس دیوار آتش Proxmox VE:

`pve-firewall {{[r|restart]}}`

- شروع سرویس دیوار آتش Proxmox VE:

`pve-firewall start`

- توقف سرویس دیوار آتش Proxmox VE:

`pve-firewall stop`

- شبیه‌سازی همهٔ قوانین دیوار آتش:

`pve-firewall {{[si|simulate]}}`

- نمایش وضعیت دیوار آتش Proxmox VE:

`pve-firewall status`
