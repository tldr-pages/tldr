# extrepo

> مدیریت مخازن خارجی دبیان.
> برای مدیریت مخازن خارجی در دبیان استفاده می‌شود.
> اطلاعات بیشتر: <https://manned.org/extrepo.1p>.

- جست‌وجوی یک بستهٔ مشخص:

`extrepo search {{package}}`

- فعال کردن مخزن:

`sudo extrepo enable {{repository_name}}`

- غیرفعال کردن مخزن:

`sudo extrepo disable {{repository_name}}`

- به‌روزرسانی مخزن:

`sudo extrepo update {{repository_name}}`
