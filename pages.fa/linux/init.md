# init

> مدیر سطوح اجرای لینوکس.
> در صورت استفاده از systemd، گزینهٔ زمان کامپایل SYSVINIT باید فعال باشد.
> اطلاعات بیشتر: <https://manned.org/init.8>.

- تنظیم سیستم برای اجرای محیط گرافیکی:

`sudo init 5`

- تنظیم سیستم برای اجرای ترمینال چندکاربره:

`sudo init 3`

- خاموش کردن سیستم:

`init 0`

- راه‌اندازی مجدد سیستم:

`init 6`

- تنظیم سیستم برای اجرا در ترمینال فقط با کاربر root و بدون شبکه:

`sudo init 1`
