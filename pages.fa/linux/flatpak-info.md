# flatpak info

> نمایش اطلاعات برنامه یا محیط اجرای نصب‌شدهٔ Flatpak.
> اطلاعات بیشتر: <https://docs.flatpak.org/en/latest/flatpak-command-reference.html#flatpak-info>.

- نمایش اطلاعات برنامه یا محیط اجرای نصب‌شده:

`flatpak info {{com.example.app}}`

- نمایش اطلاعات یک شاخهٔ مشخص:

`flatpak info {{com.example.app}} {{branch}}`

- نمایش مجوزها:

`flatpak info {{[-M|--show-permissions]}} {{com.example.app}}`

- نمایش محل روی دیسک:

`flatpak info {{[-l|--show-location]}} {{com.example.app}}`

- نمایش اندازهٔ نصب‌شده:

`flatpak info {{[-s|--show-size]}} {{com.example.app}}`
