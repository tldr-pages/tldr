# ipcs

> نمایش اطلاعات استفاده از امکانات IPC در System V: بخش‌های حافظهٔ اشتراکی، صف‌های پیام و آرایه‌های سمافور.
> همچنین ببینید: `lsipc`, `ipcmk`, `ipcrm`.
> اطلاعات بیشتر: <https://manned.org/ipcs>.

- نمایش اطلاعات همهٔ امکانات IPC فعال:

`ipcs`

- نمایش اطلاعات بخش‌های حافظهٔ اشتراکی، صف‌های پیام یا مجموعه‌های سمافور فعال:

`ipcs {{--shmems|--queues|--semaphores}}`

- نمایش جزئیات کامل منبع با شناسهٔ مشخص:

`ipcs {{--shmems|--queues|--semaphores}} {{[-i|--id]}} {{resource_id}}`

- نمایش محدودیت‌ها بر حسب بایت یا در قالب خوانا برای انسان:

`ipcs {{[-l|--limits]}} {{--bytes|--human}}`

- نمایش خلاصهٔ استفادهٔ فعلی:

`ipcs {{[-u|--summary]}}`

- نمایش UID و PID سازنده و مالک برای همهٔ امکانات IPC:

`ipcs {{[-c|--creator]}}`

- نمایش PID آخرین عمل‌کنندگان برای همهٔ امکانات IPC:

`ipcs {{[-p|--pid]}}`

- نمایش زمان آخرین دسترسی برای همهٔ امکانات IPC:

`ipcs {{[-t|--time]}}`
