# spa-json-dump

> تبدیل فایل SPA JSON به JSON استاندارد.
> اطلاعات بیشتر: <https://docs.pipewire.org/page_man_spa-json-dump_1.html>.

- تبدیل فایل SPA JSON به JSON استاندارد:

`spa-json-dump {{path/to/file.conf}}`

- تبدیل SPA JSON از `stdin` به JSON استاندارد:

`echo "{{spa_json_string}}" | spa-json-dump`
