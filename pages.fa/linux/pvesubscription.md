# pvesubscription

> مدیریت کلیدهای اشتراک Proxmox.
> اطلاعات بیشتر: <https://pve.proxmox.com/pve-docs/pvesubscription.1.html>.

- نمایش اطلاعات اشتراک:

`pvesubscription {{[g|get]}}`

- تنظیم کلید اشتراک:

`pvesubscription set {{subscription_key}}`

- به‌روزرسانی اطلاعات اشتراک:

`pvesubscription {{[u|update]}}`

- حذف کلید اشتراک از گره فعلی:

`pvesubscription {{[d|delete]}}`
