# wine reg import

> وارد کردن کلیدها، مقادیر و داده‌ها به رجیستری Wine از فایل `.reg`.
> اطلاعات بیشتر: <https://learn.microsoft.com/windows-server/administration/windows-commands/reg-import>.

- وارد کردن مدخل‌های رجیستری از فایل:

`wine reg import {{path/to/file.reg}}`

- نمایش راهنما:

`wine reg import /?`
