# winecfg

> پیکربندی پیشوند Wine (درایوها، کتابخانه‌ها، گرافیک و نسخهٔ شبیه‌سازی‌شدهٔ Windows).
> اطلاعات بیشتر: <https://manned.org/winecfg>.

- باز کردن ابزار گرافیکی پیکربندی Wine:

`winecfg`

- نمایش نسخهٔ Windows که پیشوند اکنون شبیه‌سازی می‌کند:

`winecfg /v`

- تنظیم نسخهٔ Windows که پیشوند شبیه‌سازی می‌کند:

`winecfg /v {{win11|win10|win7|winxp|...}}`

- نمایش راهنما:

`winecfg /?`
