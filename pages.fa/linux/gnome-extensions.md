# gnome-extensions

> مدیریت افزونه‌های GNOME از پایانه.
> اطلاعات بیشتر: <https://wiki.gnome.org/Projects/GnomeShell/Extensions>.

- فهرست کردن همهٔ افزونه‌های نصب‌شده:

`gnome-extensions list`

- نمایش اطلاعات افزونهٔ مشخص:

`gnome-extensions info "{{extension_id}}"`

- فعال کردن افزونهٔ مشخص:

`gnome-extensions enable "{{extension_id}}"`

- غیرفعال کردن افزونهٔ مشخص:

`gnome-extensions disable "{{extension_id}}"`

- حذف افزونهٔ مشخص:

`gnome-extensions uninstall "{{extension_id}}"`

- نمایش راهنمای یک زیردستور مشخص (مانند `list`):

`gnome-extensions help {{subcommand}}`

- نمایش نسخه:

`gnome-extensions version`
