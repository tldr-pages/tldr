# dpkg-query

> نمایش اطلاعات بسته‌های نصب‌شده.
> اطلاعات بیشتر: <https://manned.org/dpkg-query>.

- فهرست کردن همهٔ بسته‌های نصب‌شده:

`dpkg-query {{[-l|--list]}}`

- فهرست کردن بسته‌های نصب‌شدهٔ مطابق با الگو:

`dpkg-query {{[-l|--list]}} '{{libc6*}}'`

- فهرست کردن همهٔ فایل‌های نصب‌شده توسط یک بسته:

`dpkg-query {{[-L|--listfiles]}} {{libc6}}`

- نمایش اطلاعات یک بسته:

`dpkg-query {{[-s|--status]}} {{libc6}}`

- جست‌وجوی بسته‌هایی که مالک فایل‌های مطابق با الگو هستند:

`dpkg-query {{[-S|--search]}} {{/etc/ld.so.conf.d}}`
