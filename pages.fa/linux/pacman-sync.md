# pacman --sync

> همگام‌سازی بسته‌ها از مخازن راه دور.
> اطلاعات بیشتر: <https://manned.org/pacman.8>.

- نصب بستهٔ جدید:

`sudo pacman -S {{package}}`

- همگام‌سازی و تازه‌سازی پایگاه دادهٔ بسته‌ها همراه با ارتقای سیستم (برای فقط بارگیری بسته‌ها و عدم به‌روزرسانی، `--downloadonly` را اضافه کنید):

`sudo pacman -Syu`

- به‌روزرسانی و ارتقای همهٔ بسته‌ها و نصب بستهٔ جدید بدون پرسش تأیید:

`sudo pacman -Syu --noconfirm {{package}}`

- جست‌وجوی `regex` یا کلیدواژه در پایگاه دادهٔ بسته‌ها:

`pacman -Ss "{{search_pattern}}"`

- نمایش اطلاعات بسته:

`pacman -Si {{package}}`

- بازنویسی فایل‌های متعارض هنگام به‌روزرسانی بسته:

`sudo pacman -Syu --overwrite {{path/to/file}}`

- حذف بسته‌های نصب‌نشده و مخازن استفاده‌نشده از حافظهٔ نهان (برای پاک کردن همهٔ بسته‌ها از گزینه‌های `Scc` استفاده کنید):

`sudo pacman -Sc`

- تعیین نسخهٔ بسته‌ای که باید نصب شود:

`sudo pacman -S {{package}}={{version}}`
