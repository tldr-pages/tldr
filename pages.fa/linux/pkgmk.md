# pkgmk

> ساخت بستهٔ دودویی برای استفاده با pkgadd در CRUX.
> اطلاعات بیشتر: <https://docs.oracle.com/cd/E88353_01/html/E37839/pkgmk-1.html>.

- ساخت و بارگیری بسته:

`pkgmk -d`

- نصب بسته پس از ساخت:

`pkgmk -d -i`

- ارتقای بسته پس از ساخت:

`pkgmk -d -u`

- نادیده گرفتن اثر فایل هنگام ساخت بسته:

`pkgmk -d -if`

- نادیده گرفتن جمع MD5 هنگام ساخت بسته:

`pkgmk -d -im`

- به‌روزرسانی اثر فایل بسته:

`pkgmk -uf`
