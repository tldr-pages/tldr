# archlinux-java

> جابه‌جایی بین محیط‌های نصب‌شدهٔ جاوا.
> اطلاعات بیشتر: <https://wiki.archlinux.org/title/Java#Switching_between_JVM>.

- فهرست کردن محیط‌های نصب‌شدهٔ جاوا:

`archlinux-java status`

- دریافت نام کوتاه محیط پیش‌فرض فعلی جاوا:

`archlinux-java get`

- تنظیم محیط پیش‌فرض جاوا:

`archlinux-java set {{java_environment}}`

- حذف تنظیم محیط پیش‌فرض جاوا:

`archlinux-java unset`

- اصلاح پیکربندی نامعتبر یا خراب محیط پیش‌فرض جاوا:

`archlinux-java fix`
