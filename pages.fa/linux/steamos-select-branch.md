# steamos-select-branch

> انتخاب شاخهٔ انتشار سیستم SteamOS.
> توجه: این دستور منسوخ است؛ به‌جای آن از `atomupd-manager` استفاده کنید.
> اطلاعات بیشتر: <https://gitlab.com/users/evlaV/projects>.

- مشاهدهٔ شاخهٔ فعلی:

`steamos-select-branch -c`

- فهرست کردن همهٔ شاخه‌های موجود:

`steamos-select-branch -l`

- تغییر به شاخهٔ بتا:

`steamos-select-branch beta`

- بازگشت به انتشار پایدار:

`steamos-select-branch stable`

- تغییر به شاخهٔ بسیار جدید:

`steamos-select-branch main`
