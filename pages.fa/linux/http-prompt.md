# http-prompt

> کارخواه تعاملی HTTP با قابلیت تکمیل خودکار و برجسته‌سازی نحو.
> اطلاعات بیشتر: <https://github.com/httpie/http-prompt>.

- شروع نشست با URL پیش‌فرض <http://localhost:8000> یا نشست قبلی:

`http-prompt`

- شروع نشست با URL مشخص:

`http-prompt {{http://example.com}}`

- شروع نشست با تعدادی گزینهٔ اولیه:

`http-prompt {{localhost:8000/api}} --auth {{username:password}}`
