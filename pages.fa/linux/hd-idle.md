# hd-idle

> متوقف کردن چرخش دیسک‌های خارجی پس از مدتی بی‌فعالیتی.
> اطلاعات بیشتر: <https://manned.org/hd-idle>.

- شروع سرویسی برای مدیریت توقف چرخش دیسک سخت؛ به‌صورت پیش‌فرض دیسک‌ها پس از ۱۰ دقیقه بی‌فعالیتی متوقف می‌شوند:

`systemctl start hd-idle`

- توقف فوری چرخش دیسک:

`hd-idle -t {{/dev/sdX}}`

- تنظیم دیسک‌ها برای متوقف نشدن چرخش و سپس تعیین زمان بی‌فعالیتی بر حسب ثانیه برای دیسک‌هایی که نام دستگاه آن‌ها حاوی «sda» یا «sdb» است:

`hd-idle -i 0 -a /dev/sda -i {{300}} -a /dev/sdb -i {{1200}}`
