# ip

> نمایش یا تغییر مسیریابی، دستگاه‌ها، مسیریابی مبتنی بر سیاست و تونل‌ها.
> برخی زیردستورها مانند `address` مستندات کاربرد جداگانه دارند.
> اطلاعات بیشتر: <https://manned.org/ip.8>.

- فهرست کردن واسط‌ها با اطلاعات مفصل:

`ip {{[a|address]}}`

- فهرست کردن واسط‌ها با اطلاعات مختصر لایهٔ شبکه:

`ip {{[-br|-brief]}} {{[a|address]}}`

- فهرست کردن واسط‌ها با اطلاعات مختصر لایهٔ پیوند:

`ip {{[-br|-brief]}} {{[l|link]}}`

- نمایش جدول مسیریابی:

`ip {{[r|route]}}`

- نمایش همسایه‌ها (جدول ARP):

`ip {{[n|neighbor]}}`

- فعال یا غیرفعال کردن واسط:

`sudo ip {{[l|link]}} {{[s|set]}} {{ethX}} {{up|down}}`

- افزودن یا حذف آدرس IP واسط:

`sudo ip {{[a|address]}} {{add|delete}} {{ip_address}}/{{mask}} dev {{ethX}}`

- افزودن مسیر پیش‌فرض:

`sudo ip {{[r|route]}} {{[a|add]}} default via {{ip_address}} dev {{ethX}}`
