# lsblk

> فهرست کردن اطلاعات دستگاه‌ها.
> اطلاعات بیشتر: <https://manned.org/lsblk>.

- فهرست کردن همهٔ دستگاه‌های ذخیره‌سازی در قالب درختی:

`lsblk`

- فهرست کردن دستگاه‌های خالی نیز:

`lsblk {{[-a|--all]}}`

- چاپ ستون SIZE بر حسب بایت به‌جای قالب خوانا برای انسان:

`lsblk {{[-b|--bytes]}}`

- خروجی اطلاعات فایل‌سیستم‌ها:

`lsblk {{[-f|--fs]}}`

- استفاده از نویسه‌های ASCII برای قالب‌بندی درخت:

`lsblk {{[-i|--ascii]}}`

- خروجی اطلاعات توپولوژی دستگاه بلوکی:

`lsblk {{[-t|--topology]}}`

- مستثنا کردن دستگاه‌های مشخص‌شده با فهرست شماره‌های اصلی دستگاه جداشده با ویرگول:

`lsblk {{[-e|--exclude]}} {{1,7,...}}`

- افزودن اطلاعات اضافی به خروجی با فهرست ستون‌های جداشده با ویرگول (برای نمایش فقط ستون‌های مشخص‌شده علامت `+` را حذف کنید):

`lsblk {{[-o|--output]}} +{{NAME,ROTA,SERIAL,MODEL,TRAN,TYPE,SIZE,FSTYPE,MOUNTPOINT,...}}`
