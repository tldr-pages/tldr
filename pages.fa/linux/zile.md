# zile

> نسخه‌ای سبک از ویرایشگر متن Emacs.
> اطلاعات بیشتر: <https://manned.org/zile>.

- شروع بافری برای یادداشت‌های موقت که ذخیره نمی‌شود:

`zile`

- باز کردن فایل:

`zile {{path/to/file}}`

- ذخیرهٔ فایل:

`<Ctrl x><Ctrl s>`

- خروج:

`<Ctrl x><Ctrl c>`

- باز کردن فایل در شمارهٔ خط مشخص:

`zile +{{line_number}} {{path/to/file}}`

- واگرد تغییرات:

`<Ctrl x><u>`
