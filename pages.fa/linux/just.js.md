# just

> محیط اجرای JavaScript مبتنی بر V8 برای لینوکس.
> اطلاعات بیشتر: <https://github.com/just-js/just>.

- شروع REPL (پوستهٔ تعاملی):

`just`

- اجرای فایل JavaScript:

`just {{path/to/file.js}}`

- ارزیابی کد JavaScript با ارسال آن به‌عنوان آرگومان:

`just eval "{{code}}"`

- مقداردهی اولیهٔ پروژهٔ جدید در دایرکتوری هم‌نام:

`just init {{project_name}}`

- ساخت برنامهٔ JavaScript به‌صورت فایل اجرایی:

`just build {{path/to/file.js}} --static`
