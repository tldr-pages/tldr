# ubuntu-drivers

> نصب درایورها در Ubuntu.
> اطلاعات بیشتر: <https://ubuntu.com/server/docs/how-to/graphics/install-nvidia-drivers/>.

- فهرست کردن درایورهای موجود برای سخت‌افزار فعلی:

`sudo ubuntu-drivers list`

- نصب درایورها برای سخت‌افزار شناسایی‌شده:

`sudo ubuntu-drivers install`

- نمایش راهنما:

`ubuntu-drivers`
