# ldd

> نمایش وابستگی‌های کتابخانهٔ مشترک یک فایل دودویی.
> برای فایل دودویی نامطمئن از این دستور استفاده نکنید؛ به‌جای آن از objdump استفاده کنید.
> اطلاعات بیشتر: <https://manned.org/ldd>.

- نمایش وابستگی‌های کتابخانهٔ مشترک فایل دودویی:

`ldd {{path/to/binary}}`

- نمایش همهٔ اطلاعات وابستگی‌ها:

`ldd {{[-v|--verbose]}} {{path/to/binary}}`

- نمایش وابستگی‌های مستقیم استفاده‌نشده:

`ldd {{[-u|--unused]}} {{path/to/binary}}`

- گزارش اشیای دادهٔ گمشده و انجام جابه‌جایی داده‌ها:

`ldd {{[-d|--data-relocs]}} {{path/to/binary}}`

- گزارش اشیای داده و توابع گمشده و انجام جابه‌جایی برای هر دو:

`ldd {{[-r|--function-relocs]}} {{path/to/binary}}`
