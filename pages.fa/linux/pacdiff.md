# pacdiff

> ابزار نگهداری فایل‌های `.pacorig`، `.pacnew` و `.pacsave` ایجادشده توسط `pacman`.
> اطلاعات بیشتر: <https://manned.org/pacdiff>.

- بررسی فایل‌های نیازمند نگهداری در حالت تعاملی:

`pacdiff`

- استفاده از `sudo` و `sudoedit` برای حذف و ادغام فایل‌ها:

`pacdiff {{[-s|--sudo]}}`

- بررسی فایل‌های نیازمند نگهداری و ایجاد نسخهٔ پشتیبان `.bak` از فایل اصلی در صورت انتخاب `(O)verwrite`:

`pacdiff {{[-s|--sudo]}} {{[-b|--backup]}}`

- استفاده از ویرایشگر مشخص برای مشاهده و ادغام فایل‌های پیکربندی (پیش‌فرض `vim -d` است):

`DIFFPROG={{editor}} pacdiff`

- پویش فایل‌های پیکربندی با `locate` به‌جای استفاده از پایگاه دادهٔ `pacman`:

`pacdiff {{[-l|--locate]}}`

- نمایش راهنما:

`pacdiff {{[-h|--help]}}`
