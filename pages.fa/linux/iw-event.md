# iw event

> گوش دادن به رویدادهای بی‌سیم.
> اطلاعات بیشتر: <https://wireless.docs.kernel.org/en/latest/en/users/documentation/iw.html>.

- گوش دادن به رویدادهای بی‌سیم:

`iw event`

- چاپ برچسب زمانی هسته:

`iw event -t`

- چاپ برچسب زمانی خوانا برای انسان:

`iw event -T`

- چاپ برچسب زمانی نسبت به آخرین رویداد:

`iw event -r`

- چاپ داده‌های کامل قاب:

`iw event -f`
