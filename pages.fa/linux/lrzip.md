# lrzip

> برنامهٔ فشرده‌سازی فایل‌های بزرگ.
> همچنین : `lrunzip`, `lrztar`, `lrzuntar`.
> اطلاعات بیشتر: <https://manned.org/lrzip>.

- فشرده‌سازی فایل با LZMA: فشرده‌سازی کند و استخراج سریع:

`lrzip {{path/to/file}}`

- فشرده‌سازی فایل با BZIP2: تعادل مناسب بین فشرده‌سازی و سرعت:

`lrzip {{[-b|--bzip2]}} {{path/to/file}}`

- فشرده‌سازی با ZPAQ: فشرده‌سازی بسیار زیاد اما بسیار کند:

`lrzip {{[-z|--zpaq]}} {{path/to/file}}`

- فشرده‌سازی با LZO: فشرده‌سازی سبک و استخراج بسیار سریع:

`lrzip {{[-l|--lzo]}} {{path/to/file}}`

- فشرده‌سازی فایل و محافظت با رمز عبور یا رمزگذاری آن:

`lrzip {{[-e|--encrypt]}} {{path/to/file}}`

- تعیین تعداد رشته‌های پردازنده برای استفاده:

`lrzip {{[-p|--threads]}} {{8}} {{path/to/file}}`
