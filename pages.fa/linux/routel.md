# routel

> فهرست کردن مسیریابی IP در قالب خوانا برای انسان.
> همچنین ببینید: `ip route`, `route`.
> اطلاعات بیشتر: <https://manned.org/routel>.

- نمایش جدول مسیریابی پیش‌فرض:

`routel`

- نمایش جدول مسیریابی مشخص:

`routel {{table_number|main|local|default}}`

- نمایش فقط مسیرهای IPv4:

`routel {{[-4|--family inet]}}`

- نمایش فقط مسیرهای IPv6:

`routel {{[-6|--family inet6]}}`
