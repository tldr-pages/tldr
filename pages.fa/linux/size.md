# size

> نمایش اندازهٔ بخش‌های داخل فایل‌های دودویی.
> اطلاعات بیشتر: <https://sourceware.org/binutils/docs/binutils/size.html>.

- نمایش اندازهٔ بخش‌ها در فایل شیء یا اجرایی مشخص:

`size {{path/to/file}}`

- نمایش اندازهٔ بخش‌ها در فایل شیء یا اجرایی مشخص به هشت‌هشتی:

`size {{[-o|--radix=8]}} {{path/to/file}}`

- نمایش اندازهٔ بخش‌ها در فایل شیء یا اجرایی مشخص به ده‌دهی:

`size {{[-d|--radix=10]}} {{path/to/file}}`

- نمایش اندازهٔ بخش‌ها در فایل شیء یا اجرایی مشخص به شانزده‌شانزدهی:

`size {{[-x|--radix=16]}} {{path/to/file}}`
