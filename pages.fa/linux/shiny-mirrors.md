# shiny-mirrors

> تولید فهرست آینهٔ `pacman` برای Manjaro Linux.
> هر بار اجرای shiny-mirrors نیازمند همگام‌سازی پایگاه داده و به‌روزرسانی سیستم با `sudo pacman -Syyu` است.
> اطلاعات بیشتر: <https://gitlab.com/Arisa_Snowbell/shiny-mirrors/-/blob/domina/shiny-mirrors/man/shiny-mirrors.md>.

- دریافت وضعیت آینه‌های فعلی:

`shiny-mirrors status`

- تولید فهرست آینه با رفتار پیش‌فرض:

`sudo shiny-mirrors refresh`

- نمایش فایل پیکربندی فعلی:

`shiny-mirrors config show`

- تغییر تعاملی به شاخهٔ دیگر:

`sudo shiny-mirrors config --branch`
