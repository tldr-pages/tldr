# xdg-user-dir

> دریافت محل دایرکتوری‌های کاربر XDG.
> همچنین ببینید: `xdg-user-dirs-update`.
> اطلاعات بیشتر: <https://manned.org/xdg-user-dir>.

- نمایش دایرکتوری خانگی کاربر فعلی:

`xdg-user-dir`

- نمایش محل دایرکتوری کاربر:

`xdg-user-dir {{DESKTOP|DOWNLOAD|TEMPLATES|PUBLICSHARE|DOCUMENTS|MUSIC|PICTURES|VIDEOS|...}}`
