# sar

> پایش عملکرد زیرسیستم‌های مختلف لینوکس.
> اطلاعات بیشتر: <https://manned.org/sar>.

- گزارش نرخ ورودی/خروجی و انتقال دستگاه‌های فیزیکی، هر ثانیه یک بار (برای خروج `<Ctrl c>` را فشار دهید):

`sar -b 1`

- گزارش مجموعاً ۱۰ آمار دستگاه شبکه، هر ۲ ثانیه یک بار:

`sar -n DEV 2 10`

- گزارش مصرف CPU، هر ۲ ثانیه یک بار:

`sar -u ALL 2`

- گزارش مجموعاً ۲۰ آمار مصرف حافظه، هر ثانیه یک بار:

`sar -r ALL 1 20`

- گزارش طول صف اجرا و میانگین بار، هر ثانیه یک بار:

`sar -q 1`

- گزارش آمار صفحه‌بندی، هر ۵ ثانیه یک بار:

`sar -B 5`
