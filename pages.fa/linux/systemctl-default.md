# systemctl default

> ورود به حالت پیش‌فرض سیستم.
> اطلاعات بیشتر: <https://www.freedesktop.org/software/systemd/man/latest/systemctl.html#default>.

- ورود به حالت پیش‌فرض به‌صورت عملیات مسدودکننده:

`systemctl default`

- ورود به حالت پیش‌فرض به‌صورت عملیات ناهمگام:

`systemctl default --no-block`
