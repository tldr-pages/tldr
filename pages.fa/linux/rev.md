# rev

> معکوس کردن خط متن یا فایل.
> اطلاعات بیشتر: <https://manned.org/rev>.

- معکوس کردن متن تایپ‌شده در ترمینال:

`rev`

- معکوس کردن رشتهٔ متنی «hello»:

`echo "hello" | rev`

- معکوس کردن کل فایل و چاپ در `stdout`:

`rev {{path/to/file}}`

- استفاده از `\0` به‌عنوان جداکنندهٔ خط (پایان صفر):

`rev {{[-0|--zero]}} {{path/to/file}}`

- نمایش راهنما:

`rev {{[-h|--help]}}`

- نمایش نسخه:

`rev {{[-V|--version]}}`
